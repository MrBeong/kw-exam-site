## 2. 무누락(Zero-Omission) 개념 정리 5대 원칙

개념 정리 시 "중요한 것만 요약"하는 방식을 엄격히 금지하며, **시험 범위 내 모든 슬라이드와 발언을 단 하나도 빠뜨리지 않고 구조화**한다.

1. **4대 원본 소스 교차 대조**:
   - ① 강의 교안(PDF/PPTX 텍스트 계층 및 그림 내부 캡션) + ② 강의 전사본(교수님 구두 설명·반복 강조·판서) + ③ 실습/과제/퀴즈 자료 + ④ 최신 시험 공지를 1:1로 대조한다. 범위에 속하는 보충학습·연결 영상·실습 데이터도 자료 목록에 포함하며, 영상은 실제 확보한 자막/구간/화면의 확인 범위를 구분해 기록한다.
   - 시험 공지에서 명시적으로 제외된 범위(예: 별첨, 구현 코드, 미강의 슬라이드 등)는 상단 `#scope`에 명확히 분리하여 학습 혼선을 막는다.
2. **원자 개념(Atomic Concepts) 고유 번호 부여 및 전수 목록화**:
   - 각 단원의 모든 정의, 분류 기준, 수식, 성립 가정, 알고리즘 단계, 장단점, 한계점을 쪼개어 고유 ID(`OX001` ~ `OX_N`, 데이터마이닝 기준 184~195개)를 부여한다.
   - 개념별로 해당하는 **[정의] → [수식 및 기호·차원·단위] → [성립 조건 및 가정] → [위반 시 현상 및 해결책] → [유사 개념과의 차이점 비교표]**를 정리한다. 역사·명칭처럼 수식이나 위반 조건이 없는 개념에 무관한 수식·예시를 만들어 넣지 않는다.
3. **교안 빈칸(`???`)·연습 질문·숨김 텍스트 100% 회수 (`#blanks`)**:
   - 슬라이드 내 빈칸 상자, 예제 손계산 문제, PDF 텍스트 레이어에 숨겨진 답안을 페이지 번호(`.blank-page`)와 함께 전수 추출한다.
4. **교수님 강조 포인트 3단계 계층화 (`#priority`)**:
   - 각 교안 마지막 `Summary` 슬라이드 항목(`★★★`), 전사에서 교수님이 "꼭 기억해야 한다 / 중요하다 / 시험에서 헷갈리기 쉽다"고 반복한 항목(`★★★`), 응용 상황 판별 항목(`★★☆`)을 출제 지도로 정리한다.
5. **교안 원문 오탈자 및 엄밀 조건 병기 (`검산 교정`)**:
   - 교안 수식이나 예제 답안에 오탈자(예: 역행렬 정의의 \(Z \to I\), 고유값 부호 오기 \(3 \to -3\), ANOVA \(F\)값 오기, 대칭행렬 조건 누락 등)가 있을 경우, 임의로 삭제하지 않고 **[교안 원문 표현]**과 **[수학적·학술적 정확한 검산 결과]**를 나란히 병기하여 시험에서 어느 기준으로 출제되든 완벽히 대응하게 한다.

## 3. 6단계 학습 파이프라인 구조 및 단계별 역할

과목 자료가 입력되면 아래 **6단계 학습 파이프라인**을 순서대로 구축하며, 전 단계에 걸쳐 개념 누락이 0건(`coverageMissingAfterSupplement = 0`)이 되도록 교차 검증한다.

| 단계 | 구성 요소 | 수록 위치 | 핵심 역할 및 제작 기준 |
|---|---|---|---|
| **Step 1** | **개념 정리** | 메인 `개념 정리` 탭 (`#dashboard`~`#scope`) | 공지 범위 요약 → 교수 강조 출제 지도 → 단원별 전수 아코디언 노트(정의·수식·비교표·검산교정) → 교안 빈칸 전수표 → 직전 체크리스트 |
| **Step 2** | **O/X 퀴즈** | `O/X` 전용 탭 (`./ox/index.html`) | 추출된 **모든 원자 개념(100% 전수)**을 1문장 1개념 진위형 문제로 제작. ‘항상·반드시·자동으로·~만으로 충분하다’ 등 조건 함정 정밀 훈련 |
| **Step 3** | **다지선다 문제** | `다지선다` 전용 탭 (`./multiple-choice/`) | 모든 원자 개념을 **정식 4지선다(단일선택·복수선택·사례형)**로 전환한 집중 훈련장 (`실전 혼합` / `개념별` / `복수정답` 모드 지원) |
| **Step 4** | **단답·서술·코드 작성** | 주관식 원본 JSON/MD와 답안 화면 | 용어·이유·계산·절차를 직접 인출하고 상세 기준으로 자기채점한다. 코드가 공지된 과목은 실제 언어의 편집창·빈칸·완성 코드·실행 검증을 포함한다. |
| **Step 5** | **실전 문제 (전 범위 기출형)** | 전 범위 실전 은행과 개념 대응표 | 학부 시험 수준의 적용·자료 판독·계산·서술 문제로 평가 가능한 모든 개념을 포괄한다. 선행 은행을 활용할 수 있지만 단순 O/X 대응만으로 실전 문제를 완성했다고 하지 않는다. 별도 화면을 쓰지 않아도 실전 은행의 위치와 누락 보완 결과를 명시한다. |
| **Step 6** | **실제 기출 또는 기출형 예상시험 5세트** | 모의시험 화면·세트별 문제/해설·출제 설계 | 실제 기출은 출처를 기록하고 자체 제작 예상시험과 구분한다. 공지된 유형·분량·시간을 적용하며 미공지 문항 수/배점은 시간 배분에 근거한 연습용 가정으로 명시한다. |

## 4. 학부 실제 시험 수준의 변별력 설계 10대 기법 (Data Mining 레퍼런스)

강의 범위와 시험 공지에 맞춰 기본 회상·조건 적용·자료 해석을 평가한다. 용어·정의·공식을 직접 답하는 기본 문항도 공지 유형에 맞으면 포함한다. 지문·자료에 답을 선제시하거나 보기의 형식만으로 고르게 하는 문항은 금지한다. 아래 10가지 설계 기법은 해당 과목에서 배운 내용에 적용하며, 학생 응답 통계로 검증된 변별력과 구분한다.

### 4.1 문항 줄기(Stem) 설계 5대 표준 템플릿
1. **다중 사례 매칭형 (`(가), (나), (다) 짝짓기`)**:
   - 실제 도메인 시나리오 3개 `(가)`, `(나)`, `(다)`를 제시하고 각각의 분석 목적(추론/예측-회귀/예측-분류), 확률분포(포아송/지수/정규), 또는 학습 유형(지도/비지도/준지도/강화)을 바르게 짝지은 보기를 고르게 한다.
2. **복수 진술 정밀 판별형 (`옳은 것을 모두 고르시오`)**:
   - 단원 핵심 개념·수식·가정 4개 진술을 제시하고, 공지·공개한 출제 규칙 안에서 정답 개수를 구성한다. 4지선다 연습에서는 2개·3개 정답을 섞는 방식을 사용할 수 있으며, 항상 같은 개수라는 패턴으로 답을 추측하지 못하게 실제 분포를 확인한다. 각 보기를 독립된 O/X처럼 판단하게 한다.
3. **수치 손계산 & 연쇄 역산형 (`Hand-Calculation & Table Reconstruction`)**:
   - 계산기 허용 여부와 강의 수준에 맞는 수치를 주고, 연쇄 계산형에서는 공식을 2단계 이상 연결해 답을 구하게 한다(예: \(x_i, y_i\) 표본 4개 제시 → \(\bar{x}, \bar{y}, S_{xx}, S_{xy}\) 계산 → \(\hat{\beta}_1, \hat{\beta}_0\) 도출 → 특정 \(x_k\)에서의 예측값 \(\hat{y}_k\) 및 잔차 \(e_k = y_k - \hat{y}_k\) 계산).
4. **통계·전공 소프트웨어 출력표 빈칸 추론형 (`Output Table Interpretation`)**:
   - 회귀분석 결과표(Coefficients 테이블의 `Estimate`, `Std. Error`, `t value`, `Pr(>|t|)` 및 ANOVA 테이블의 `Df`, `Sum Sq`, `Mean Sq`, `F value`)에서 일부 숫자를 `[ (가) ]`, `[ (나) ]`로 가려 두고 자유도·표준오차·제곱합·\(F=t^2\) 관계로 역산하게 한다.
5. **시각 도식·그래프 종합 진단형 (`📊 그림문제`)**:
   - 잔차 플롯 3종, 편향-분산 과녁 4종, 연립방정식 직선 3종, 상자수염그림, 산점도 비교 등을 인라인 SVG로 제시하고 그림에서 평가할 한 가지 핵심 판단을 정하고 필요한 근거를 묻는다. 위반 가정과 해결책은 같은 진단을 완성하는 데 직접 필요한 경우에만 함께 요구한다. 서로 다른 그림·연구를 한 서술형에 묶어 모두 설명하게 하지 않는다.

### 4.2 데이터마이닝에서 사용한 10대 출제 설계 포인트 (과목에 맞춰 적용)
1. **수식의 기준 축(Target Variable of Property) 교란**:
   - 예: 선형회귀의 '선형'이 설명변수 \(X\)의 차수가 아니라 **모수 \(\beta\)에 대한 선형 결합**(\(\partial^2 \hat{y}/\partial \beta_j \partial \beta_k = 0\))임을 물어 \(\beta_1 X^2\)(선형회귀 O)와 \(X^{\beta_2}\) 또는 \(\exp(\beta_1 X)\)(비선형회귀)를 구별하게 한다.
2. **정리(Theorem)와 공식의 정확한 전제 조건(Prerequisites) 타격**:
   - 예: 가우스–마르코프 정리(OLS가 BLUE)에는 선형성·엄격 외생성·구형 오차(등분산·무상관)·풀랭크만 필요하고 **오차의 정규성 가정은 필요하지 않다**는 점(정규성은 유한표본 \(t, F\) 검정에 필요).
   - 예: 서로 다른 고유값에 대응하는 고유벡터는 항상 일차독립이지만, **실수 대칭행렬(\(A=A^\top\))이면 서로 다른 고유값의 고유벡터가 직교한다**는 추가 보장. 일반 행렬에서 서로 다른 고유값이라는 이유만으로 직교를 단정하지 않는다.
   - 예: \(\mathrm{SST}=\mathrm{SSR}+\mathrm{SSE}\)와 \(0 \le R^2 \le 1\)은 **절편(\(\beta_0\))을 포함한 OLS로 추정한 동일 학습 데이터**에서만 보장되며, 절편 없는 회귀나 별도 테스트 세트에서는 \(R^2 < 0\)이 될 수 있다는 점.
3. **1글자 차이 유사 개념 쌍(Confusable Pairs)의 엄격한 대조**:
   - `오차(Error, 관측 불가 모수 기반 ` \(\varepsilon_i = y_i - E[Y\mid X_i]\)) vs `잔차(Residual, 관측 가능 표본 기반 ` \(e_i = y_i - \hat{y}_i\))
   - `추정량(Estimator, 표본의 함수인 확률변수 ` \(\hat{\beta}\)) vs `추정치(Estimate, 실제 데이터 대입 수치)`
   - `확률(Probability, 모수 ` \(\theta\) ` 고정 시 데이터 가능성 ` \(p(y\mid\theta)\)) vs `우도(Likelihood, 관측 데이터 ` \(y\) ` 고정 시 모수의 함수 ` \(L(\theta\mid y)\), 적분해도 1 아님)
   - `설명변수 간 다중공선성(X끼리의 강한 선형 상관)` vs `오차항의 독립성 위반(관측치 간 잔차 자기상관)`
   - `변수 선택(Feature Selection, 기존 변수 부분집합 유지)` vs `변수 추출(Feature Extraction, PCA 등 새로운 축 합성)`
   - `단사(One-to-one, ` \(\ker(T)=\{0\}\)) vs `전사(Onto, 치역=공역)`
   - `REF(행사다리꼴)` vs `RREF(기약행사다리꼴: 피벗=1 및 피벗 열의 다른 원소 모두 0)`
   - `레버리지(Leverage, 설명변수 공간 ` \(X\) `에서의 극단성)` vs `영향점(Influential Point, 회귀계수 추정치를 크게 흔드는 점, Cook's Distance)`
4. **자유도(Degrees of Freedom) 및 분모 함정**:
   - 표본분산·공분산의 분모 \(n-1\), 단순선형회귀 잔차 자유도 \(n-2\), 다중선형회귀(\(p\)개 설명변수, 절편 포함) 모수 개수 \(p+1\) 및 잔차 자유도 \(n-p-1\), 회귀 제곱합 자유도 \(p\), 수정 결정계수 \(\text{Adj } R^2 = 1 - \frac{\mathrm{SSE}/(n-p-1)}{\mathrm{SST}/(n-1)}\)에서 \(n\)과 \(n-1\), \(p\)와 \(p+1\), \(n-p\)와 \(n-p-1\)을 교차 배치해 정확한 공식을 아는 학생만 맞히게 한다.
5. **부호(Sign) 및 계산 순서 역전 함정**:
   - 잔차 정의 \(e_i = y_i - \hat{y}_i\)를 \(\hat{y}_i - y_i\)로 바꿔 부호를 틀리게 하거나, \(2\times2\) 역행렬 공식에서 대각 원소 교환(\(a \leftrightarrow d\))과 비대각 부호 반전(\(-b, -c\))을 반대로 적용한 선지, 행렬 곱 전치 \((AB)^\top = B^\top A^\top\)를 \(A^\top B^\top\)로 쓴 선지를 배치한다.
6. **조건부확률·베이즈 정리의 기저율 오류(Base-Rate Fallacy) 타격**:
   - 낮은 유병률/불량률 상황에서 민감도 \(P(+\mid D)\)를 사후확률 \(P(D\mid +)\)와 혼동하게 하거나, 베이즈 분모 \(P(+) = P(+\mid D)P(D) + P(+\mid D^c)P(D^c)\)에서 거짓양성(False Positive) 항을 빠뜨린 계산값을 매력적 오답으로 제시한다.
7. **실전 파이프라인의 데이터 누출(Data Leakage) 및 검증 원칙 위반 적발**:
   - 전체 데이터에 대해 평균·표준편차 표준화, 결측치 대체, PCA, 오버샘플링(SMOTE)을 먼저 수행한 뒤 Train/Test를 나누는 실수, 또는 테스트 세트 성능을 보고 모델을 다시 고르는 행위를 찾아내게 한다.
8. **상관관계·p값·결정계수(\(R^2\))의 과잉 해석 경계**:
   - 피어슨 상관계수 \(r=0\)은 '선형' 관계만 없을 뿐 \(Y=X^2\) 같은 강한 비선형 함수 관계가 있을 수 있다는 점, \(p < 0.05\)나 높은 \(R^2\)가 관찰자료에서 교란변수 통제 없이 인과관계를 증명하거나 테스트 세트 정확도를 보장하지 않는다는 점을 묻는다.
9. **단위(Unit) 및 스케일 불변성/변화성 판별**:
   - 설명변수나 반응변수의 단위를 바꿀 때(예: m → cm, 원 → 만원) 회귀계수 \(\hat{\beta}_1\)의 수치와 단위가 어떻게 변하는지, 반면 무차원 표준화 지표인 상관계수 \(r\), \(t\)-통계량, \(R^2\), \(\mathrm{VIF}\)는 스케일 변환에 어떻게 반응하는지 묻는다.
10. **진단 지표 발견 후의 올바른 후속 조치(Actionable Remedy) 판별**:
    - Cook's distance나 이상치가 크다고 해서 **즉시 무조건 삭제**하는 것이 아니라 입력·측정 오류 여부, 도메인 맥락, 해당 점 포함/제외 시 계수 민감도를 먼저 확인해야 한다는 원칙; 다중공선성(\(\mathrm{VIF} \ge 10\)) 발견 시 계수 해석 불안정성을 인지하고 변수 선택·도메인 결합·차원축소·규제화(Ridge/Lasso)로 대응하는 절차를 묻는다.

### 4.3 다음 과목의 난이도 설계와 판정

‘같은 수준’은 같은 문항 수·길이·계산량을 복사한다는 뜻이 아니다. 공지된 유형과 해당 과목의 학부 강의 내용 안에서 아래 평가 행위를 설계하고, 왜 그 수준인지 기록한다.

| 예상 수준 | 평가 행위 | 문항 설계와 검수 기준 |
|---|---|---|
| 기본 | 핵심 용어·정의·조건 회상, 직접 계산, 단순 자료 읽기 | 공지된 단답형·기초 확인을 포함한다. 물음에 답이나 번역 목록을 붙이지 않는다. 모든 기본 문항을 복합 추론으로 바꾸지 않는다. |
| 적용 | 인접 개념 구별, 조건 변화 적용, 분석 방법 선택, 계산 단계 연결 | 강의에서 배운 차이를 근거로 보기를 판별한다. 생소한 표현·황당한 오답을 지우는 것만으로 정답에 도달하지 않게 한다. |
| 통합 | 여러 개념으로 표·그림·출력·사례를 해석하고 판단을 정당화 | 필요한 자료·정의·단위·가정이 문제 안에 완결돼야 한다. 설명해야 할 판단과 채점 기준의 항목이 일치해야 한다. |

- **범위와 근거**: 문항별 개념 ID·원문 위치·평가 행위·필수 조건을 먼저 정한다. 범위 밖 이론·더 높은 학년의 기법·익숙하지 않은 영어를 추가해 난도를 높이지 않는다. 교안의 단순화·경험칙은 교안의 설명 범위로 한정한다.
- **유형과 분량**: 실제 기출·공지·교수 강조·강의 예제의 복잡도를 우선한다. 근거가 부족하면 수준·유형 배분과 예상 소요시간을 ‘연습용 설계 가정’으로 기록한다. 일률적인 어려운 문제 비율은 강제하지 않는다.
- **시간과 작업량**: 지문 읽기·자료 확인·계산·코드 빈칸·서술·답안 검토를 포함해 문항별 시간을 산정한다. 총 풀이 시간과 별도 검토 시간은 공지된 시험 시간 안에 들어가야 한다. 어려움을 긴 독해·불필요한 계산·작은 글씨·누락 자료로 대신하지 않는다.
- **은행과 시험 세트 구분**: 은행 전체는 개념을 빠짐없이 훈련하고, 실제 시험 세트는 공지된 분량·유형·시간에 맞춘다. 세트의 난이도·단원 편중을 비교하되 각 세트에 모든 원자 개념을 억지로 넣지 않는다.
- **정답 유일성과 재풀이**: 보기만 읽는 검토 뒤 문제를 다시 풀어 단일 정답 또는 복수 정답 집합을 확정한다. 설명을 길게 하거나 오답 표현을 완곡하게 바꾼 뒤에도 오답이 주어진 조건에서 참이 되지 않았는지 확인한다.
- **증거 구분**: 예상 난이도와 검토 근거를 기록한다. 실제 학생 응답·풀이 시간이 있을 때만 정답률·변별도·오답 선택률 등 측정 결과를 별도로 기록한다. 글자 수·수식 개수·개념 ID 누락 0·자동 검사 통과를 실제 난이도의 증명으로 쓰지 않는다.

## 5. 보기(선지) 구성 및 선지별 상세 해설 7대 원칙

1. **선지 길이와 문장 구조의 엄격한 대칭성**:
   - 정답 선지만 길고 구체적이거나 조건이 자세히 적혀 있어 내용 없이 찍을 수 있는 문제를 엄격히 금지한다. 선지의 분량·구문·학술적 어조·수식 밀도가 정답 단서가 되지 않도록 균형을 맞춘다. 글자 수를 억지로 같게 하여 의미를 흐리지 않는다.
2. **오답 선지(Distractor) 7대 엔지니어링 기법**:
   - 모든 오답 선지는 아래 7가지 중 하나에 해당하는 **학습자가 혼동할 수 있는 구체적 오개념**으로 설계한다:
     1. **분자·분모 역전형** (예: \(\hat{\beta}_1 = S_{xx}/S_{xy}\), \(\mathrm{VIF}_j = 1 - R_j^2\), 조건지수 \(\sqrt{\lambda_j/\lambda_{\max}}\))
     2. **자유도 오기형** (예: 분모에 \(n-p-1\) 대신 \(n\) 또는 \(n-p\) 대입)
     3. **부호 반전형** (예: 잔차 \(\hat{y}_i - y_i\), 고유방정식 인수분해 부호 반전)
     4. **핵심 조건 누락/과잉 일반화형** (예: "항상", "어떠한 행렬에서도", "정규성이 있어야만 BLUE이다")
     5. **인접·쌍둥이 개념 치환형** (예: 추론 자리에 예측 배치, 포아송 자리에 지수분포 배치, 등분산 자리에 독립성 배치)
     6. **중간 계산값 노출형** (예: 분산 \(\sigma^2\)을 구한 뒤 제곱근을 씌우지 않아 표준오차 대신 분산을 고르게 함, \(\mathrm{SSR}\)만 구하고 \(\mathrm{SST}\)로 나누지 않음)
     7. **인과·일반화 비약형** (예: "\(p < 0.001\)이므로 인과효과가 증명되었다", "\(R^2 = 0.85\)이므로 테스트 데이터에서도 85% 정확도로 맞힌다")
3. **결정론적 선지 셔플 (`seededShuffle`)**:
   - 고정된 보기 배열 또는 문항 ID 기반 `seededShuffle(options, q.id)`를 사용해 재접속 시 보기·답안 연결이 일관되게 한다. 셔플만으로 균등 분포가 보장된다고 하지 말고 최종 정답 위치를 실제 집계해 편향을 점검한다. 보기 고유 ID로 답안을 저장한다.
4. **채점 즉시 모든 선지(정답 `✓` + 오답 `×` 전체)에 개별 상세 풀이 노출 (필수)**:
   - 각 선지 객체는 반드시 `{"id": "...", "text": "...", "correct": true, "explanation": "..."}` 4개 필드를 가진다. `correct`는 실제 JSON의 `true` 또는 `false`로 기록한다.
   - 오답 선지의 `explanation`에는 단순한 부정("틀린 설명이다")이 아니라 **① 왜 틀렸는지(어느 수식/자유도/부호가 잘못되었는지)**와 **② 올바르게 고치면 무엇인지(정확한 계산값과 공식)**를 한 문장으로 명확히 적는다.

5. **정답 유일성·집합 및 채점 조건**:
   - 단일선택에는 최선의 정답이 하나인지, 복수선택에는 ‘모두 고르시오’와 정답 집합이 명확한지 검증한다. 일부 정답 선택·오답 추가·O/X 진술 묶음의 부분점수 처리는 UI·해설·배점에서 일치시킨다.
6. **보기와 자료·표기 간의 정합성**:
   - 제시 표·그래프·코드·문제 조건과 각 보기를 대조한다. 보기 셔플 시 `(가)/(나)`, ‘1·2번’ 등 위치 참조가 틀어지지 않게 하고, 동의 표현 중복·여러 정답·무관한 오답을 제거한다.
7. **풀이 단계에 맞는 해설 공개**:
   - 일반 연습은 답안 채점 후 전체 보기 해설을 공개한다. 시험 모드는 제출/시간 만료 전 해설을 공개하지 않는다. 재풀이 시작은 해설을 다시 닫고, 문제의 제시자료는 정답 누설 없이 풀이에 필요한 근거를 유지한다.

### 5.1 정답을 모른 채 보는 보기 품질 검사 (2026-10-18)

- 정답 표시와 해설을 가린 학생 화면에서 전 문항의 보기를 먼저 읽는다. 정답만 길거나 구체적인지, 유일한 오답만 길어지는지 확인한다. 정답에만 조건·예외·전문 용어가 몰리거나 오답에만 ‘항상·절대·오직’이 반복되는 패턴도 검사한다. 그런 단어의 존재 자체를 오답 기준으로 삼지는 않는다.
- 보기들이 같은 질문에 답하도록 정보 항목·문장 수·조건의 수준을 맞춘다. 문법·어조·용어 수준·수치 자릿수·단위·수식/코드 표기 역시 정답만 두드러지지 않게 한다. 중복·동의 보기나 보기끼리의 포함 관계로 정답이 드러나는지도 확인한다. 길이는 공백·TeX 명령을 정리한 문자 수로 이상치를 찾고, 실제 데스크톱·모바일 줄바꿈과 수식 표시도 확인한다. 비율 기준은 검토 도구이며 합격의 충분조건이 아니다. 숫자·벡터처럼 답의 형태 자체를 평가하는 문항에 불필요한 문장을 붙이지 않는다.
- 무관한 학문·단위·시대나 황당한 수치를 채우지 않는다. 수치 오답은 제곱·부호·분모·반올림·단위 환산 등 구체적인 오류에서 산출하고 그 계산 경로를 해설에 남긴다. 인접 개념, 조건의 차이, 추정과 검정, 표본과 일반화, 코드 인자, 단위 환산·중간 계산 오류를 근거로 오답을 설계한다. 실제 응답 통계가 없으면 ‘검증된 다빈도 오답’이나 측정된 변별력이라고 주장하지 않는다.
- 오답을 완곡하게 다듬다가 주어진 조건에서는 참이 되지 않았는지 다시 풀어 본다. 틀린 인과관계는 보기 안에 명시하고 해설에만 숨기지 않는다. 필요 조건·유의수준·적용 모형을 지문에서 명확히 하되 정답의 판단을 선제시하지 않는다.
- 분석·함수 선택을 평가하는 코드 보기는 실제 언어 문법으로 작성하고, 인자·집단 선택·모형 방향·반환값 해석 등의 차이로 판단하게 한다. 문법 오류 자체를 찾는 문항은 그 목적을 명시한다. 구문 분석과 실제 실행·출력 검증을 구분하며, 의도한 오답의 잘못된 분석까지 정답 코드로 고쳐 버리지 않는다.
- 길이 비율은 이상치 후보를 찾는 보조 지표다. 이번 레퍼런스는 모든 보기의 정규화 길이가 15자 이상인 문항에서 `정답 평균 길이 / 오답 평균 길이`가 `0.67~1.50` 밖인지 양방향으로 확인했다. 이 수치와 ‘이상치 0’을 다음 과목의 강제 합격선으로 복사하지 않는다. 숫자·벡터·수식 결과처럼 형태를 평가하는 경우의 유지 사유와 수동 검토 결과를 남긴다. 화면 줄 수가 같아도 의미 검토가 필요하다.
- 원본·모의시험의 보기별 근거와 정답 집합을 대조하고, 보기 ID별로 갱신해 각 페이지의 기존 순서를 보존한다. 출력된 정답 번호·부분점수·합산 기준을 다시 검사한다. 의미나 정답 판정이 바뀌는 수정은 12.1절에 따라 기존 학습 기록을 처리한다.
- 전수 검토 수, 실제 수정 ID, 유지한 계산·대응형의 근거, 정답 위치 분포, 복수정답 개수, 실행 가능한 R 코드의 문법 검사와 실제 실행 여부를 기록한다. 전체 문항·개념·배점 및 저장·재풀이 회귀 검증과 함께 완료한다.

## 6. 시각·그림 문제 (`📊 그림문제`) 제작 표준 규격

시험에서 그래프·도식·산점도·결과표 해석 문제가 출제될 때 완벽히 대비할 수 있도록, **문항의 일부분이 아닌 문제 전체의 비교 구도와 핵심 정보를 포괄하는 도식·원문 그림·표**를 제작한다.

1. **'문제 전체 포괄형(Holistic Comparison)' 도식 설계 원칙**:
   - 필요한 **정상/위반·변환 전/후·성분 분해**의 비교 조건을 모두 포함한다. 비교가 필요한 문항은 2~4개 패널로 묶을 수 있지만, 단일 그래프/표로 충분한 문항에 관련 없는 패널을 추가하지 않는다. 원문 그림은 축·범례·단위·필요한 캡션을 보존한다.
2. **과목 공통으로 활용 가능한 레퍼런스 도식 패턴 (데이터마이닝 기출 1~5세트 적용 사례)**:
   - **다중 패널 패턴 비교형**: 잔차 진단 3종 비교 `(A) 수평 무작위 띠(정상)` vs `(B) U자 곡선(비선형성)` vs `(C) 부채꼴 확산(이분산성)`
   - **기하학·벡터 분해형**: 선형회귀 편차 분해 \((y_i - \bar{y}) = (\hat{y}_i - \bar{y}) + (y_i - \hat{y}_i)\) 또는 선형변환 전후 기저 격자·고유벡터 방향 유지 도식
   - **2×2 매트릭스·과녁 비교형**: 편향–분산(Bias–Variance) 4개 과녁 비교 `(가) 저편향·저분산` ~ `(라) 고편향·고분산`
   - **분포·분위수·임계값 도식형**: 상자수염그림(Boxplot)의 \(Q_1, Q_2, Q_3, \mathrm{IQR}\), 수염 경계(\(Q_3 + 1.5\mathrm{IQR}\)) 및 이상치 표시 / 정규 Q–Q Plot의 대각선 이탈 패턴
   - **인과 그래프(DAG) 및 파이프라인 다이어그램형**: 교란변수 \(Z \to X, Z \to Y\) 구조도 / 교차검증 및 전처리 데이터 누출(Data Leakage) 발생 구간 표시도
   - **수치 좌표·행렬·출력표 결합형**: 소규모 관측점 좌표 산점도 + 회귀선 / 소프트웨어 ANOVA·계수 출력 테이블 박스
3. **시각적 가독성 기준**:
   - `.visual-box` 배경(`#f8fafc`), 테두리(`1px solid #cbd5e1`), 상단 제목(`📊 [제시 그림] ...`), 반응형 `viewBox`, 명확한 축 라벨과 색상 구분(정상/기저: `#2563eb` 블루, 기준선/회귀선: `#dc2626` 레드, 보조/평균선: `#16a34a` 그린)을 사용한다.

## 7. 기출 문제 5세트 분량 산정 및 단원 배분 공식

1. **1세트당 문항 수 산정 기준**:
   - **제1원칙 (실제 출제 문항 수 파악 시)**: 교수님 공지, 이전 기출, 또는 강의 중 언급으로 실제 시험 문항 수가 파악되면 **그 문항 수를 정확히 1세트 분량**으로 고정한다 (예: 데이터마이닝 중간고사 **18문항 × 5세트 = 90문항**).
   - **제2원칙 (출제 문항 수 미파악 시 — 시험 시간 기준 산정 공식)**:
     - 아래 문항 수는 초기 연습 설계 예시다. 실제 문항별 읽기·풀이 시간과 검토 시간 합계, 공지된 유형을 기준으로 조정한 뒤 **5세트**를 제작한다:
       - **50~60분 시험 (객관식·단답·손계산 혼합)**: **18 ~ 20문항 / 세트** (총 90~100문항)
       - **50~60분 시험 (개념·O/X·단순 객관식 위주)**: **25문항 / 세트** (총 125문항)
       - **75~90분 시험 (복합 계산·서술·객관식 혼합)**: **20 ~ 25문항 / 세트** (총 100~125문항)
       - **서술·증명·대문항 위주 시험 (60~90분)**: **대문항 8~10개(소문항 포함 15~20문항) / 세트**
        - **120분 혼합형 시험**: 유형별 예상 풀이 시간 합계와 검토 시간을 먼저 배정한 뒤 문항 수를 정한다. 인터랙티브심리학의 32문항·100점·5세트는 사례이며 모든 2시간 시험의 고정 분량이 아니다.
2. **세트 내 단원별·유형별 배분**:
   - 단원·유형 비중은 실제 공지·기출·교수 강조와 풀이 시간을 우선한다. 근거가 없는 경우 균등 배분 (\(\lfloor N/K\rfloor \sim \lceil N/K\rceil\))은 초기 설계안으로 쓸 수 있으며 실제 분포를 강제하는 공식으로 사용하지 않는다.
   - 각 세트에서 범위 내 단원들이 고르게 연습되는지 확인하고, 모든 세트의 합집합과 별도 전 범위 실전 은행에서 전체 개념을 다루게 한다. 한 세트가 모든 원자 개념을 전부 포함한다고 주장하지 않는다.
   - 연습용 O/X·복수정답 유형과 실제 시험에 공지된 유형을 구분한다. 모의시험은 공지된 유형을 중심으로 만들고, 주관식/코드가 공지됐으면 해당 분량을 반영한다.
   - 그림·표 문항은 개념·범위에 필요한 만큼 배치한다. ‘세트마다 그림 최소 3개’ 같은 형식적 수량을 맞추려고 무관한 자료를 넣지 않는다. 전체 비교 조건을 갖춘 시각 자료와 해설은 실제 해당 문항에서 검증한다.
   - 문항별 예상 시간과 별도 검토 시간을 합해 시험 시간과 맞추고, 세트별 문항 수·배점 합계·단원·유형·개념 수·자료 수를 실제 문항 배열에서 산출한다. 세트 간 문항/수치 변형은 출처 ID와 함께 추적하고 변형 답안도 재검산한다.

## 8. 제작 완료 전 최종 검수표

각 과목의 실제 개념 목록·문제 데이터·최종 화면을 기준으로 다음 항목을 확인한다. 내용은 원문과 대조하고, 계산·실행은 독립 검산하며, 기능은 브라우저에서 조작한다. 미검수 항목을 통과로 표시하지 않는다. 부분 단계 완료와 전체 제작 완료를 구분한다.

| 번호 | 검수 항목 | 완료 조건 |
|---|---|---|
| 1 | 디자인·화면 | 웹디자인 가이드 12절의 구성요소를 대조한다. 테마·탭·목차·필터·자료·편집창·재풀이·시험·검색·인쇄·빈 상태·키보드와 데스크톱/모바일을 확인한다. |
| 2 | 시험 공지·범위 | 최신 일시·범위·유형·언어·시간·제외 항목을 대조한다. 보충학습·영상도 포함 여부와 실제 확인 근거를 기록한다. |
| 3 | 개념 정리 | 정의·공식·가정·단위·비교 개념·교안 빈칸·구두 강조가 개념 목록과 노트에 대응한다. 자료 버전이나 교안 오류는 원문과 교정을 구분한다. |

### 8.1 정답 단서가 문제에 노출되지 않는지 확인

- **문항이 요구하는 것을 먼저 표시한다.** 명칭·분류·순서·공식·수치를 회상하라고 했으면 그 답이나 한글 번역을 괄호, 제목, 비교 대상의 나열 순서, 코드 설명에 미리 적지 않는다. 예를 들어 브랜드 경험의 네 영문 요소를 묻는 지문에 인지도·태도·윤리·충성도를 붙이지 않는다.
- **필수 자료와 해석을 구별한다.** 원자료·조건·단위·변수 정의·유의수준·필요한 로그값은 유지한다. 계산된 정답, 영향의 방향, 원인 분류, 추가 자료 필요성 같은 판단은 해설에서 설명한다. 정의를 적용하는 문항의 변수 설명이나 공식 적용을 평가하는 문항의 명시적 주어진 식을 무조건 삭제하지 않는다.
- **그림·표·코드까지 본다.** 강의 슬라이드가 답을 직접 쓰고 있으면 문제용 자료를 축·범례·관측값·비교 조건이 온전히 남도록 재구성한다. 단지 답을 숨기려고 자료를 잘라 문제 조건을 누락하지 않는다. 캡션·alt/title·코드 주석·준비 코드에 빈칸 답이 반복되는지도 확인한다.
- **보기와 물음을 함께 검토한다.** 지문 숫자나 기능 목록을 그대로 복사한 보기가 정답이 되는 경우에는 그 자료의 의미·적용·판정을 묻도록 바꾼다. 정답만 지우고 무엇을 답해야 할지 모호해지지 않도록 한다.
- **복제본에도 전파한다.** 원본과 모의시험의 대응 ID·검색용 지문·그림·해설·채점 기준을 함께 갱신하고 수치 변형은 그 문항의 자료·답을 유지한다. 정답/보기 의미가 바뀌면 12.1절의 저장 기록 호환 규칙을 따른다.
- **학생 화면으로 재검증한다.** 정답 공개 전 화면에서 문제·자료를 보고 풀 수 있는지 확인하고, 공개 후에는 영문 용어·상세 해설·채점 기준이 완전한지 확인한다. 자동 문구 검사와 실제 문항의 교육적 판단을 구분해 기록한다.

### 8.2 보기·난이도 전수 검토 순서와 완료 판정

1. **출제 근거 확인**: 개념 ID·범위·평가 행위·공지 유형·답안 언어·필수 자료·예상 수준·풀이 시간을 문항별로 확인한다. 틀린 보기의 근거도 강의 안의 구체적 개념과 연결한다.
2. **정답을 가린 검토**: 5.1절에 따라 보기만 보고 추측할 수 있는 형식·길이·어조·정답 개수 패턴을 찾는다. 이어 전체 지문·자료를 보고 괄호 번역·제목·캡션·코드 주석의 정답 단서를 확인한다. 실제 시험 세트는 다른 독립 문항이 답을 직접 제공하는지도 확인하되 의도한 공통 자료와 구분한다.
3. **독립 재풀이**: 정답표에 맞추기보다 제공된 자료와 조건에서 답을 다시 구한다. 단일선택 정답 하나·복수선택 집합·모든 오답의 잘못된 지점을 각각 확정한다. 모호한 문항은 조건·물음을 고치고 다시 푼다.
4. **해설·채점 대조**: 원본·모의시험·수치 변형의 지문/자료/보기/정답/해설/부분점수를 대조한다. R 등 코드는 구문과 실제 실행을 구분해 확인한다. 객관식 정답·오답·일부 정답·오답 추가, O/X 진술별 점수, 주관식 기준 합계가 공개 채점 규칙과 일치해야 한다.
5. **생성본과 학생 화면 확인**: 원본을 수정해 MD·HTML을 재생성한다. 제출 전에는 정답 표시·해설·채점 내용이 새지 않고 필요한 자료는 보이며, 공개 후에는 모든 보기/단계의 해설과 기준이 표시돼야 한다. 데스크톱·모바일에서 실제 줄바꿈·수식·코드·자료를 확인하고 관련 채점·저장·초기화·재풀이를 다시 검사한다.
6. **기록과 완료 판정**: 11.3절의 문항별 기록을 남기고 변경을 모든 복제본에 전파한다. `보완 필요`나 `미검수`가 남은 범위를 완료라고 보고하지 않는다. 길이 이상치 수·자동 검사 수만으로 통과시키지 않으며, 마지막 보완 후 영향을 받는 검사를 다시 실행한다.

문항 검토의 독립 재풀이는 정답표를 숨기고 별도로 계산·판단한다는 뜻이다. 별도 검토자가 참여했는지는 실제 수행 여부만 기록하며, 형식적으로 인원이 있었다고 쓰지 않는다.

## 9. 단계별 무누락 검증의 증거와 기능 확인 (2026-10-17 보완)

- 문제은행에는 원자 개념 ID 대응표와 각 보기의 정답 여부·상세 해설을 함께 유지한다. 대응 개념 수와 원본 재감사 여부를 구분하여 기록한다.
- 여러 개념을 한 문항에서 묻는 경우 지문·보기·해설에 실제로 해당 개념을 판단할 근거가 있어야 한다. ID만 붙여 커버리지로 계산하지 않는다.
- 문항 수는 전수 훈련용 은행과 실제 시험 분량을 구별한다. 실제 원문이 없는 자체 제작 문제를 실제 기출로 표시하지 않는다.
- 교안의 단순화·경험칙은 문제 조건에 한정한다. p값의 비기각을 가설의 증명으로, R²를 미래 정답률로, 시각 강조를 확률 분포 변화로 바꾸어 해석하지 않는다.
- 완성 단계마다 채점·정답 복원·오답·북마크·초기화·모바일 화면을 브라우저로 검사하고, 다음 단계로 이어갈 문서를 갱신한다. 전체 최종 검수는 8절의 표, 오답 재풀이 예외는 10절, 결과 기록은 11절을 따른다.


## 최신 답안 언어·주관식 제작 기준 (2026-10-17)

- “용어를 영어로 작성”은 교안에서 영문으로 제시한 명칭을 쓰라는 뜻이다. 설명·해석·수치 답안이나 원래 한글인 개념까지 임의로 영어로 바꾸지 않는다. 요구 영문 용어마다 교안 페이지 근거를 기록한다.
- 주관식은 답안 작성→모범답안·상세 풀이 열기→배점 항목 체크→완벽 이해/애매함/다시 풀기의 흐름으로 제공한다. 자유 서술·코드를 실행·의미 분석 없이 자동 채점한다고 표시하지 않는다.
- 배점 항목 합계와 문항 총점을 일치시키고, 수식·단위·조건·부호·자유도의 실수별로 부분점수를 구분한다.
- 코드에는 실행 가능한 모범 코드와 동등한 대안의 인정 범위를 적는다. 코드 구문 검사와 실제 R 실행 검증 여부를 구분해 기록한다.

### R 코드 부분 빈칸·한 줄 전체 작성 기준 (2026-10-18)

- R 문항은 **부분 빈칸과 한 줄 전체 작성**을 함께 준비한다. 부분 빈칸은 실행 가능한 코드 틀을 제공하고, 한 줄 작성은 이미 준비된 객체·열·조건과 원하는 결과를 제시한 뒤 함수·조건·인자를 포함한 문장 전체를 입력하게 한다. 모든 문항을 함수명만 묻는 빈칸으로 제한하지 않는다.
- 함수명·인자·행 선택 조건·포뮬러·계산식 등 강의에서 다룬 핵심 부분을 빈칸으로 만들고, 입력값·객체·열 자료형·패키지 준비 여부를 지문에서 명시한다.
- 부분 빈칸에는 “빈칸에 들어갈 코드를 적으시오”, 한 줄 작성에는 “원하는 결과를 얻는 R 코드 한 줄 전체를 작성하시오”를 명시한다. 문자열은 필요한 따옴표를 포함해 실제 R 문법으로 답하도록 안내한다. 출력값·검정 해석은 요구가 있는 경우 별도 답안으로 받는다.
- 해설에는 번호별 또는 한 줄 전체의 모범 코드, **코드 한 문장씩의 역할**, 완성 코드, 의미 단위별·추가 답안별 부분점수를 적는다. 주어진 코드 틀에서 같은 동작을 하는 동등한 식은 인정하며 문자열 일치만으로 자동 채점하지 않는다.

### 코드 서식 보완 (2026-10-17)

- 문제 코드와 완성 답안은 실제 R 스크립트 형태로 작성한다. 여러 줄 함수 호출의 인자는 2칸 들여쓰고, 닫는 괄호를 호출 시작과 맞추며 논리 단계 사이에 빈 줄을 둔다.
- 웹에서는 줄 번호·고정폭 글꼴·문법 색상·R 파일 탭을 제공하고, MD의 r 코드 블록에도 같은 개행과 들여쓰기를 보존한다. 빈칸 번호와 UI 라벨은 R 소스의 일부로 섞지 않는다.


### 분석자료·수식·코드의 완결성

- 문항별로 ‘요구하는 판단/계산 → 필요한 근거 → 실제 제시된 자료 → 정답 → 해설·채점 항목’을 대조한다. p값·설명력·집단 차이를 묻는다면 해당 출력이나 요약값을 제시하고, 로그 해석에는 실제 열 이름과 의미를 적는다.
- 연관 없는 그래프·다른 실험의 표·비슷한 주제의 코드를 빈자리에 넣지 않는다. 같은 문항의 서로 다른 분석이라면 구분해서 표시한다. 실제 원자료와 새로 구성한 연습 데이터도 구분한다.
- 필요한 자료는 문제에 표·텍스트·준비 코드로 직접 제공할 수 있다. 이미지일 경우 문제 전체의 비교 조건·축·범례·단위·표본/조건·해석에 필요한 캡션을 포함한다. 과목에 따라 원문 그림을 사용할 수 있으며 SVG라는 형식만을 위해 필요한 원문 정보를 바꾸지 않는다.
- 코드 입력에 외부 데이터가 필요하면 전체 준비 코드/자료를 문제에서 읽을 수 있게 하고, 현재 답안 초기화로 제시자료까지 지우지 않는다. 완성 코드에 준비 코드를 결합하면 미제공 객체 없이 독립 실행되어야 한다.
- 수식은 `\(...\)` 또는 `\[...\]`로 작성한다. 예를 들어 표본평균의 표준오차는 `\(\mathrm{SE}=s/\sqrt{n}\)`처럼 표시한다. 표본 수 산정식은 분수·제곱·평균 기호와 해당 공식의 전제, 정수 올림·추가 인원 계산 기준을 함께 검증한다.
- 수식 엔진은 로컬 자산으로 제공하고 모든 고유 TeX를 실제 변환한다. R의 `$`, 코드 비교 연산자, 문자열·입력칸을 수식으로 바꾸지 않는다. 값이 맞아도 깨진 수식은 수정하며, 잘 렌더링돼도 잘못된 공식은 통과시키지 않는다.
- R 등 코드 검증은 각 문항의 실제 빈칸 답안으로 완성한 소스가 모범 코드와 같은지 먼저 대조한 뒤 실행한다. 원본과 모의시험 변형을 모두 실행하고 통계량·p값·자유도·출력 형태·그림·해석을 비교한다. 정상적으로 예상한 경고와 실행 오류를 구분한다.
- 검증용 원본 데이터의 버전·해시, 실행기/패키지 버전, 명령, 출력, 검사 결과를 보관한다. 반복 실행이 필요하면 고정 데이터나 시드를 사용하고 수치 허용오차를 명시한다. 구문 검사나 결과의 문자열 비교만으로 실행·통계 해석 검증을 대신하지 않는다.

## 10. 오답 재풀이의 과목 공통 검증 시나리오

기본 동작과 저장 규약은 [웹디자인 가이드 10절](02_시험대비_웹디자인_표준가이드.md#retry-state-standard)을 따른다. 아래 사례는 각 문제 유형에서 실제 브라우저로 확인하고 결과를 남긴다.

| 시나리오 | 기대 결과 |
|---|---|
| 전체·미응답·북마크 ↔ 오답 탭 이동 | 첫 클릭은 오답 목록만 표시하고 바는 접힌 상태다. 같은 탭을 다시 누르면 바를 펼치고, 재클릭하면 바만 접는다. 화살표·aria-expanded와 화면이 일치하며 답안·현재 문항·진도는 바뀌지 않는다. |
| 정답·오답·미채점·애매함·북마크 혼합 | 채점상 오답만 선택한다. 주관식 `unsure`는 제외한다. 명시적 복습 표시는 `오답·복습`에서 구분한다. |
| 새 회차 시작 | 기존 답안 보관, 새 선택/텍스트/코드 빈칸 준비, 해설 닫힘, 회차 문항 ID와 진행 정보 표시 |
| 재풀이 중 새로고침 | 같은 회차·현재 문항·입력·추가 답안·채점 상태를 복원하며 새 입력을 다시 지우지 않는다. 제어 바는 접힌 상태로 돌아가고 활성 오답 탭을 누르면 다시 펼쳐진다. |
| 정답으로 재채점 후 다음 회차 | 해결한 문항은 제외하고 아직 틀린 문항만 남긴다. 최신 결과가 오래된 오답을 덮어쓴다. |
| 입력만 한 뒤 종료/다른 상태 탭 이동 | 미채점 문항의 이전 답안·채점을 복원하고, 확정한 새 결과는 유지한다. |
| 채점 완료 후 답안/채점 기준 수정 | 미확정 상태로 되돌리고 해결 집계를 무효화한다. 다시 확정하지 않고 종료하면 기존 기록을 복원한다. |
| 오답 0개 / 애매함만 존재 | 오답 없음 안내 또는 비활성 상태. 전체 문제를 대신 시작하거나 아무 반응 없는 활성 버튼을 두지 않는다. |
| 제출한 모의시험의 여러 세트 오답 | 최신 결과를 모아 별도 연습으로 풀며, 제출 답안·원래 시험 점수·다른 세트 기록은 보존한다. |
| 시험 진행 중 재풀이 시도 | 재풀이·세트/모드 전환을 막고 진행 중 답안과 마감 시각을 유지한다. |
| 타이머 갱신·화면 다시 그리기 | 1초 갱신이나 렌더링이 재풀이 답안/선택/코드 입력을 지우지 않는다. |
| 직접 링크 → 종료 → 새로고침 | 선언·저장소 준비 후 한 번만 시작하며, 소비한 URL 요청이 재풀이를 다시 시작하지 않는다. |
| 다른 탭 저장·재진입·저장 실패 | 최신 저장 객체와 회차 보관본의 연결이 유지되고 답안이 유실되지 않는다. 저장 실패는 표시한다. |
| 초기화 실행/취소와 모바일 조작 | 취소 시 유지, 실행 시 명시한 범위만 초기화한다. 작은 화면에서도 버튼·제시자료·빈칸·이동 제어를 사용할 수 있다. |

## 11. 검수 결과와 다음 과목 인계 기록

### 11.1 결과 기록 형식

과목별 최종 검수 MD와 재현용 `final-audit/`를 함께 유지한다. 기존 문서 번호를 존중하고 README나 범위 문서에 최신 검수 문서로 가는 링크를 둔다.

| 기록 항목 | 과목마다 새로 작성할 내용 |
|---|---|
| 기준 자료·확인 범위 | 최신 시험 공지, 원문 파일/페이지·데이터 버전, 보충영상 확인 근거, 제외·미확인 항목 |
| 실제 목록과 개수 | 개념 수, 유형별 문항 수, 보기 수/정답 위치, 채점 항목 수, 코드·빈칸 수, 고유 수식 수 |
| 대응 검증 | 문제은행별 누락 ID, 실제 내용 대조 결과, 보완 문항 및 오류 수정 내역 |
| 내용·실행 결과 | 수치 검산, 수식 변환, 코드 실제 실행의 통과/실패 수와 실행 환경·허용오차 |
| 브라우저 결과 | 순회 문항 수, 자료·그림·코드·해설 표시, 재풀이·저장·초기화·타이머·모바일·직접 링크 예외 결과 |
| 재생성·게시 결과 | 원본/생성본/게시본의 일치, 필요한 상대 경로·참고자료, 게시했다면 원격 커밋·빌드 상태·공개 주소 확인 결과 |

## 12. 과목별 실제 제작 순서와 단계별 산출물

학습 흐름은 3절의 6단계를 유지한다. 그 앞의 자료 수집·디자인과 그 뒤의 검수·게시·인계까지 아래 순서로 관리한다. 사용자가 ‘하나씩’ 요청하면 요청한 단계까지 완료·검수하고 결과와 다음 작업을 알린다. 아직 제작하지 않은 단계의 링크를 완성된 기능처럼 연결하지 않는다.

| 순서 | 작업 | 필수 산출물과 다음 단계 진입 조건 |
|---|---|---|
| A | 최신 요청·공지 확인 | 범위/제외 범위·유형·시간·언어·준비물·문항 수·배점·게시 시점을 확정/미공지/설계 가정으로 구분한다. 사용자 최신 지시를 과거 MD보다 우선 적용한다. |
| B | 자료 목록·원문 대조 | 교안·전사·실습/과제·보충학습/영상·원본 데이터마다 파일/URL·버전·페이지/구간·확인 상태를 기록한다. 누락·읽을 수 없는 자료를 미확인으로 남기며 추측으로 메우지 않는다. |
| C | 디자인 기본 구조 | 02번 가이드의 테마·상단 탭·개념 목차·문제 카드·코드/자료 영역을 구성한다. 공통 화면을 복제하되 과목명·범위·ID·저장 키·링크·시험 시간을 교체한다. |
| D | 개념 정리 | 원문 단위 → 원자 개념 ID → 노트/공식/빈칸/강조/교정 대응표를 만든다. 개념 노트와 원문을 양방향 대조해 빠진 내용과 근거 없는 내용을 확인한다. |
| E | O/X | 전 개념의 핵심 조건을 전수 점검한다. 정답·상세 해설·출처·개념 ID와 정오/저장/초기화를 확인한다. |
| F | 다지선다 | 실제 학부 시험 수준의 사례·조건·계산·표/그림 판독으로 구성한다. 4.3·5.1~5.2·8.2절에 따라 예상 수준·보기 단서·정답 집합·모든 보기 해설·정답 위치·자료·커버리지를 검수하고 11.3절에 기록한다. |
| G | 단답·서술·코드 | 영문 명칭 요구는 교안 근거에 한정한다. 모범답안·상세 풀이·부분점수·대안 인정 기준을 제공하고, 코드는 17절에 따라 강의 입력 화면·객체명·문법을 대조하고 부분 빈칸과 목표 결과→한 줄 전체 작성을 분산한다. 문장별 해설·의미 단위 채점·동등 대안을 제공하며 준비 자료와 완성 코드를 실제 실행한다. |
| H | 전 범위 실전 은행 | D의 모든 평가 가능한 개념이 실제 적용/판단 문제에 대응하는지 확인하고 누락을 보완한다. 기존 은행을 쓰면 해당 ID 목록과 출제 유형을 명시한다. |
| I | 기출/기출형 5세트 | 공지·실제 기출 근거와 미공지 가정, 유형별 시간/배점, 세트별 단원·유형·개념 및 전체 합집합을 설계한다. 선행 검증 문항을 선별/변형하고 변형 답안·자료·해설을 다시 검산하고, 세트별 난이도·풀이 시간·문항 사이 직접 정답 단서를 확인한다. |
| J | 최종 내용·동작 검수 | 8절의 18항목과 8.2절의 보기·난이도 검토, 오답 재풀이 예외, 전 문항 화면, 수식, 실제 코드, 저장/초기화/타이머/모바일/인쇄·링크를 확인하고 발견한 오류를 수정한다. |
| K | 재생성·게시 | 원본 JSON·템플릿·빌더에서 MD/HTML을 재생성해 일치를 확인한다. 사용자가 정한 시점에 게시하며 실제 게시 파일·주소·핵심 동작까지 확인한다. |
| L | 완료 보고·다음 과목 인계 | 완료 단계·현재 개념/문항 수·검증 결과·미확인/남은 항목·원본 위치·재생성 명령·최신 검수 문서·다음 작업을 기록한다. 다음 과목은 A부터 새 자료로 시작한다. |

### 12.1 제작 원본과 수정 이력

- **단일 제작 원본**: 문항/개념/시험 메타정보·템플릿·스타일·빌더의 실제 원본 경로를 README에 기록한다. 생성된 HTML/MD와 게시 복사본을 원본으로 혼동하지 않는다. 메인 별칭 HTML을 유지한다면 동일 내용을 생성한다.
- **문항별 최소 정보**: 안정적인 ID, 유형·단원, 지문, 필요한 자료, 답안 언어, 정답/모범 코드, 모든 보기 또는 단계별 해설, 배점·기준, 인정 답안·주의점, 개념 ID, 원문 근거를 관리한다. 모의시험은 세트·번호·예상 시간·원본 문항 ID/변형 내역도 기록한다.
- **변경 전파**: 새 자료·개념·정답 교정이 생기면 원자 개념 목록 → 관련 문제·변형 → 해설·채점 → 대응표·집계·HTML → 관련 검증·최신 문서 순서로 갱신한다. 수치만 바꾼 문제의 이전 해설/배점 값을 남기지 않는다.
- **저장 기록 호환**: 문항 순서만 바뀌면 ID로 기록을 이어간다. 정답·선지 의미·문제 조건이 바뀌는 경우 데이터 버전과 이전 기록 처리 방식을 명시하고, 과거 채점 결과를 새 문항의 정답처럼 표시하지 않는다. 다른 과목·유형의 기록을 일괄 삭제하지 않는다.
- **증거의 범위**: 개념 대응표·수식 변환·실제 코드 실행·브라우저 동작·원문 재감사는 각각 무엇을 확인했는지 구분한다. 참고 자료를 받지 못한 사실이나 영상 전체를 보지 못한 사실을 ‘전수 검증’ 문구로 덮지 않는다.

### 12.2 다음 과목 시작 설정표

다음 자료를 받으면 과목별 범위/출제정보 MD에 아래 설정을 먼저 기록한다. 미공지는 `미공지`, 잠정 설계는 `연습용 가정`, 자료가 없는 항목은 `미확인`으로 구분한다. 확정하지 못한 항목과 독립적으로 진행할 수 있는 작업은 계속하되, 추정값을 공지처럼 표시하지 않는다.

| 설정 | 입력·확인할 값 |
|---|---|
| 과목·시험 구분 | 과목명·과목 경로·학기·중간/기말·출처를 구분하는 내부 키 |
| 최신 지시·공지 | 사용자 최신 요구, 공지 제목/일자/근거, 이전 공지에서 바뀐 내용 |
| 실제 시험 조건 | 일시·시간대·장소·범위·제외 범위·허용/필수 유형·준비물·계산기/참고자료 허용 여부 |
| 답안 언어·코드 언어 | 지문/설명 언어, 교안 영문 명칭 목록과 페이지 근거, 실제 코드 언어와 교과 실행 환경 |
| 강의 입력 코드 대응 | 실제 입력/출력 화면의 페이지·색상·프롬프트, 객체·열·인자·기본값, 원문 오타 교정 근거, 부분 빈칸/한 줄 작성의 목표 결과·대응 문항·문장별 설명·의미 단위 배점·허용 대안·실행 증거(17절) |
| 원문 목록·확인 범위 | 교안·전사·실습·과제·보충영상·데이터의 파일/URL·버전·쪽수/구간·확인 상태 |
| 난이도·보기 검수 설계 | 강의/공지의 난이도 근거, 평가 행위·예상 수준·시간 배분, 5.1절의 검토 기준/지표 방법·예외, 11.3절 기록 위치 |
| 개념·유형별 목표 | 원문에서 확정한 개념 기준 목록, 단계별 대응 범위, 해당 과목에 필요한 계산·자료·서술·코드 유형 |
| 시험 설계 | 확정 문항 수/배점 또는 잠정 설계 근거, 세트 수·유형 비중·문항별 시간·검토 시간·총점 |
| 제작 원본 | 실제 JSON/개념 목록·템플릿·스타일·빌더·시험 메타정보와 생성되는 MD/HTML 경로 |
| 상태 저장 | 과목·시험·은행별 저장 키, 문항/보기/데이터 버전, 이전 답안 보존·변경 처리 |
| 자료·실행 환경 | 그림·수식 엔진·준비 데이터·fixture·패키지, 실제 실행기와 버전, 실행/재생성 명령 |
| 검증·게시 경로 | 검증 스크립트의 대상 URL/폴더·결과 출력 위치, 게시 복사본·상대 링크·원격 저장소/게시 경로 |
| 제작 순서·진행 현황 | 이번 요청 단계, 단계별 완료 조건·미완료 항목, 사용자가 정한 게시 시점, 최신 검수 문서 |

**레퍼런스 복사 시 추가 확인:** 인터랙티브심리학 빌더/검증 코드에는 `188개 개념`, `160문항`, `32문항/세트`, `100점`, `7200초`, R 전용 검증과 원본 파일명이 들어 있다. 이는 해당 과목의 검증값이므로 다음 과목에서는 새 기준 목록·시험 메타정보·언어·원본 경로로 바꾼다. 화면의 숫자만 고치거나 맞지 않는 검사를 삭제해 통과시키지 않는다. 이전 과목의 결과 JSON·캡처를 새 과목 검증 증거로 복사하지 않는다.

### 12.3 자료 → 개념 → 노트 → 문제의 양방향 대조

- **원문 목록 표**: `자료 ID | 원본 파일/URL·버전 | 페이지/구간 | 포함·제외·미확인 및 근거 | 추출/그림 확인 상태 | 연결 개념 ID`를 기록한다. 제외·표지·행정 안내처럼 개념이 없는 부분도 이유를 남겨 원문 구간이 조용히 사라지지 않게 한다.
- **개념 대응표**: `개념 ID | 원문 위치 | 개념 노트 위치 | 공식/조건/단위·예제·빈칸 | O/X | 다지선다 | 주관식/코드 | 전 범위 실전 | 모의시험 세트/문항`을 연결한다. 수식·코드가 없는 개념에는 무관한 문제를 만들어 넣지 않고 적절한 다른 유형으로 평가한다.
- **정방향**: 범위 내 원문 구간이 개념 목록과 노트에 빠짐없이 반영됐는지 확인한다. 그림 속 글자·캡션·교수 강조·실습 입력·보충학습도 대조한다.
- **역방향**: 노트·문제의 개념과 수치·자료가 어느 원문/연습용 구성자료에 근거하는지 확인한다. 출처가 없는 주장·범위 밖 내용·ID만 붙인 문제를 제거하거나 명시적으로 보완한다.
- **문제 내부 대조**: 지문·제시자료·정답·해설·채점 기준의 기호·값·단위·표기·판정 조건을 함께 확인한다. 전체 은행과 세트별 배점/시간/유형/개념 집계를 최종 배열에서 재계산한다.
- **충돌 처리**: 일정·범위·유형은 최신 공식 시험 공지를 따르고 사용자 최신 제작 지시를 반영한다. 교안·전사·원본 데이터·출력이 다르면 원문과 교정/해석을 구분한다. 계산은 문제에 명시한 데이터 버전을 기준으로 검산하며, 교안의 설명 모형과 일반 이론을 서로 바꾸어 출제하지 않는다.
- **미확인 처리**: 읽지 못한 원문·확보하지 못한 자막/화면·실행하지 못한 코드는 해당 상태와 범위를 기록한다. 기존 개념 목록의 ID 누락 0과 원문 전체 재감사 완료를 구분한다.

## 13. 사용자 요구와 제작 기준의 누락 대조

다음은 공통 기준의 **정의가 빠지지 않았는지** 확인하는 대조표다. 표가 있다는 사실은 다음 과목의 실제 제작·검수가 완료됐다는 뜻이 아니다.

|---|---|
| 기존 데이터마이닝 디자인 유지 및 디자인 MD | 02번 가이드 2~8·12절 |
| 원문·보충학습을 포함한 무누락 개념 정리 | 이 문서 2·9·12절, 원문-개념-노트 대응표 |
| 실제 학부 시험 수준의 난이도와 보기 형식 | 이 문서 4.3·5.1~5.2·8.2절, 11.3절 기록 양식 |
| 길이·어조·무관한 오답·정답 개수로 드러나는 단서 차단 | 이 문서 5.1~5.2·8.1~8.2절, 02번 가이드 6.1~6.2절 |
| 보기 수정 후 유일 정답·해설·채점·기출형 동기화 | 이 문서 5·8.2·12.1절, 문항/보기 ID별 대조 |

## 14. 계산기 없는 시험의 계산 문항 기준

계산기 허용 여부는 새 과목의 공지와 사용자 확인을 구분해 기록한다. 계산기 없이 응시한다면 학부 수준의 개념·조건 판단은 유지하면서 불필요한 소수 연산 부담을 줄인다.

- 등확률 로그는 2의 거듭제곱 대안 수를 활용한다. 비등확률 엔트로피·Fitts처럼 로그가 필요하면 **문제 안에 필요한 로그 근삿값을 제공**한다. 로그를 모두 제거하거나 정답 값을 직접 알려 주지 않는다.
- 제시 로그는 대체로 소수 첫째 자리로 구성하고 ‘제시 근삿값을 그대로 사용’하도록 명시한다. 중간 계산은 반올림하지 않고 마지막 답에서만 정해진 자리로 반올림한다. 제시값 기준 결과와 고정밀 실제 로그 결과를 섞지 않는다.
- 처리율·회귀의 비율/F처럼 나눗셈이 길어지는 경우 **정확한 분수 또는 최종 소수 첫째 자리**를 인정한다. 지문·모범답안·항목별 채점 기준·대안 인정 범위를 일치시킨다. 모든 비율을 소수 첫째 자리로 강제해 정보가 사라지게 하지 않는다.
- 표본 수는 계산 과정의 소수를 유지한 후 필요한 총 인원을 최소 정수로 올린다. 파일럿을 포함하는지, 추가 인원인지 총 인원인지 문제에 명시한다. 표본분산의 분모, 단위 환산, 로그 인수, 잔차의 부호 등 평가할 개념은 유지한다.
- 표준편차·회귀 직접 계산은 작은 표본과 단순한 정수/분수 자료로 구성한다. 무리한 로그·제곱근·다자리 소수 계산이 답안의 주된 부담이 되지 않도록 실제 손풀이 경로와 예상 시간을 확인한다.
- 강의 원문 또는 **실제 분석 출력의 p값·유의수준·확률·계수는 일괄 소수 첫째 자리로 바꾸지 않는다.** 판독용 자료는 유의성·해석에 필요한 정밀도를 유지한다. 코드 출력은 실제 실행 결과를 따른다. 코드로 계산하는 값과 손계산 제시 근삿값은 구분한다.
- 수치를 변형했다면 원문 예제와 연습용 구성자료를 출처에 구분한다. 원본 은행 → O/X·주관식·기출형 변형 → 모든 보기·해설·배점 → MD/HTML → 실제 코드 실행·수치 검증을 함께 갱신한다.
- 변경 전후 문항과 ID·정답 집합·배점·개념 대응을 기록한다. 변경된 연습 답안은 별도 보관 후 해당 문항만 갱신한다. 진행/제출 시험은 이전 문항·해설·답안·채점·마감 시각을 유지하며 새 응시에서 새 버전을 적용한다. 버전 메타정보는 시험 답안 원본 밖에 두고 저장 실패·새로고침·다중 탭에서도 검증한다.

인터랙티브심리학 적용 사례는 [손계산형 문항 검수](../interactive-psychology-midterm/24_손계산형_문항검수.md)에 있다. 이 과목의 숫자·문항 수·배분을 다음 과목의 고정 기준으로 복사하지 않는다.

## 15. 세부 표·그림·옵션과 직접 빈칸 인출 검수

개념 ID가 한 문항에 연결됐다는 사실만으로 그 개념의 모든 평가 요소를 출제했다고 판단하지 않는다. 각 개념군을 **명칭·정의·구성요소·순서·기호/수치·단위·공식의 조건·그림/표 판독·코드 인수/값·출력 항목·오류 진단**으로 분해하고, 해당하는 평가 요소별 문항 ID와 실제 답안/채점 위치를 기록한다.

- 표·그림·스크린샷 속 글자와 범례도 원문에 포함한다. 텍스트 추출에 빠진 대응표를 이미지로 직접 확인한다. 설치 클릭 순서·행정 정보·우연한 파일명을 기계적으로 모두 시험 문제로 늘리지 않는다.
- 코드의 함수 하나만 물었다면 인수 이름·허용 값·의미·숫자↔이름 대응·그림 결과가 충분히 평가되는지 따로 확인한다. 예를 들어 R `lty=1`만으로 선 종류 0~6 전체를 출제한 것으로 표시하지 않는다.
- 직접 회상과 보기 기반 판별을 구분한다. 서술 답안 속에만 들어 있거나 객관식 보기에서만 알아볼 수 있는 중요 명칭·조건·표의 행/열은 빈칸 단답으로도 준비한다. 모든 개념에 부적합한 모든 유형을 억지로 적용하지는 않는다.
- 빈칸 번호와 입력칸·모범답안·상세 해설·부분점수는 1:1로 대응한다. 수식은 수식 기능, 코드는 실제 구문·들여쓰기를 지킨다. 입력·새로고침 복원·수정 후 채점 해제·초기화·오답 재풀이·제출 잠금을 직접 검증한다.
- 그림에 정답 이름·번호 대응·해석을 남기지 않는다. 필요한 도식 전체와 자료 조건은 제공하되 요청한 판단을 캡션·alt·주석·제목에서 미리 알려 주지 않는다. 관련 없는 이미지를 넣지 않는다.
- 언어는 원문을 따른다. 교안 영어 명칭과 실제 코드 표기만 영어로 요구하고, 한글 개념을 임의 번역하는 빈칸은 만들지 않는다. 숫자와 문자열의 구문상 동등성은 실제 실행/렌더링으로 확인한다.
- 기출형에도 반영하되 시험 시간·문항 수·배점·유형·단원·개념 합집합을 재검증한다. 바뀐 시험은 버전별 문항·답안·해설·마감 시각을 보존하고 새 응시에 새 버전을 쓴다.

세부 검수 표: `자료/쪽 | 개념군 ID | 평가 요소 | 직접 회상/판별/계산/코드/자료 해석 | 기존 문항과 실제 채점 항목 | 부족한 유형/내용 | 보완 ID | 정답 단서·실행·UI 재검증`을 남긴다. **기존 개념군 누락 0**, **세부 요소 검토 완료**, **새 원문 전체 재감사 완료**는 서로 다른 주장으로 보고한다. 다음 과목에는 해당 자료로 새 목록을 만들며 기존 과목의 개수나 결과를 복사하지 않는다.

인터랙티브심리학의 실제 보완은 [25번 세부 빈칸 검수](../interactive-psychology-midterm/25_세부항목_빈칸단답_검수.md)와 문항별 JSON을 참고한다.

## 16. 실제 대학 시험형 서술 문항의 초점과 요구량

서술형은 **한 문항에서 한 가지 핵심 이해·판단을 평가**한다. 개념의 수를 많이 붙이거나 장문의 목록을 쓰게 하는 것으로 난이도를 높이지 않는다. 대학 학부 수준은 강의에서 다룬 원리의 이해, 사례의 구별, 자료에 근거한 해석, 짧은 계산과 그 의미로 구현한다. 다음 기준은 단계 4의 서술형과 단계 5~6의 모든 복제·변형 문항에 함께 적용한다.

1. **범위를 먼저 좁힌다.** 역사는 한 시기의 변화나 의미를 묻는다. 여러 시대 전체·연대·기관·최근 동향을 한 문항의 필수 답안으로 묶지 않는다. 실험은 한 실험·한 결과·명확한 비교에 초점을 맞춘다.
2. **요구 사이의 연결을 확인한다.** 핵심 판단과 이를 뒷받침하는 이유는 함께 물을 수 있다. 회귀식과 그 식으로 구한 예측·잔차처럼 같은 추론에 속하는 요구도 가능하다. 별개 연구의 해석, 관련 없는 개선안, 모든 유형의 분류·목록은 독립 문항으로 분리한다. 같은 단원이라는 사실만으로 요구들이 연결되는 것은 아니다.
3. **‘개념→사례→적용→한계’를 모든 문항에 강제하지 않는다.** 고릴라 실험에서 주의의 특성을 묻는다면 그 실험을 명확히 제시하고 이유를 설명하게 한다. 별도의 관제 화면 설계나 막연한 ‘입증하지 못한 주장’까지 덧붙이지 않는다. 비평을 요구하려면 평가할 주장과 그 근거 자료를 지문에 특정한다.
4. **완결된 자료만 제시한다.** 질문에 필요한 자극·지시·조건·관측값·지표·단위를 제공한다. 질문과 별개인 표·그림·논문 결과는 제거한다. 도식과 실제 데이터, 서로 다른 연구의 결과를 구분한다. 학생이 추론할 결론은 캡션에 미리 써 주지 않는다.
5. **답안과 채점도 함께 줄인다.** 질문을 짧게 고친 뒤 예전 모범답안·배점에 긴 목록을 남기지 않는다. 요구한 판단과 근거에 점수를 배정하고 항목별 부분점수를 명시한다. 질문에 없는 연도·기관·용어·코드·추가 사례를 쓰지 않았다고 감점하지 않는다. 표현이 달라도 같은 의미면 인정하며 연쇄 산술 오류를 중복 감점하지 않는다.
6. **범위 보존은 문제은행 전체에서 한다.** 문항에서 덜어 낸 중요 내용은 별도 서술형·빈칸 단답·객관식·코드 중 적합한 위치로 옮기고 그 ID를 기록한다. 줄인 문항에 옛 conceptIds를 그대로 붙여 무누락으로 표시하지 않는다. 개념군 대응과 세부 회상 항목을 각각 대조한다.
7. **분량과 배점은 답안 작업량으로 검토한다.** 한 문항에 쓰게 될 모범답안을 먼저 실제로 작성해 읽기·생각·계산·서술 시간을 추정한다. 보통 짧은 한 단락으로 핵심을 설명할 수 있는지 확인한다. 문장 수·배점·채점 항목 수를 고정된 난이도 지표로 쓰지는 않는다. 총 시험 시간에 맞추려고 무관한 과제를 억지로 묶지 않는다. 예상 시간은 실제 학생 측정치와 구분한다.
8. **은행과 기출형을 함께 보완한다.** 지문·자료·답안·해설·감점·배점·언어 지시·출처를 한 묶음으로 갱신한다. 변형 수치는 재검산한다. 진행·제출 시험에는 원래 문항과 답안을 유지하고 새 응시부터 바뀐 문항을 적용한다. 변경 연습 답안은 먼저 보관하고, 변경되지 않은 학습 기록은 유지한다.

### 16.1 문항별 검토 기록과 완료 조건

기존 ID, 새 평가 초점, 과도하거나 무관했던 요구, 분리한 내용의 새 위치, 필요한 자료, 모범답안과 배점의 대응, 기출형 반영 ID, 수치 검산, 화면·이전 답안 보존 결과를 기록한다. 문항당 핵심 질문을 한 문장으로 설명할 수 있는지 직접 읽어 검토한다. 자동 검사 통과를 내용의 적절성이나 실제 변별도의 증명으로 대신하지 않는다.

검수 예: ‘UX·HFE의 모든 시대와 기관·최신 동향’을 ‘1945~1960년 전문 학문 형성의 의미’로 좁힌다. ‘고릴라 결과+관제 설계+불명확한 미입증 주장’을 ‘패스 세기 과제 중 고릴라를 놓친 이유’로 바꾼다. 분산분석 계산은 회귀식 계산과 별도 문항으로 훈련한다. 구체적인 로컬 보완 기록은 [인터랙티브심리학 서술형 검수](../interactive-psychology-midterm/26_서술형_문항검수.md)를 따른다.

**게시 조건:** 사용자가 마지막에 푸시를 요청하기 전에는 로컬 제작·검수까지만 진행한다. 앞선 단계의 게시 허용을 새 수정의 푸시 허용으로 해석하지 않는다.


## 17. 강의의 실제 입력 코드와 한 줄 작성 검수

- 본문의 설명용 코드와 **실제 콘솔에 입력한 코드**를 구분해 읽는다. 텍스트 추출에서 빠진 화면 캡처도 눈으로 확인한다. 해당 강의의 파란 텍스트는 입력 코드이고 검정 결과는 출력이다. 색상 규칙은 과목 자료를 확인한 뒤 적용한다.
- 실행 가능한 강의의 객체명·열 선택·함수 호출·인자 순서·기본값을 기본 모범답안으로 쓴다. 예를 들어 강의에서 `t.test(data=datat, height ~ group, var.equal=TRUE)`와 `datadiff = datat2$after - datat2$before` → `shapiro.test(datadiff)` → `t.test(datadiff)`를 썼다면 그 형태를 우선 훈련한다. `<-` 대입, 이름 붙은 인자 순서, 명시적인 `mu=0` 등 같은 동작을 하는 유효한 R 표현은 인정한다.
- 본문 `Sort`·`True`·휘어진 따옴표처럼 실행되지 않는 오타는 맹목적으로 복제하지 않는다. 실제 입력 화면과 실행 결과를 대조하여 `sort`·`TRUE`·일반 따옴표 등으로 고치고 수정 근거를 기록한다. 입력 프롬프트 `>`는 R 문장 밖에 표시한다.
- 한 줄 작성은 함수·괄호·인자 일부가 미리 주어지지 않은 입력란을 사용한다. 객체·데이터·조건과 목표 출력은 문제에 제공하고, 목표를 달성하는 전체 호출 또는 대입을 직접 구성하게 한다. 준비 코드가 이미 실행되었는지, 패키지가 설치/불러오기 되었는지 명확히 한다.
- 정렬 결과에서 특정 순서의 원소를 고르는 코드, 열 추출과 저장, 기초통계, 조건 행 선택 후 정규성·단일표본·등분산·독립표본·대응표본 검정, 회귀 등 강의의 주요 입력 문장을 직접 작성하도록 분산한다. 한 문항은 원하는 결과 하나에 초점을 맞춘다.
- 함수·자료·인자·비교 방향의 역할을 코드 **문장별로** 해설한다. 빈칸의 정답을 나열하는 것만으로 설명을 대신하지 않는다. 기본값의 생략과 의미, `=`와 `==`, `$`와 `[행, 열]`, 포뮬러 방향, 문자열·논리형 대소문자를 해당 문장에 연결한다.
- 채점은 같은 결과를 내는 유효한 대안을 인정하는 의미 기준으로 설계한다. 웹에서 코드의 의미를 자동 판정한다고 표시하지 않는다. 한 줄 모범답안·준비 자료·동등 대안은 실제 언어 실행기로 실행하고 출력·모형 유형·객체·조건·그래프를 확인한다. 불러오기 문제를 검증하면서 불필요하게 패키지 설치를 실행하지 않는다.
- 한 줄 작성도 입력→저장→새로고침→해설→부분점수→오답 탭 재풀이→현재 문항 초기화를 직접 확인한다. 한 줄을 임의로 접지 않고 편집창 안에서 가로 스크롤한다. 숫자만 입력하거나 함수명만 적는 답안과 완전한 문장 작성을 구별한다.
- **문항별 기록 표**는 `강의 파일/페이지·입력 화면 → 원하는 결과·준비 상태 → 모범 문장 → 문장별 설명 → 채점 항목/점수 → 유효 대안 → 실제 실행 결과 → 은행/기출형 대응 ID`로 연결한다. 입력 소스와 설명용 의사코드를 구별하고, 원본과 변형의 객체·조건 차이는 각 문항에 기록한다.
- **채점 예시:** Deagu의 키를 기준 평균 150과 비교하는 한 줄은 `t.test(datat[datat$group == "Deagu", ]$height, mu = 150)`다. 2점 문항이면 집단/열 선택 1점, 올바른 양측 단일표본 호출·기준 평균 1점처럼 평가한다. 공백·유효한 따옴표·이름 붙은 인자 순서나 `alternative="two.sided"` 명시는 감점하지 않는다. 실행을 막는 오타는 영향을 받은 항목에서 처리하고 같은 오류를 모든 항목에 중복 감점하지 않는다. 지문에 없는 출력 해석을 채점표에서 추가로 요구하지 않는다. 실제 배점은 다음 과목의 요구와 작업량에 맞춘다.
- 줄 배치·설명만 바꾼 문항은 기존 답안을 유지한다. 빈칸 의미·변수 기대·전체 문장 작성처럼 답안 구조가 달라지면 이전 답안을 먼저 보관하고 그 문항만 새로 시작한다. 진행·제출 시험은 당시 버전의 문항과 점수를 유지한다.

최신 적용 사례는 [강의형 R 입력·한 줄 작성 검수](../interactive-psychology-midterm/27_R_강의형입력과_한줄작성_검수.md)다. 이 과목의 문항 수·R 표기·코드 색상·실행 검사 수를 다음 과목의 고정 조건으로 복사하지 않는다.


## 18. 시험 직전 압축 정리본 제작 기준

- 사용자가 요청한 시간에 맞춰 하나의 읽기 경로를 설계한다. 예를 들어 60분이면 방법 판별·대표 손계산·출력 해석·코드 직접 회상·마지막 점검에 시간을 나누되, 이 배분은 편집상 권장 경로이며 실제 시험의 출제 비중이나 측정된 학습 시간이 아니다.
- 개념명을 늘어놓는 대신 **문제의 단서 → 선택할 개념/방법 → 답안을 쓰는 절차 → 검산/감점 지점**으로 묶는다. 모든 큰 단원을 연결하되 전체 원문을 압축본 하나로 완전 대체한다고 주장하지 않는다. 원문에서 중요도가 확인되지 않은 항목을 출제 확률이 높은 것처럼 쓰지 않는다.
- 계산에는 풀이 가능한 조건·로그 근삿값·단위·정밀도를 함께 주고 대표 예제와 검산을 넣는다. 수식은 로컬 엔진으로 렌더링하고 숫자는 독립 계산한다. 교안 실제 출력과 새 연습용 예제는 명시적으로 구분한다.
- 코드는 강의 입력 형식과 객체명을 유지한다. 결과 목표를 보고 문장 전체를 떠올리는 짧은 인출 구간과 문장별 설명을 제공한다. 새 예제·허용 대안은 실제 런타임에서 실행한다.
- 마지막 구간은 답을 가리고 바로 확인할 수 있는 짧은 혼합 점검으로 구성한다. 단답의 영문 명칭은 해당 강의 근거에 한정하고, 서술 예시는 한 가지 초점에 대한 짧은 실제 답안으로 제시한다.
- 기본 자료와 구분되는 진입 링크를 두고, 화면/인쇄에서 수식·표·코드·해설이 모두 읽히는지 확인한다. 인쇄 시 접힌 해설을 누락하지 않으며 기존 문제은행의 답안·타이머·재풀이 기록을 변경하지 않는다. 압축본을 추가했다는 이유로 시험 문항 수·배점을 공지처럼 확정하지 않는다.


### 압축본 누락 재검수와 계산 검산 보완 (2026-10-19)

압축본은 원자 개념뿐 아니라 독립 출제 가능한 세부 항목·유형(순서/표/그림 라벨, 직접 손계산, 코드 부분 빈칸/전체 문장, 실습 전처리·조건별 회귀)을 대조한다. `개념/유형 → 압축본 위치 → 실제 근거 문구 → 부족/보완/확인`을 기록하고, 이름만 존재하는 것을 설명 완료로 처리하지 않는다. 계산 검산은 주어진 근삿값을 대입하는 데서 멈추지 않고 로그의 밑·인수·근삿값 자체가 맞는지 실제 함수값으로 확인한다. 예를 들어 log₂5≈2.3과 log₂6≈2.6을 구별한다. 한 문제당 시간·단위의 기울기는 반응시간 증가량/독립변수 증가량으로 계산한다. 이전 출제·코드 기준은 시험 분량 확장 시에도 유지하고, 기존 응시 기록은 확장 전후의 실제 문항·정답·점수·마감 시각으로 보존한다.
