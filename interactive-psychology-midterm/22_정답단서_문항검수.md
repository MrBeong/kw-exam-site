# 정답 단서 제거와 문항 보완 검수

검증일: 2026-10-17. 사용자 제보 문항(SA002·ME2-Q19)의 정답 번역 목록을 계기로 전체 589문항의 물음·지문·보기·자료·코드 설명과 복제본을 점검했다. 이번 검수는 문제의 평가 내용에 앞서 답이 드러나는지에 초점을 둔다.

## 수정 결과

총 52문항을 보완했다: O/X 3, 다지선다 8, 단답·서술·R 22, 기출형 19. 전체는 기존 188개 개념·589문항을 유지한다. 정확한 ID·변경 필드·사유는 [변경 목록](final-audit/answer-hint-changes.json)에 기록했다.

- SA002·ME2-Q19에서 인지도·태도·윤리·충성도의 한글 정답 목록을 없앴다. 제품 경험 요소, 정보처리 단계, 역사 단계명·순서, 반응 순서와 코드 빈칸 함수명도 같은 기준으로 검토했다.
- 정답 문장과 탐색 방식 라벨이 적힌 Sternberg 교안 슬라이드를 문제에 그대로 보여주지 않는다. PSS·RT 축과 YES/NO 관계를 유지한 문제용 SVG로 재구성했고, 해석은 해설에 남겼다. 원자료가 없는 도식은 실제 수치 관측으로 가장하지 않는다.
- MC097의 자료 제목에서 판별 대상인 NO 조건을 없앴다. Probe 정의를 묻는 문항에서는 열 설명이 그 정의를 먼저 알려주지 않게 했다. 일반 분석 문제에 필요한 변수 정의·단위·수집 조건은 유지한다.
- ES030은 과업 분류명을 적은 슬라이드 대신 실제 두 과업의 첫/최대 정점 시각을 표로 제시한다. 분류·비교는 답안에서 수행한다.
- MC021은 설계 특징을 정답 보기로 복사하는 방식에서 신체 부담·방향 판단·결과 피드백을 연결하는 해석 문제로 보완했다. ME4-Q08에서 구하라고 한 Hmax를 지문에 미리 계산해 둔 부분도 제거했다.
- ES039·ME4-Q28에는 계산 대상과 무관한 12행 회귀 출력 대신 각 문항의 실제 관측 3쌍만 제공한다. 수치 변형의 값은 서로 바꾸지 않았다.
- 물음에 맞춰 ES006/ME1-Q25의 세 연구 유형 명칭, ES032의 개념 양립성, ES020의 대표 수치, ES025의 사전 경고 예시를 모범답안에 명시했다. ES014에서 이미 요구하던 중복도 27.8%의 누락된 답안·채점 기준도 보완했다.
