# 원문 보존과 검증 메모

최근 확인일 2026-10-07. 사용자가 붙여넣은 전사는 보존하고, 교안 PDF·엑셀·논문·실습 로그와 대조 가능한 지점만 검증했다. 원본 영상/녹음·시간코드는 제공되지 않아 발화 자체의 확인은 미완료다. 아래 수정은 학습 파트너의 설명이며 원문/원문 정답을 덮어쓰지 않는다.

| 항목 | 원문 위치·내용 | 대조 근거·판정 | 공부할 때 사용할 설명 |
|---|---|---|---|
| 화자 이름 | 정보처리 전사 1–2는 `김연경`, 후속은 `김현경` 등 | PDF 표지 `Hyunkyung Kim`. 자동 전사의 이름 인식 오류 가능, 음성 미확인 | 강의자 표기를 전사마다 임의 통일하지 않음. |
| BMI 단위 | HFE 교안 p.5 BMI 식의 치수 표현이 불명확 | kg/(m²)가 차원적으로 일치 | `BMI=체중(kg)/키(m)²`, kg/m². |
| 표본 수 입력 | 연구방법론 전사 1 말미 평균 5/SD 100처럼 인식 | HFE 교안 p.19와 전사 2는 평균 100, SD 10, 파일럿 5명 | α=.05, k=.05에서 n=15.3664→총16명, 추가11명. 원문은 전사 오류 의심. |
| 스마트글래스 오차막대 | HFE 전사 1의 분산·오차막대 설명 | HFE 교안 p.10에 `SE` 표시 | SE는 평균의 표준오차, SD는 관측값의 퍼짐. 동일 개념 아님. |
| 표본 수 경험칙 | HFE 교안 p.17/전사 2의 30명, 9–11명 언급 | 연구 질문/분산/목표 정밀도에 따라 필요 수가 달라짐 | 보편적 최소 표본 수로 외우지 않음. |
| 정보량 Venn 기호 | 정보처리 교안 p.15–16의 `H(X∩Y)`, `H(X∪Y)` 그림 | 확률 정보량의 표준 계산식은 `I(X;Y)=H(X)+H(Y)−H(X,Y)` | 시험 계산에는 공동·조건부 엔트로피 정의 사용. 그림 기호를 그대로 숫자 연산하지 않음. |
| Sternberg 탐색 | 정보처리 교안 p.31 YES self-terminating, NO exhaustive | [Sternberg의 원 논문 기록](https://pubmed.ncbi.nlm.nih.gov/5939936/)은 고전 기억탐색 과제의 serial exhaustive 해석 근거. 특정 조건마다 달라질 수 있음 | 시험에서 교안의 분류를 묻는다면 원문을 정확히 쓰되, 일반 이론 설명에서는 고전 결과와의 차이를 명시. |
| Hick 기울기 단위 | 정보처리 교안 p.35 b를 처리 `rate`로 기술; 전사 3의 초/ms 인식 불일치 | `RT(ms)=a(ms)+b(ms/bit)H(bit)` | b는 bit당 시간, `1/b`가 bit/s 차원. `b=150 ms/bit`이면 역수 약6.67 bit/s. |
| Fitts 논문 참가자 | 피츠 전사의 `3명`으로 인식된 구간 | 보충 논문 p.4는 23명 | 논문 실험은 23명. 전사 원문 보존. |
| 회귀 모델 인과 해석 | 회귀 전사의 X가 Y에 `영향` 표현 | 자료는 관측 상관·회귀 예시 | 회귀계수는 조건부 평균의 연관/예측, 단독으로 인과 증명 아님. |
| 회귀 데이터 9번째 X | 교안 p.21은 X₉=55 | 엑셀 `Sheet1!C10=65`, Y₉=81. 교안 p.25 R 출력은 엑셀 버전과 일치 | 엑셀: b₀=30.9333,b₁=.870476,R²=.682814,F=21.5273; 인쇄 표: b₀=30.0433,b₁=.897214,R²=.743828,F=29.0363. 문제에 쓰인 자료 버전을 우선. |
| ANOVA 표의 F열 | 회귀 교안 p.19의 F열에 MSR/MSE가 분리된 듯 표시 | 표준 F 정의는 MSR/MSE | 분모·분자와 자유도 `(1,n−2)`를 쓰고 계산. |
| 평균 예시 산술 | T검정 전사의 B집단 `0,100,25,75` 평균을 56으로 발화/인식 | 합 200, n=4이므로 평균 50 | 두 집단 평균은 50으로 같고 B의 표본SD만 약45.64로 큼. 원문 수치 보존. |
| R 함수 대소문자 | t-test 교안 p.3의 `Sort(...)` | p.4 화면과 R 함수명은 소문자 `sort` | R은 대소문자 구분. 시험 코드에는 `sort` 사용. |
| p>.05 표현 | t-test 교안 p.13,18,19,23의 `H0 채택` | 가설검정은 p>.05일 때 H0를 기각할 근거가 부족함 | `H0를 기각하지 못함`으로 쓰고 정규성·등분산이 증명됐다고 말하지 않음. |
| 표본 수와 정규성 | t-test 교안 p.13,17의 `관측 20개 이상이면 만족한다고 가정` | 표본 수만으로 원자료 정규성이 자동 성립하지 않음 | 수업 경험칙으로 출처를 밝혀 기억하되, 분포·이상치·설계와 강건성을 함께 판단. |
| Levene 코드 따옴표 | t-test 교안 p.19의 `location='mean’)` 형태 | R 코드는 ASCII 따옴표가 필요 | `location='mean'`으로 입력. |
| 대응검정 H0 표현 | t-test 교안 p.24의 `전/후 ... 차이의 평균은 같다` | p.21의 엄밀한 H0는 `μ(after−before)=0` | 차이 정의와 부호를 먼저 쓰고 평균차 0을 검정. |
| OLS 목적함수 | SRT/CRT 전사의 회귀선이 표준편차를 최소화한다는 취지의 설명 | 보통 최소제곱 회귀는 잔차제곱합 SSE 최소화 | 표준편차와 잔차제곱합을 구별. |
| Sternberg 로그 T/F | SRT/CRT 전사에서 true/false를 포함 여부와 정오로 혼용할 수 있는 설명 | 실제 로그는 `Number Set`, `Number`, `User Input`, `T/F`를 별도 열로 가짐 | target-present는 집합과 probe로 계산하고 T/F는 응답 정오로 해석. |
| Sternberg 실행파일명 | README.docx의 `Sternberg.exe` | 실제 원본은 `SternbergTest.exe` | 원본 이름을 바꾸지 않고 불일치만 기록. |

그림·표의 일부 작은 글씨, 전체 강의 영상과 자동 전사의 일치 여부, 보충 논문의 모든 표 수치는 미확인이다. SRT·CRT·Sternberg 강의까지가 중간 전 진도라는 교수 발언은 확인했지만 실제 출제 페이지·문항 유형은 미확인이다. 교수 설명과 보완 설명은 각 정리에서 표기했다.
