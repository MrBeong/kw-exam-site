## 공지와 설계 가정

- 확정: 2026-10-19(월) 18~20시, 1~6주차 전체, 객관식·주관식·서술식·간단한 코드 작성, 연필·지우개. 교안 영문 명칭만 영어 답안으로 요구한다.
- 미공지: 실제 문항 수·유형별 비율·배점·계산기 허용 여부(공식 공지). 사용자는 2026-10-18 계산기 미사용을 확인했다. 32개 대문항·100점은 120분에 맞춘 자체 설계이며 확정 출제 구조라고 주장하지 않는다.
- 기존 MD의 5세트 구조를 적용했다. 총160개 대문항이며 회차 사이 동일 원문 문항을 중복 사용하지 않았다. 수치·사례 및 세부 빈칸 변형 21개를 포함한다. 검증된 선행 은행에서 선별·재구성한 출처를 originId로 추적한다.
- 회차당 7개 단원을 모두 포함한다. 무누락은 5회분 전체의 기존188개 개념 목록에 대한 대응이다. 개별 회차가188개 전부를 시험한다는 뜻이 아니다. 원본 교안 전체를 새로 재감사한 것으로 표시하지 않는다.

## 시간·배점

단일15분 + 복수8분 + O/X2분 + 단답12분 + 서술48분 + R25분 = 풀이110분. 검토10분을 더해120분이다. 난이도는 용어 인출·조건 판별·표/그래프 판독·연쇄 계산·한계 해석을 섞은 학부 수준이다. 실제 학생 응시로 측정한 소요시간은 아니므로 시간 배분은 권장치다.

총점100=객관식36+주관식64다. 객관식은 확정 채점, 주관식14문항은 기준 체크 후 채점 완료를 직접 확정한다. 미채점이 남으면 최종 총점으로 표시하지 않는다.

## 변별력·보완 조건

- 보기마다 정오 이유와 올바른 조건·계산을 기록했다. 단일선택의 정답 위치는 세트마다1~4번 각3회로 균등 분산했다. 복수선택은2~3개 정답을 독립적으로 판별하도록 했다.
- p값 비기각과 가설 증명, R²와 미래 정확도, 신뢰도와 타당도, 모호도와 잡음, 자극 식별과 반응 선택, ISO형 +1 위치, 표본분산 분모·단위, 회귀 잔차 부호를 구별한다.
- 혼동행렬·OLS 관측표·회귀 출력 등은 문항 전체의 입력 조건을 포괄한다. 5세트 모두 그림·표가 포함된다.
- R은 직전 단계의 Source 편집창 렌더러와 스타일을 재사용한다. 함수 인자2칸 들여쓰기·문법 색상·줄 번호·코드 빈칸을 유지한다.
- 시험 모드는7200초 종료시각을 저장해 새로고침 후에도 시간이 계속 흐른다. 제출·시간 종료 전에는 해설 UI를 제공하지 않는다. 주관식은 의미·R 실행을 자동 채점하지 않는다.
