### 8. 1주차 보충학습 영상 심화 (Old computer · Gen Z Vs Old Technology · 2000s Tech) — 3문항 (`OX186` ~ `OX188`)

- **OX186 (정답: X)** — 1주차 보충영상(`TEENS REACT TO WINDOWS 95`)과 교안의 `Old computer` 사례에서, MS-DOS의 명령줄 인터페이스(CLI)는 화면의 시각적 아이콘을 보고 선택하는 재인(Recognition) 기반이어서 Windows 95의 그래픽 사용자 인터페이스(GUI)보다 작업기억의 회상(Recall) 부하가 낮았다.
  - **해설**: MS-DOS(CLI)는 정확한 명령어를 장기기억에서 직접 회상(Recall)해야 해 인지 부하가 높았고, Windows 95 GUI는 `Start` 버튼·아이콘 등 시각적 단서를 통한 재인(Recognition)을 지원해 부하를 낮추었다(`1-2 교안 p.5 · 보충영상 PSY-L001`).
- **OX187 (정답: O)** — 1주차 보충영상(`Gen Z Vs Old Technology`)에서 Z세대가 3.5인치 플로피 디스크(오늘날 ‘저장’ 아이콘의 원형 실물), VHS 비디오테이프, 숫자키 하나를 여러 번 눌러 알파벳을 입력하는 Nokia 피처폰(Multi-tap 방식) 조작에 어려움을 겪은 것은 행동유도성(Affordance) 지각과 집단 고정관념(Population Stereotype)이 사용자의 사전 경험(Previous Experience)과 시대적 맥락에 따라 달라질 수 있음을 보여준다.
  - **해설**: 물리적 슬롯·버튼이 있더라도 과거 사용 경험(`Previous Experience`)과 내재화된 심성모형이 다르면 직관적 조작 기대(`Population Stereotype`)가 형성되지 않아 시행착오가 발생한다(`1-2 교안 p.6 · 보충영상 PSY-L002`).
- **OX188 (정답: X)** — 구형 기기가 켜지거나 검색 결과가 표시되는 것만으로 모든 웹·영상 편집 과업의 사용성이 검증되었다고 볼 수 있다는 주장.
  - **해설**: 실제 페이지 열기·과업 완료, 별도 PS2 메모리카드, 문자 입력·영상 편집 부담까지 평가한다. 성공한 게임·문서 과업도 고려하고 특정 기기 고장과 설계 제약을 구분한다. 영상에 없는 지도·길찾기를 근거로 삼지 않는다.
