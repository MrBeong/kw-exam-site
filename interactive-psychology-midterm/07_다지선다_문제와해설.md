2. 실제 결제 과정은 성능 평가로 분리하고, UX 조사에는 기대와 사용 후 공유를 반영한다.
3. 사회적 공유는 사용 후 효과로 분리하고, UX 조사에는 구매 전 기대와 결제 과정을 반영한다.
4. 구매 전 기대·사용 과정·사용 후 공유를 조사해 개인·사회 맥락을 함께 반영한다.

**정답: 4번**

- 1번 ×: 구매 전 기대도 UX 범위에 속한다. 마케팅에서 자료를 얻더라도 UX 분석에서 제외할 근거는 아니다.

- 3번 ×: 사용 후 공유와 사회적 맥락도 경험 형성에 관여하므로 조사 범위에 포함한다.
- 4번 ✓: UX는 사용 전·중·후를 포괄하며 사용자의 개인적·사회적 맥락도 포함한다.

2. 고릴라의 인식 실패를 줄이려면, 패스 세기에 더 집중하도록 지시하는 방법이 우선이다.
3. 중앙 자극을 놓쳤으므로, 이 결과는 선택적 주의보다 시각 수용기의 감도 저하를 지지한다.
4. 과업에 주의를 배분하면 다른 자극이 시야에 있어도 의식적으로 놓칠 수 있다.

**정답: 4번**

- 1번 ×: 한 과업을 수행했다는 사실이 예상 밖 자극에도 충분한 주의가 배분됐음을 뜻하지 않는다.
- 2번 ×: 같은 과업에 집중을 더 요구하면 다른 자극의 탐지를 보장하지 못한다. 과업 요구와 경보 설계를 함께 검토한다.
- 3번 ×: 이 결과만으로 감각기관의 손상을 추론할 수 없다. 주의와 의식적 인식의 한계를 구분해야 한다.
- 4번 ✓: 제한된 주의를 패스 세기에 투입한 동안 예상하지 못한 자극의 인식이 실패한 사례다.
