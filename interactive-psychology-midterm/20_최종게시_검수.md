# 최종 게시 검수 · 오답 재풀이

검증일: 2026-10-17. 사용자 최종 요청에 따라 전체 시험대비 자료를 점검하고 GitHub 게시용 폴더를 구성했다.

## 오답만 다시 풀기

- O/X·다지선다·단답/서술/R·기출형의 **오답 탭 안에서만** 버튼을 표시한다. 전체·미응답·북마크 탭에서는 숨긴다.
- 정답·미채점 문항을 섞지 않는다. 단답/서술/R의 `애매함`은 별도 검토 상태이며 오답 재풀이에서는 `다시 풀기`만 대상으로 삼는다.
- 기존 답안의 보관본을 만든 뒤 새 답안·닫힌 해설로 시작한다. 진행·입력·현재 문항은 자동 저장하며 새로고침해도 이어진다.
- 다시 해결한 문제는 다음 재풀이 회차에서 제외한다. 다른 상태 탭으로 나가거나 종료하면 미채점 문항은 이전 답안으로 복원한다.
- 기출형은 5세트의 최신 오답을 모아 연습 모드에서 다시 푼다. 제출한 시험 답안·점수는 변경하지 않으며 진행 중인 시험에서는 재풀이를 시작하지 못한다.
- 기출형의 1초 타이머 갱신 때 재풀이 입력을 반복 삭제하던 경로, 채점 기준 변경 후 미확정 상태가 되지 않던 경로, 다른 탭 저장 후 재풀이 보관본을 놓치던 경로를 수정했다.
- 오답 재풀이 직접 링크가 초기화 중 선언되지 않은 값을 참조하던 오류를 수정했다. 직접 링크는 한 번만 처리하므로 재풀이 종료 후 새로고침할 때 다시 초기화하지 않는다.

개념 범위는 기존 강의 대조 목록을 기준으로 한다. 실제 시험의 문항 수·배점은 공지되지 않아 120분·32문항·100점의 자체 제작 예상시험 5세트를 구성했다. 주관식과 R 입력의 의미는 자동 채점하지 않으며 공개된 상세 기준으로 자기채점한다. R 모범답안은 실제 R에서 별도로 실행 검증했다. 보충영상은 확보한 자막과 메타데이터를 기준으로 대조했고 전체 영상 프레임의 수동 검수로 확대해서 주장하지 않는다.
