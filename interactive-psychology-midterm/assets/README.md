# 시험대비 수식 렌더링

MathJax 3.2.2의 tex-svg 엔진과 Apache 2.0 LICENSE를 mathjax/에 함께 보관한다. 네 개 학습 화면은 study-math.js / study-math.css를 공통 사용하며 네트워크가 없어도 수식을 표시한다.

- 문제의 지문·보기·모범답안·해설·채점 기준에 TeX 인라인 또는 표시 수식을 직접 작성한다.
- study-math.js는 문제를 바꾸거나 해설을 열 때 새 수식을 처리한다. 수식 언어를 추측해 R 코드를 변환하지 않는다.
- R의 $ 열 선택 문법을 보존하기 위해 웹 수식 구분자는 역슬래시 괄호/대괄호만 사용한다. code·pre·textarea·선택 메뉴·R 편집창은 수식 처리에서 제외한다.
- 긴 수식은 해당 줄 안에서 가로 스크롤한다. 전체 페이지나 R 편집창의 들여쓰기를 바꾸지 않는다.
- HTML을 직접 고치기 전에 각 은행의 questions.json과 template/app/build 원본을 수정하고 build.py를 실행한다.

수식·수치 검산 및 재생성 기준은 ../17_최종검수.md를 따른다.
