# 교안 영문 용어와 답안 언어 기준

기준일: 2026-10-17 · 사용자 최신 지시 반영

**강의자료에서 영어로 쓴 용어를 영어로 쓰라는 의미다.** 설명·계산까지 영어로 바꾸거나 한글 개념을 임의로 영문화하지 않는다. 문제의 “교안 영문 명칭” 부분만 아래 근거 표기를 요구한다. 기타 단답은 한글·수식·단위를 허용하고 R 문법은 실행 가능한 표기로 쓴다.

영문 용어 60개의 교안 페이지 근거를 확인했다. 대소문자·일반 하이픈·공백은 의미가 같으면 인정하되 철자로 다른 용어가 되면 감점한다. R 함수·객체·문자열의 철자와 대소문자는 실행에 영향을 준다.
