## 1. 주관식 대비 필수 영문 용어 사전 (English Terminology Glossary)

교안에서 영어로 제시한 **용어의 명칭을 요구할 때만 영어로 작성**한다. 정의·이유·계산·해석은 한글로 답하며, 한글로 제시된 개념을 임의로 번역하지 않는다. 아래 표는 교안의 영문 용어와 의미를 연결하기 위한 참고표다.

| 단원 | 핵심 영문 용어 (정확한 철자) | 한글 의미 및 핵심 정의 | 출처 쪽수 |
|---|---|---|---|
| **Ch 1** | **User Experience (UX)** | 제품·시스템·서비스 사용 전·중·후의 전반적 경험과 만족도 (`Previous / Present / Future Experience`) | Intro 1 p.2 |
| **Ch 1** | **Ergonomics** | 그리스어 `Ergon`(work) + `Nomos`(laws)의 합성어; 인간 특성을 설계에 적용해 인간 안녕과 시스템 성능을 최적화하는 학문 | Intro 2 p.7 |
| **Ch 1** | **Human Factors (Engineering)** | 미국에서 Ergonomics와 동의어로 사용하는 명칭 (미군은 `Human Engineering`, 심리학계는 `Engineering Psychology`) | Intro 2 p.7 |
| **Ch 1** | **Physical Ergonomics** | 인체측정학(`Anthropometric`), 생리학(`Physiological`), 생체역학(`Biomechanical`) 특성을 다루는 인간공학 영역 | Intro 2 p.15 |
| **Ch 1** | **Cognitive Ergonomics** | 지각(`Perception`), 기억(`Memory`), 추론(`Reasoning`), 운동 반응(`Motor response`) 등 정신 과정(`Mental process`)을 다루는 영역 | Intro 2 p.15 |
| **Ch 1** | **Time and Motion Study** | Frank & Lillian Gilbreth 부부가 창시한 시간·동작 연구 (`Methods Engineering`) | Intro 2 p.12 |
| **Ch 1** | **Therbligs (therblig)** | Gilbreth 부부가 고안한 **미세동작분석(`Micro-motion analysis`)**의 기본 동작 단위 (Gilbreth 철자를 역순으로 변형) | Intro 2 p.12 |
| **Ch 1** | **Selective Attention** | 특정 자극을 선택해 주의를 집중하는 과정. 이때 예상 밖 자극을 놓치는 무주의 맹시가 나타날 수 있음 (*The Monkey Business Illusion*) | Intro 1 p.9–10 |
| **Ch 2** | **Descriptive Research** | 인간의 신체 치수, 근력, BMI 등 속성과 분포를 있는 그대로 측정·기술하는 연구 | HFE p.4–7 |
| **Ch 2** | **Experimental Research** | 독립변수를 조작하여 행동 및 수행(종속변수)에 미치는 효과를 검증하는 연구 | HFE p.4, 8–10 |
| **Ch 2** | **Evaluation Research** | 제품이나 시스템의 효과성(`effectiveness`, 즉 **사용성 `usability`**)을 평가하는 연구 | HFE p.4, 11–13 |
| **Ch 2** | **Laboratory Study / Field Study** | 실험실 연구(통제·반복·정확한 측정 유리, 일반화 불리) / 현장 연구(현실 충실도·일반화 유리, 통제 어렵고 비용·안전 문제) | HFE p.14 |
| **Ch 2** | **Independent Variable (IV)** | 연구자가 관심을 갖고 의도적으로 조작하는 요인 (`manipulated factor`, 예: 마우스 종류, 무게 중심 위치) | HFE p.15 |
| **Ch 2** | **Dependent Variable (DV)** | 독립변수에 따라 측정되는 결과값 (`measured value`, 예: 클릭 시간, 코 압력, 만족도 점수) | HFE p.15–16 |
| **Ch 2** | **Control / Stratification** | 기타 외생변수를 일정하게 고정하는 **통제(`Control`)** vs 집단 비율별로 계층화해 배정하는 **층화(`Stratification`)** | HFE p.15 |
| **Ch 2** | **Representativity** | 표본이 목표 모집단(`target population`)의 특성을 편향(`Bias`) 없이 대표하는 성질 (`Random sampling` 활용) | HFE p.17 |
| **Ch 2** | **Significant Level ($\alpha$) / Precision ($k$)** | 유의수준(감수할 오류 위험, $\alpha=0.05 \to z=1.96$) / 정밀도(평균 대비 허용 오차 비율, $\text{Absolute error} = k\bar{x}$) | HFE p.17–19 |
| **Ch 2** | **Unobtrusive** | 실무적 측정 요건 중 피험자의 자연스러운 과업 수행을 방해하지 않아야 한다는 성질 | HFE p.20 |
| **Ch 2** | **Reliability** | 시간 경과나 표본에 걸쳐 측정 결과가 일관되고 안정적인 정도 (`consistency or stability`) | HFE p.20–21 |
| **Ch 2** | **Internal Validity / External Validity** | 내적 타당도(혼동변수 `confounding` 배제) / 외적 타당도(결과를 다른 대상·환경으로 일반화 `generalizability`) | HFE p.20 |
| **Ch 2** | **Construct Validity** | 구성타당도: 이론적 구성개념(`Construct`)을 실제 측정 도구(`Measure`)가 제대로 측정하는 정도 | HFE p.22 |
| **Ch 2** | **Deficiency** | 구성타당도 결핍: 구성개념(`Construct`)에 속하지만 측정치(`Measure`)가 평가하지 못하고 빠뜨린 부분 | HFE p.22 |
| **Ch 2** | **Contamination** | 구성타당도 오염: 측정치(`Measure`)에 포함되었으나 원래 구성개념(`Construct`)과 무관한 외생 요인이 섞여든 부분 | HFE p.22 |
| **Ch 3** | **Short-term Sensory Store (STSS)** | 외부 자극(`Stimuli`)이 가장 먼저 아주 짧게 머무는 단기감각기억 저장소 | Info p.6 |
| **Ch 3** | **Perception** | 감각 정보를 장기기억(`Long-term memory`)의 지식과 결합해 의미를 해석하는 지각 단계 | Info p.6 |
| **Ch 3** | **Working Memory (Short-term Memory)** | 정보를 일시적으로 유지(유지 시간 `20~30 sec`)하고 조작하는 작업기억 | Info p.6, 25 |
| **Ch 3** | **Decision and Response Selection** | 지각된 정보를 바탕으로 어떤 행동을 할지 결정하고 반응을 선택하는 단계 | Info p.6 |
| **Ch 3** | **Response Execution** | 선택된 반응을 실제 근육 운동으로 실행하는 단계 (이후 `Feedback` 루프로 연결) | Info p.6 |
| **Ch 3** | **Attention Resources** | 지각, 작업기억, 의사결정, 반응실행 각 단계에 배분되는 제한된 주의 자원 | Info p.6 |
| **Ch 3** | **Bit (Binary Digit)** | 정보량의 기본 단위; 동등 확률의 2개 대안($2^1$) 중 하나를 처리할 때 필요한 정보량 | Info p.8 |
| **Ch 3** | **Redundancy (% Redundancy)** | 중복도(잉여도): 최대 정보량($H_{\max}$) 대비 실제 정보량($H_{\text{target}}$)이 줄어든 비율 $(1 - H_{\text{target}}/H_{\max})\times 100$ | Info p.11 |
| **Ch 4** | **Information Transmission Theory** | 인간을 입력(자극 $X$)과 출력(반응 $Y$) 사이의 통신 채널(`Channel`)로 보고 정보 처리 수행도를 정량화하는 이론 | Info p.15 |
| **Ch 4** | **Transmitted Information** | 자극에서 반응으로 실제 전달된 정보량 $H(X \cap Y) = T(X,Y) = H(X) + H(Y) - H(X \cup Y)$ (클수록 좋음) | Info p.16 |
| **Ch 4** | **Equivocation** | 모호도(손실정보, `miss`): 입력 정보 중 출력으로 전달되지 못하고 유실된 정보량 $H(X\mid Y) = H(X) - H(X \cap Y)$ (작을수록 좋음) | Info p.15–16 |
| **Ch 4** | **Noise** | 잡음(거짓정보, `false`): 입력 자극과 무관하게 출력 반응에 끼어든 불확실성 $H(Y\mid X) = H(Y) - H(X \cap Y)$ (작을수록 좋음) | Info p.15–16 |
| **Ch 4** | **Channel Capacity** | 인간이 단위 시간당 처리할 수 있는 최대 전달정보량의 점근적 한계 (`asymptotic value`, 단위 `bits/sec`) | Info p.20 |
| **Ch 4** | **Magic Number ($7 \pm 2$)** | G. A. Miller가 제시한 인간 작업기억/절대판단의 단일 차원 처리 한계 (약 5~9개, $2.3\sim 3.2\text{ bits}$) | Info p.21 |
| **Ch 4** | **Rehearsal** | 작업기억의 정보가 20~30초 내에 사라지지 않도록 마음속으로 반복해 되뇌는 시연 과정 | Info p.25 |
| **Ch 4** | **Absolute Judgment / Relative Judgment** | 절대 판단(기억 속 기준과 단일 자극 비교) vs 상대 판단(두 자극을 나란히 두고 비교 `side by side`, 채널 용량 향상) | Info p.26–28 |
| **Ch 4** | **Chunking** | 개별 정보들을 의미 있는 묶음(`grouping/parsing`)으로 만들고 장기기억의 기존 지식과 연결해 작업기억 효율을 높이는 전략 | Info p.26, 29 |
| **Ch 4** | **Positive Set / Probe Digit** | Sternberg 기억탐색 과제에서 외워야 할 숫자 목록(`Positive set`)과 판별을 위해 제시되는 검사 숫자(`Probe`) | Info p.30–31 |
| **Ch 4** | **Serial Processor** | 기억집합 크기(`PSS`)가 커질수록 반응시간(`RT`)이 선형 증가하므로 인간이 항목을 하나씩 순차 처리한다는 개념 | Info p.31 |
| **Ch 4** | **Self-terminating Search / Exhaustive Search** | 자기종료 탐색(목표를 찾으면 즉시 종료, 교안 `YES`) vs 전수 탐색(집합 끝까지 모두 비교 후 응답, 교안 `NO`) | Info p.31 |
| **Ch 4** | **Simple Reaction Time (SRT)** | Donders' A 과업 (`1S-1R`): 단일 자극에 단일 반응 (자극 식별 N, 반응 선택 N) | Info p.32 |
| **Ch 4** | **Choice Reaction Time (CRT)** | Donders' B 과업 (`MS-MR`): 여러 자극에 각각 대응하는 반응 선택 (자극 식별 Y, 반응 선택 Y; **Hick's Law** 적용) | Info p.32, 34 |
| **Ch 4** | **Discrimination Reaction Time** | Donders' C 과업 (`MS-1R`): 여러 자극 중 지정된 하나의 자극에만 반응 (자극 식별 Y, 반응 선택 N) | Info p.32 |
| **Ch 4** | **Hick's Law** | 선택 반응시간이 자극 정보량(또는 전달정보량)에 선형 비례한다는 법칙 ($\mathrm{RT} = a + bH$) | Info p.34–37 |
| **Ch 5** | **Fitts' Law** | 목표 지점 포인팅/탭핑 운동시간(`MT`)이 이동 난이도 지수(`ID`)에 선형 비례한다는 법칙 ($\mathrm{MT} = a + b \cdot \mathrm{ID}$) | Info p.42–48 |
| **Ch 5** | **Index of Difficulty (ID)** | 피츠 법칙의 난이도 지수: 원형 $\log_2(2A/W)$ 또는 ISO 표준 $\log_2(D/W + 1)$ (단위 `bits`) | Info p.43, 46 |
| **Ch 5** | **Positioning Movement (Closed Loop)** | 감각 피드백(`feedback`)을 실시간으로 받아 목표 위치를 정밀하게 조정하는 폐회로 움직임 | Info p.50–51 |
| **Ch 5** | **Ballistic Movement (Open Loop)** | 피드백 수정 없이 미리 계획된 대로 빠르게 한 번에 실행되는 개회로(탄도) 움직임 | Info p.50–51 |
| **Ch 5** | **Range Effect (Overshoot / Undershoot)** | 짧은 거리는 목표를 지나치고(`Overshoot`), 긴 거리는 목표에 못 미치는(`Undershoot`) 운동 제어 현상 | Info p.51 |
| **Ch 5** | **Compatibility** | 제어장치와 표시장치의 관계가 사용자의 기대와 일치하는 정도 | Info p.57 |
| **Ch 5** | **Population Stereotype** | 제어-표시 관계에 대해 특정 인구 집단이 공통으로 가지고 있는 고정관념·기대 | Info p.57 |
| **Ch 5** | **Affordance** | 사물의 디자인·특성이 사용자로 하여금 직관적으로 특정 행동을 하도록 유도하는 성질 (`intuitive operation`) | Info p.57 |
| **Ch 5** | **Spatial Compatibility** | 물리적 제어장치와 표시장치의 공간적 배열·배치 유사성 (예: 가스레인지 화구와 손잡이 배치) | Info p.58 |
| **Ch 5** | **Movement Compatibility** | 제어장치의 조작 방향과 표시장치의 이동/증감 방향의 일치 (예: 다이얼 회전 방향과 눈금 이동) | Info p.59 |
| **Ch 5** | **Conceptual Compatibility** | 색상·기호·코드가 사람들의 개념적 연상과 일치하는 정도 (예: 빨강=온수/위험, 파랑=냉수/정상) | Info p.60 |
| **Ch 5** | **Modality Compatibility** | 자극(표시)과 반응(조작)이 동일한 감각·반응 양식을 사용하는 정도 (예: 음성 지시에 음성으로 응답) | Info p.61 |
| **Ch 6** | **One-sample / Independent / Paired t-test** | 단일표본 t-검정(1집단 평균 vs $\mu_0$) / 독립표본 t-검정(독립 2집단 평균 비교) / 대응표본 t-검정(동일 집단 전후 차이 검정) | t-test p.10–24 |
| **Ch 7** | **Correlation / Regression Analysis** | 상관분석(두 변수의 선형 관계 강도 $r$) / 회귀분석(독립변수 $X$로 종속변수 $Y$를 설명·예측하는 함수식 추정) | Reg p.2–8 |
| **Ch 7** | **Ordinary Least Squares (OLS)** | 잔차제곱합($\mathrm{SSE} = \sum(y_i-\hat{y}_i)^2$)이 최소가 되도록 회귀 직선을 추정하는 최소제곱추정법 | Reg p.15 |
| **Ch 7** | **Coefficient of Determination ($R^2$)** | 결정계수($\mathrm{SSR}/\mathrm{SST} = 1 - \mathrm{SSE}/\mathrm{SST}$): 독립변수가 종속변수 변동을 설명하는 비율(회귀식의 타당성) | Reg p.20, 25 |

## 2. 전 단원 필수 계산 공식 및 교안 예제 수치 요약표

| 공식 명칭 | 수식 및 기호 정의 | 교안 핵심 계산 예제 수치 (암기 및 검산용) |
|---|---|---|
| **체질량지수 (BMI)** | $\mathrm{BMI} = \dfrac{\text{weight (kg)}}{\text{stature}^2\text{ (m}^2\text{)}}$ | 단위: $\text{kg/m}^2$ (키를 반드시 $\text{m}$ 단위로 제곱) |
| **적정 표본 수 ($n$)** | $n = \left(\dfrac{z_{\alpha/2} \times s}{k \times \bar{x}}\right)^2$ | 파일럿 $n_0=5, \bar{x}=100, s=10, \alpha=0.05(z=1.96), k=0.05$일 때:<br>$n = (1.96 \times 10 / 5)^2 = 3.92^2 = 15.366 \Rightarrow$ **총 16명** (추가 모집 **11명**)<br>참고: $\alpha=0.01 \Rightarrow z_{\alpha/2}=2.576$ |
| **Hartley 정보량 (등확률)** | $H = \log_2 N = \log_2(1/P)\text{ [bits]}$ | $N=1 \to 0\text{ bit}$, $N=2 \to 1\text{ bit}$, $N=4 \to 2\text{ bits}$, $N=8 \to 3\text{ bits}$, $N=16 \to 4\text{ bits}$ |
| **Shannon 정보량 (비등확률)** | $H = \sum_{i=1}^N p_i \log_2\left(\dfrac{1}{p_i}\right) = -\sum_{i=1}^N p_i \log_2 p_i$ | ① $P=(0.2, 0.8) \Rightarrow H = 0.2(2.322)+0.8(0.322) = \mathbf{0.722\text{ bits}}$<br>② 휜 동전 $P=(0.9, 0.1) \Rightarrow H \approx \mathbf{0.4690\text{ bit}}$ (교안 제시값 0.468 bit)<br>③ 8경고등($P_{1,2}=0.35, P_{3..8}=0.05$) $\Rightarrow H = \mathbf{2.3568\text{ bits}}$ |
| **중복도 (% Redundancy)** | $\%\text{Redundancy} = \left(1 - \dfrac{H_{\text{target}}}{H_{\max}}\right) \times 100$ | ① 휜 동전: $(1 - 0.468/1)\times 100 = \mathbf{53.2\%}$<br>② 8경고등: $(1 - 2.3568/3)\times 100 = \mathbf{21.44\%}$<br>③ 카운트다운 신호등($H_{\text{new}}=0$): $(1 - 0/1)\times 100 = \mathbf{100\%}$ |
| **전달정보량·모호도·잡음** | $\begin{aligned} H(X \cup Y) &= -\sum_i\sum_j p_{ij}\log_2 p_{ij} \\ H(X \cap Y) &= H(X) + H(Y) - H(X \cup Y) \\ \text{Equivocation } H(X\mid Y) &= H(X) - H(X \cap Y) \\ \text{Noise } H(Y\mid X) &= H(Y) - H(X \cap Y) \end{aligned}$ | **교안 16문항 시험 표**:<br>$X$ 각 4회 $\to H(X) = \mathbf{2.0\text{ bits}}$<br>$Y$ 합계 $(8,0,4,4) \to P(Y)=(1/2,0,1/4,1/4) \to H(Y) = \mathbf{1.5\text{ bits}}$<br>결합칸 4개가 각 $4/16=1/4 \to H(X \cup Y) = \mathbf{2.0\text{ bits}}$<br>$\therefore H(X \cap Y) = \mathbf{1.5\text{ bits}}$, $H(X\mid Y) = \mathbf{0.5\text{ bits}}$, $H(Y\mid X) = \mathbf{0\text{ bits}}$ |
| **Hick의 법칙 (선택반응)** | $\mathrm{RT} = a + bH$ (또는 $a + bH_T$)<br>채널용량 $= 1/b\text{ [bits/sec]}$ | $b = 150\text{ ms/bit}$일 때 $1/b = 1/0.15\text{ s} \approx \mathbf{6.67\text{ bits/sec}}$<br>단순반응 생리 합계: 눈→뇌(10~30) + 중앙처리(90) + 뇌→근육(20) + 근수축(30) = **150~170 ms** (교안의 별도 대표 범위는 150~180 ms) |
| **Fitts의 법칙 (운동시간)** | $\mathrm{MT} = a + b \cdot \mathrm{ID}$<br>원형: $\mathrm{ID} = \log_2(2A/W)$<br>ISO 표준: $\mathrm{ID} = \log_2(D/W + 1)$ | $a=50, b=150$, ISO 식 기준:<br>① $D=80, W=20 \Rightarrow \mathrm{ID}=\log_2 5 \approx 2.3219 \Rightarrow \mathrm{MT} \approx \mathbf{398.29\text{ ms}}$<br>② $D=100, W=10 \Rightarrow \mathrm{ID}=\log_2 11 \approx 3.4594 \Rightarrow \mathrm{MT} \approx \mathbf{568.91\text{ ms}}$<br>부위별 기울기: 팔뚝(`105`) > 손목(`43`) > 손가락(`26 ms/bit`) |
| **공분산과 상관계수** | $s_{XY} = \dfrac{\sum(x_i-\bar{x})(y_i-\bar{y})}{n-1}$<br>$r = \dfrac{s_{XY}}{s_X s_Y} = \dfrac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}$ | $-1 \le r \le 1$ (무차원). $r>0$ 양의 선형, $r<0$ 음의 선형, $r=0$ 선형 무관 |
| **단순선형회귀 OLS & ANOVA** | $b_1 = \dfrac{S_{xy}}{S_{xx}}, \quad b_0 = \bar{y} - b_1\bar{x}$<br>$\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$<br>$\mathrm{MSR} = \dfrac{\mathrm{SSR}}{1}, \quad \mathrm{MSE} = \dfrac{\mathrm{SSE}}{n-2}$<br>$F = \dfrac{\mathrm{MSR}}{\mathrm{MSE}}, \quad R^2 = \dfrac{\mathrm{SSR}}{\mathrm{SST}} = 1 - \dfrac{\mathrm{SSE}}{\mathrm{SST}}$ | **교안 12명 사원 예제 (`regression1` R 출력 기준)**:<br>$\hat{y} = \mathbf{30.93 + 0.87x}$ ($b_0=30.9333, b_1=0.8705$)<br>$R^2 = \mathbf{0.6828}$ (업무만족도 변화의 **68.3%** 설명), $\text{Adj } R^2 = \mathbf{0.6511}$<br>$F(1, 10) = \mathbf{21.53}$, $p = \mathbf{0.0009223} < 0.05$ (회귀모형 및 계수 모두 유의) |

## 5. 최종 수식 검수 · 적용 조건

- 평균의 표준오차는 $\mathrm{SE}=s/\sqrt{n}$이다. 독립 표본의 표본평균에 대한 식이며 SD는 개별값의 산포, SE는 평균 추정의 불확실성이다.
- 표본 수 공식 $n=(zs/(k\bar{x}))^2$은 양의 평균에 대한 상대 허용오차 $k\bar{x}$와 정규 근사를 쓰는 교안 공식이다. $z_{\alpha/2}$는 상측 꼬리 확률이 $\alpha/2$인 양의 임계값이다. 총 인원은 올림하고 포함되는 파일럿 인원을 빼서 추가 모집 수를 구한다.
- 휜 동전 $(0.9,0.1)$의 직접 계산은 $H\approx0.4689956$ bit, 중복도 $53.10044\%$다. 교안은 $H=0.468$ bit를 제시해 $53.2\%$로 계산한다. **문제에서 0.468을 주면 그 제시값으로 계산한다.** 확률만 주고 직접 로그를 계산할 때는 0.4690 bit와 약 53.10%를 사용한다.
- 눈→뇌 10~30, 중앙처리 90, 뇌→근육 20, 근수축 30 ms의 **산술 합은 150~170 ms**다. 교안의 별도 대표 범위인 150~180 ms와 구분한다.
- Shannon 엔트로피는 $H=-\sum_i p_i\log_2p_i$, $p_i\ge0$, $\sum_i p_i=1$이며 $0\log_2 0=0$은 극한 규약이다. $H_{\max}=\log_2N$이고 중복도 식은 $H_{\max}>0$에서 사용한다. 색·크기만 바꾸고 확률 분포가 같으면 엔트로피도 같다.
- 전달량 $I(X;Y)=H(X)+H(Y)-H(X,Y)$, 모호도 $H(X\mid Y)=H(X)-I(X;Y)$, 잡음 $H(Y\mid X)=H(Y)-I(X;Y)$다. 교안의 $H(X\cap Y)$는 전달량, $H(X\cup Y)$는 결합 엔트로피를 뜻하는 표기다. 정답률과 전달량은 서로 다르다.
- Hick은 선택반응의 $\mathrm{RT}=a+bH$, Fitts는 운동의 $\mathrm{MT}=a+b\,\mathrm{ID}$다. 역수 $1/b$를 bits/s로 읽으려면 b를 s/bit로 변환한다. Fitts의 거리와 너비는 같은 길이 단위를 사용하고 원형·ISO형 계수를 서로 바꾸어 대입하지 않는다.
- 절편을 포함한 동일 학습 자료의 OLS에서 $\mathrm{SST}=\mathrm{SSR}+\mathrm{SSE}$다. 단순회귀는 잔차 자유도 $n-2$이고 $F=(\mathrm{SSR}/1)/(\mathrm{SSE}/(n-2))$다. $R^2=1-\mathrm{SSE}/\mathrm{SST}$는 표본 내 설명력이다. 수정 결정계수는 $\bar R^2=1-(1-R^2)(n-1)/(n-p-1)$이며 p는 절편을 제외한 설명변수 수다.
- 피어슨 상관계수는 두 변수의 분산이 양수일 때 정의된다. $r=0$은 비선형 관계의 부재나 독립성을 보장하지 않는다. 검정의 비기각은 정규성·등분산·영가설의 참을 증명하지 않는다.
