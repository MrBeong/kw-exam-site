# 보기 품질과 기출형 정합성 검수

검증일: 2026-10-18. 정답만 유독 길거나 오답이 무관한 표현으로 쉽게 지워지는지 다지선다 135문항, 기출형 객관식 80문항과 O/X 진술 20개를 전수 검토했다. 필수 분석자료·조건을 유지하고, 강의의 개념 차이를 적용해 판단하도록 보완했다.

## 수정 내용

다지선다 **80문항**, 기출형 **48문항**(객관식 44·O/X 묶음 4)을 수정했다. [수정 ID 목록](final-audit/distractor-changes.json)과 [검토 기준·판단 기록](final-audit/distractor-review.json)에 범위를 남겼다. 그대로 유지한 55개 다지선다도 계산 오류·인접 범주·대응 관계를 평가하는지 검토했다.

- UX 범위, HFE 접근, 타당도, 기억 전략, 회귀 해석의 보기들을 비슷한 정보 항목·문장 구조로 맞췄다. 무관한 분야·시대·단위, 황당한 단정 대신 범위 누락·인접 개념·추론 비약을 오답 근거로 사용했다.
- BMI는 모든 보기에 같은 단위를 쓰고 제곱 누락·단위 환산 오류로 수치를 구성했다. 정보량·시간·변화량은 단위, 적용 모형과 계산 단계를 구별하도록 했다. 숫자·벡터 출력형은 군더더기로 길이를 맞추지 않았다.
- t-검정·회귀·그리기 코드의 오답도 실제 R 문법을 사용한다. 집단 선택, 귀무 기준, 등분산 인자, 반응변수, 선 종류·계수 순서를 잘못 적용한 경우를 구별한다. 코드 대안 18개를 실제 R에서 구문 분석했다.
- MC086은 제시된 수행시간 자료에 맞게 사후 시간 감소로 해석한다. MC054는 교안이 제시한 탐색 설명의 범위를 명확히 하고, MC067은 기울기로 시간을 비교하는 양의 ID 조건을 명시했다.
- 독립 검토에서 MC127·ME1-Q06의 오답이 해당 조건에서는 참으로도 읽힐 수 있음을 발견했다. 보기 자체에 ‘메뉴 수가 같으면 D/W가 달라져도 유지된다’는 잘못된 일반화를 명시하고 해설도 바로잡았다.
- 복제본은 보기 ID별로 내용을 갱신하여 각 페이지의 기존 순서·정답 번호를 보존했다. 수정된 모든 보기에 개별 근거를 제공한다.

## 정답·채점·저장

정답 ID·순서·정답 집합·개념 대응·문항 수·배점은 유지한다. 다지선다 연습은 정답 집합을 정확히 골라야 정답이며, 기출형 단일·복수선택은 일치 2점/불일치 0점, O/X 두 진술은 각 1점이다. 실제 입력으로 정답·오답 채점과 해설을 대조했다. 주관식 모범답안·587개 채점 항목과 R 준비 코드·빈칸·완성 코드에는 이번에 변경이 없다. 기록 키를 변경하거나 기존 답안을 지우지 않는다.

단일선택·사례형의 정답 위치는 1번 28·2번 29·3번 28·4번 28문항이다. 복수선택은 정답 2개 4문항·3개 18문항으로 한 개수에 고정되어 있지 않다. 글자 수 검사에서는 정답과 오답 평균 길이 비율의 양방향 이상치를 확인했다. TeX·공백을 정리한 길이와 최소 길이 조건의 같은 기준에서 전 13문항 → 후 0문항이다. 이는 검토 보조이며 실제 학생 응답으로 측정한 난이도·변별력은 아니다.
