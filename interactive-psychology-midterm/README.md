## 오답만 다시 풀기

각 문제 유형의 **오답 탭**(단답·서술·R은 **오답·애매**)에서 같은 탭을 한 번 더 눌러 재풀이 바를 펼쳤을 때만 버튼을 표시합니다. 첫 진입은 목록만 보이고, 다시 누르면 바를 접습니다. 접고 펼쳐도 현재 선택·입력·진도는 유지됩니다. 단답·서술·R의 오답 재풀이는 자기평가 `다시 풀기` 문항만 포함하고 `애매함`은 제외합니다. 객관식은 정오 결과, 기출형은 최신 채점 결과와 복습 표시를 기준으로 모읍니다.

새 답안과 해설이 닫힌 상태로 시작하며 진행 상황은 브라우저에 저장됩니다. 다시 채점해 해결한 문제는 다음 재풀이 회차에서 빠집니다. 다른 상태 탭으로 이동하거나 재풀이를 종료하면 미채점 문항은 이전 답안으로 복원합니다. 제출한 모의시험 답안은 연습 모드의 재풀이와 별도로 보존합니다.

주관식·R 코드는 상세 해설과 항목별 기준에 따라 자기채점합니다. 웹 화면에서 R을 실행하거나 자유 서술의 의미를 자동 판정하지 않습니다. 모든 R 모범 코드는 별도 실제 R 실행으로 검증했습니다.

## 재생성

이 폴더에서 Python 3로 순서대로 실행합니다. Node 빌드나 외부 CDN은 필요하지 않습니다.

```sh
python3 multiple-choice/build.py
python3 written/build.py
python3 mock-exam/build.py
python3 final-audit/r-execution/run.py
python3 final-audit/verify_content.py
python3 final-audit/verify_cram.py
python3 final-audit/verify_cram_coverage.py
python3 final-audit/collect_formulas.py
node final-audit/verify_paper_versions.js
```

R 실행 검증은 R 및 `lawstat`, `jsonlite`가 설치된 환경에서 실행합니다. 검증에 사용한 원본 엑셀 파일은 `final-audit/fixtures/regression1.xlsx`에 포함되어 있습니다.

```sh
python3 final-audit/r-execution/run.py
```

`final-audit/wrong-retry-ui.js`, `wrong-retry-edges.js`, `release-ui.js`는 Playwright CLI의 `run-code --filename`으로 실행하는 브라우저 검증입니다. 별도의 격리 프로필을 사용해야 합니다. 이 스크립트는 학습 저장소를 연습 데이터로 초기화합니다. 전체 검증에서는 이 폴더를 HTTP로 제공한 뒤 첫 학습 페이지를 연 상태에서 실행하세요.

학습 기록은 해당 브라우저·origin의 localStorage에 저장되므로 로컬 파일과 GitHub Pages, 다른 기기·브라우저의 기록은 분리됩니다. 초기화는 문제 유형별로 적용하며 북마크와 다른 유형의 기록은 보존합니다.

## 계산기 없는 시험 대비

손계산용 문제는 제시한 로그 근삿값을 그대로 사용하고, 중간값을 유지한 뒤 최종 소수 답만 첫째 자리까지 적습니다. 정확한 분수도 문제의 인정 범위에 따라 허용합니다. 필요한 인원은 최소 정수로 올립니다. 강의 원문·실제 R 출력의 p값·계수는 판독 자료이므로 일괄 반올림하지 않습니다.

수치·조건이 바뀐 연습 문항의 이전 답안은 별도 보관 후 해당 문항만 새로 풀도록 합니다. 이미 진행·제출한 모의시험은 원래 문항·해설·답안·마감 시각으로 유지되며 다시 응시할 때 새 문항을 적용합니다. 보관본은 각 화면의 손계산형 안내를 펼쳐 내려받을 수 있습니다.

`final-audit/handcalc-revision-ui.js`는 변경 답안 보관·영향 문항만 갱신·미채점 재풀이 복원·저장 공간 부족·진행/제출 시험 보존·다중 탭의 이전 문항 유지·새 응시·모바일을 검증합니다. 다른 브라우저 검사와 마찬가지로 격리 프로필에서 실행합니다. 문항별 변경 및 이전/현재 원문은 `handcalc-changes.json`, `handcalc-compatibility.json`에 기록했습니다.

세부 빈칸 단답은 SA045–SA075의 31문항·128칸이다. `lty` 숫자↔이름↔그림, R 연산자·탭·출력 표와 교안의 표/도식을 직접 회상한다. 새 UI 검증은 `final-audit/detail-recall-ui.js`, 실제 R 보완 검증은 `verify_recall_R.R`로 실행한다. 개념군 ID의 출제 여부와 세부 항목의 직접 인출은 별도 대응표로 확인한다.
