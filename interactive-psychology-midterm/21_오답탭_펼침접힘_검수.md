# 오답 탭 재클릭 펼침/접힘 검수

검증일: 2026-10-17. 사용자 최신 요청(재풀이 바를 오답 탭 재클릭으로 표시)에 따라 UI와 공통 제작 기준을 보완했다.

## 최신 동작

- O/X·다지선다·단답/서술/R·기출형 모두 첫 오답 탭 클릭은 목록만 표시하고 바는 접힌 상태다.
- 활성 오답 탭을 한 번 더 누르면 재풀이 바가 펼쳐지고, 다시 누르면 바만 접힌다. 화살표와 aria-expanded도 같은 상태로 표시한다.
- 펼침/접힘은 문항 재필터링·이동·초기화·채점을 실행하지 않는다. 현재 선택·코드 입력·답안·회차·채점 진도를 보존한다.
- 통합 오답 정리에서는 문항/목록 탐색만 제공한다. 별도 재풀이 시작 버튼·자동 시작 링크·동작하지 않는 이전 초기화 버튼은 제거했다.
- 새로고침·직접 링크로 회차를 이어가도 제어 바는 기본 접힘 상태다. 활성 오답 탭을 누르면 다시 펼칠 수 있다.
- 다른 상태 탭으로 이동하거나 명시적으로 종료하면 기존 정책대로 미채점 문항을 복원한다. 단순히 바를 접는 동작과 재풀이 종료는 구분한다.

## 검증

| 항목 | 결과 |
|---|---|
| 네 문제은행의 토글·입력/진도 보존·재진입·모바일 | 87검사 통과, 브라우저 예외 0 |
| 기존 오답 재풀이·재채점·저장·타이머 회귀 | 51검사 통과 |
| 직접 링크·채점 무효화·다중 탭·종료 복원 | 18검사 통과 |
| 문항·개념·정답·해설·채점 정합성 | 기존 589문항·188개 개념, 검증 2,565항목·독립 수치 146항목 통과 |
