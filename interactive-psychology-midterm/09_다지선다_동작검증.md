## 초기화 누락의 원인과 재현

메인의 `resetBtn`, `toolbarResetBtn`은 HTML에 있었지만 클릭 이벤트가 없었다. 가상 답안·정오·체크리스트를 넣은 수정 전 페이지에서 버튼을 클릭해도 답안이 그대로 남는 것을 재현했다. O/X의 기존 기록 초기화는 접힌 도구 메뉴 안에 있어 평상시 보이지 않았고 북마크까지 지웠다.

버튼을 실제 초기화 함수에 연결하고 O/X·다지선다의 초기화를 항상 보이는 행에 배치했다. 확인창에서 지울 범위를 설명하고 해당 단계 답안·정오만 초기화한다. 북마크·개념 체크리스트·다른 단계의 기록은 보존한다.
