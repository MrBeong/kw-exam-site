정보량은 확률부터, 전달량은 표부터

02 / 06
등확률 대안 N개\[H=\log_2N\]
비등확률의 평균 정보량\[H=-\sum_i p_i\log_2p_i\]
중복도\[R=\left(1-\frac{H}{H_{\max}}\right)100\%\]

한 사건의 정보량은 \(-\log_2p_i\), 평균은 확률로 가중한다. \(H_{\max}=\log_2N\). 0인 확률 항은 0으로 취급한다. 확실한 사건은 0 bit, 같은 N이면 등확률일 때 H가 최대다. 대안 수를 두 배로 늘리면 등확률 H는 1 bit 증가한다.

확률이 0.2와 0.8인 두 신호. log₂5≈2.3, log₂1.25≈0.3을 주면 H와 중복도는?풀이 확인

제시 로그를 그대로 사용한다.

\[H=0.2(2.3)+0.8(0.3)=0.7\ \mathrm{bit}\]\[H_{\max}=1,\qquad R=(1-0.7)100=30.0\%\]

이 문제는 제시한 근삿값 기준의 연습 예제다. 정밀 로그로 계산한 0.722 bit를 섞지 않는다. 색·크기만 바뀌고 확률이 같다면 Shannon 정보량은 그대로다.

H(X), H(Y), H(X,Y)를 먼저 구한 뒤 전달량·모호도·잡음을 복원하라.풀이 확인

행은 1/4씩 네 개 → \(H(X)=2\). 열은 1/2, 0, 1/4, 1/4 → \(H(Y)=1.5\). 0이 아닌 안쪽 칸은 1/4씩 네 개 → \(H(X,Y)=2\).

\[I(X;Y)=H(X)+H(Y)-H(X,Y)=1.5\ \mathrm{bits}\] \[\underbrace{H(X\mid Y)}_{\mathrm{Equivocation}}=H(X)-I=0.5\ \mathrm{bit}\] \[\underbrace{H(Y\mid X)}_{\mathrm{Noise}}=H(Y)-I=0\ \mathrm{bit}\]

뜻으로 검산: Y₁이 나오면 X₁인지 X₂인지 모른다(모호도). 반면 각 X에서 반응은 하나로 정해져 있다(잡음 0). 정답률은 12/16=75%이지만 전달량은 1.5 bits다.

교안 기호 주의: 교안의 \(H(X\cup Y)\)는 결합 엔트로피 \(H(X,Y)\), \(H(X\cap Y)\)는 전달량 \(I(X;Y)\)를 뜻한다. 검산은 \(I+H(X\mid Y)+H(Y\mid X)=H(X,Y)\). 전달량은 항상 \(0\le I\le\min(H(X),H(Y))\)다.

함정: 두 입력을 항상 반대로 답하면 정답률은 0%여도 대응이 일정해 입력을 복원할 수 있다(등확률 두 입력이면 I=1 bit). 항상 같은 답만 하면 입력에 관한 정보는 0이다. 정답률과 전달량을 같은 지표로 취급하지 않는다.

강의의 대응자료 출력: datadiff=after−before, 평균차 −33.65, p=2.97e−7, 95% CI [−42.80264, −24.49736]. 결론은?풀이 확인

답안: 평균차 0이라는 귀무가설을 기각한다(p<0.05). 차이를 after−before로 정의했으므로 복용 후 평균 혈압이 복용 전보다 33.65만큼 낮게 나타났다. 차이의 95% 신뢰구간도 모두 음수여서 이 방향과 일치한다.

강의 t-test p.23–24의 출력이다. 차이값 정규성 p=0.06655는 정규성을 기각하지 못한 결과다. p를 ‘귀무가설이 참일 확률’이나 ‘약이 반드시 인과적으로 효과를 냈다는 확률’로 바꾸지 않는다.

회귀는 방향, 상관은 선형 관계의 강도

\[b_1=\frac{S_{xy}}{S_{xx}},\quad b_0=\bar y-b_1\bar x\]
\[e_i=y_i-\hat y_i\]
\[r=\frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}\]

\(S_{xx}=\sum(x_i-\bar x)^2\), \(S_{xy}=\sum(x_i-\bar x)(y_i-\bar y)\). 공분산은 \(S_{xy}/(n-1)\), r은 단위가 없고 −1~1이다. r=0은 비선형 관계나 의존까지 없다는 뜻이 아니다. OLS는 잔차제곱합을 최소화한다.

손계산 연습: x=(1,2,3), y=(2,3,7). 회귀식과 두 번째 점의 잔차는?풀이 확인

평균은 \(\bar x=2,\ \bar y=4\). \(S_{xx}=1+0+1=2\), \(S_{xy}=(-1)(-2)+0(-1)+1(3)=5\).

\[b_1=2.5,\quad b_0=4-2.5(2)=-1,\qquad\hat y=-1+2.5x\]

두 번째 점에서 예측값은 4, 잔차는 실제−예측=3−4=−1이다.

ANOVA는 제곱합과 자유도를 함께

아래는 절편이 포함된 단순선형회귀, 설명변수 1개 기준이다.

변동제곱합자유도평균제곱
전체\(\mathrm{SST}=\sum(y_i-\bar y)^2\)\(n-1\)—
회귀·설명\(\mathrm{SSR}=\sum(\hat y_i-\bar y)^2\)1\(\mathrm{MSR}=\mathrm{SSR}/1\)
잔차\(\mathrm{SSE}=\sum(y_i-\hat y_i)^2\)\(n-2\)\(\mathrm{MSE}=\mathrm{SSE}/(n-2)\)
\[\mathrm{SST}=\mathrm{SSR}+\mathrm{SSE},\quad R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}},\quad F=\frac{\mathrm{MSR}}{\mathrm{MSE}}\]
n=10, SST=80, SSE=20인 연습 자료. SSR·R²·F를 구하면?풀이 확인
\[\mathrm{SSR}=60,\quad R^2=60/80=0.75,\quad F=\frac{60/1}{20/8}=24\]

단순히 SSR/SSE로 F를 계산하지 않는다. 잔차 자유도는 n−2=8이다. 설명력은 표본 내 Y 변동의 75%이며 미래 예측 정답률 75%라는 뜻이 아니다.

원하는 결과 → R 한 문장 직접 복원

05 / 06

먼저 한 줄을 종이에 쓴 뒤 펼친다. 함수명만 쓰지 말고 객체·조건·인자·괄호까지 완성한다.

강의의 객체가 준비된 상태를 가정한다: baseball의 득점 열, datat의 group("Deagu"/"Seoul")·height 열, 동일인을 행별로 맞춘 datat2의 before·after 열, 길이가 같은 수치 벡터 x·y. 아래 파란색은 실제 입력 코드이고 >는 답안에 쓰지 않는 프롬프트다. "Deagu"는 강의 데이터의 철자다.

① 득점을 내림차순으로 정렬해 세 번째 값을 출력한다.풀이 확인
>
sort(baseball$득점, decreasing=TRUE)[3]

sort는 정렬, decreasing=TRUE는 내림차순, [3]은 정렬 결과의 세 번째 원소다. [1]이면 최댓값이다. sort와 TRUE의 대소문자를 지킨다.

② Deagu의 키 자료만 골라 정규성을 검정한다.풀이 확인
>
shapiro.test(datat[datat$group == "Deagu", ]$height)

==는 비교, [조건, ]는 그 조건의 행과 모든 열, $height는 키 열을 선택한다. shapiro.test는 선택된 수치 벡터의 정규성을 검정한다. 등호 하나인 대입과 혼동하지 않는다.

③ Deagu의 모평균 키가 150 cm와 다른지 양측 검정한다.풀이 확인
>
t.test(datat[datat$group == "Deagu", ]$height, mu=150)

선택한 Deagu 키를 mu=150과 비교하는 단일표본 t-검정이다. alternative 생략 시 양측이다.

자기채점 2점: 올바른 집단·열 선택 1점 + 양측 단일표본 검정·기준 평균 150 1점. 공백·유효한 인자 순서 차이는 감점하지 않는다.

④ 두 집단의 평균 키를 강의의 등분산 가정 방식으로 비교한다. 각 줄의 역할도 확인.풀이 확인
>
library(lawstat)

이미 설치된 lawstat 패키지를 현재 R 세션에 불러온다. 매 분석마다 install.packages를 반복할 필요는 없다.

>
levene.test(datat$height, datat$group, location="mean")

height를 group별로 비교해 등분산성을 검정한다. location="mean"은 평균 중심의 강의 Levene 검정이다.

>
t.test(data=datat, height ~ group, var.equal=TRUE)

height가 결과, group이 집단이다. 독립 두 집단의 평균을 등분산 가정의 pooled t-검정으로 비교한다. 패키지 적재·가정 검토가 끝난 뒤 평균 비교 한 줄을 요구하면 마지막 줄만 쓴다.

Shapiro는 각 집단에서 별도로 확인한다. Levene의 비기각이 등분산을 증명하는 것은 아니다. Welch 검정을 요구했다면 var.equal=TRUE를 쓰지 않는다.

⑤ 같은 사람의 전후 변화: after−before를 만든 뒤 차이의 평균이 0인지 검정하는 강의 흐름.풀이 확인
>
datadiff = datat2$after - datat2$before

같은 행의 동일인 자료끼리 after−before를 계산해 datadiff에 저장한다. 음수는 after가 더 낮다는 뜻이다. <- 대입도 유효하다.

>
shapiro.test(datadiff)

차이값의 정규성을 확인한다. 전·후 각각의 정규성만 확인하는 것으로 대체하지 않는다.

>
t.test(datadiff)

차이 평균을 기본 mu=0과 비교한다. 원자료 전후의 대응표본 평균 차이 검정과 동등하다. paired=TRUE인 직접 전후 비교도 같은 차이 방향이면 인정된다.

전체 문장 문제: “차이 벡터가 이미 만들어져 있다”면 마지막 한 줄만, “차이 벡터를 만들라”면 첫 줄만 쓴다. 질문이 요구한 작업을 확인한다.

⑥ x로 y를 설명하는 회귀모형을 만들고 요약과 파란 실선을 표시하는 문장.풀이 확인
