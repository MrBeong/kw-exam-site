공통 원본2개와 기존 study-standards 미러2개, 총4개 MD에 같은 기준을 반영했다. 기존 링크 차이는 유지했다. 이번 과목의 문항 수나 Python 문법을 다른 과목에 그대로 복사하는 기준이 아니다.

1. 실행·오류·자료형·변수/컬렉션·파일 상태를 묻는 객관식/단답형에도 **실제 코드**를 별도 영역에 제시한다. 지문은 판단할 결과를 짧게 묻는다. 명칭 자체를 회상하는 문항에는 정답을 미리 보여 주는 코드를 억지로 붙이지 않는다.
2. 초기값·자료형·함수 정의/호출·데이터, 셀 경계/실행 순서/커널 상태, 파일의 준비 내용·경로·모드·인코딩·개행 등 필요한 조건을 함께 제공한다.
3. 실제 문법·들여쓰기·줄바꿈을 보존하고 코드/입력란/출력/모범답안을 구분한다. 의도적 오류·의사코드·프롬프트의 역할을 명확히 한다.
4. 판단해야 할 출력·예외명·최종 상태를 주석/제목/도움말로 누설하지 않는다. 코드를 작성해 목표 결과를 구현하는 문제의 목표 출력과 구분한다.
5. 원문·전사·실행을 대조하고 문장별/보기별 해설과 MD·HTML·변형을 함께 갱신한다. 실행과 화면을 각각 검증하고, 표시 보완은 기존 풀이 기록을 유지한다.
6. 검색·좁은 화면 내부 스크롤·인쇄·저장/새로고침·이전 기록 보존까지 확인한다. 실제로 수행한 검증만 기록한다.

## 전사에서 보완한 학습 내용

원문91행(내용46문단·빈 줄45개)을 보존하고 교안과 대조했다. 기술 설명43문단은 기존 개념에 연결하고53·55·57행의 화면/프로젝트 대화는 비시험 문맥으로 분리했다. 프로젝트 대화와 기술 설명이 섞인43·85·87·91행은 부분별로 구분했다. 실제 녹화일·원영상·타임코드는 미확인이다.

| 보완 지점 | 반영 내용 |
|---|---|
| 읽기와 문자열 | read의 현재 위치·EOF, text[:20]과 파일 커서의 차이, str/list 반환, readline과 readlines 구분 |
| with 종료 | 파일은 닫히지만 파일 객체 이름/미리 읽은 text는 남음. closed 확인과 닫힌 파일 read 오류 구별 |
| 개행과 제거 범위 | repr의 표시 역할, print의 개행 중복, strip/rstrip의 공백류 범위, 쉼표는 자동 삭제하지 않음 |
| 파일 처리 예제 | 줄 번호 초기화/최종 인원수, 공백 구분과 소수 시간 float, 사람별 total 초기화 |
| 쓰기/복사 | w가 열릴 때 비우는 시점, write의 개행, str 복사와 bytes 복사, 2500바이트의3블록·4읽기 |
| 원문 교정 | 마지막91행 “R은 덮어쓴다”는 기존 교안/문맥에 따라 w로 정리. 전사는 수정하지 않고 교정 설명을 별도 보존 |

**기존98개 개념군 중14곳·관련16문항의 해설을 보완**했다. 개념 노트에는 전체 읽기→슬라이스→EOF→with 종료 상태를 비교하는 실제 실행 코드 예시1개와6문장별 설명·준비 파일·출력을 추가했다. 원래 교안 코드와 연결한 보충 예시라고 라벨을 붙였다. 문제 해설의 보충 메모는 채점 또는 사용자가 “정답·해설 보기”를 누른 뒤 표시한다.

전사31행의 lstrip은 해당 슬라이드에 없는 구두 보충임을 표시했다. 공식 공지의 슬라이드 한정 범위에 새 정답/보기를 추가하지 않았다. 전사의 즉석 근무 시간 수치로 교안/제시 파일을 바꾸지 않았으며, 전화번호/평균/파일 복사 예제의 원래 입력과 결과도 유지했다. 실제 py의 float·빈 파일 평균0 조건과 슬라이드의 int·최소1줄 조건을 구분했다.
