# 교안 예제형 코드 완성 문제 보완 · 2026-10-25

기존 화면의 ‘완성할 동작’ 내용과 코드 빈칸을 보완했다. 화면을 강의 슬라이드처럼 좌우로 재배치하지 않았다. 전체 요구사항을 보고 하나의 프로그램을 완성하는 연습으로 바꾸고, 같은 예제의 단계나 용어 확인을 여러 작은 코드 문제로 나누지 않았다.

현재 **398문항: 코드94 · 개념 단답242 · 객관식62, 코드231빈칸**이다. 교안 원문19문항·52빈칸은 그대로 보존한다. 추가 완성형 연습75문항을 검토해 식·조건식·호출·문장 단위로 다시 선정했다. 관련 부분 연습/변형12개와 용어·단순 시연 성격의9개를 기존 완성형/단답/객관식에 통합 또는 대응했다. 새로운 수치/변수명을 붙여 비슷한 문제를 늘리지 않았다.

## 완성할 동작의 내용

- 입력과 초기 자료, 계산·분기·변경 순서, 반환/출력/파일/최종 상태를 구체적으로 적었다. BP12는 전역 반지름10.0과 원주율3.14, 계산 결과 반환을 지정한다. BP08은 함수명addtwo와 매개변수a·b, 합의 반환,3·5를 전달하는 호출까지 한 문제에서 요구한다.
- 원문19개 예제의 문제 화면을 다시 확인했다. 원문에서 직접 제시한 결과가 있는9문항은 해당 입력별 값/판정/표시 결과만 함께 제시한다. 원문에서 주지 않은 모든 결과를 정답 페이지에서 가져와 붙이지 않았다. BO02의약37.78은 확인용 근삿값이며 실제 코드에 소수점 자리 제한 서식이 없다는 점도 구분한다.
- 추가 연습은 제시된 입력/파일/고정 코드로 검증한 목표 출력·파일 내용·난수 조건 등을 ‘완성할 동작’ 안에 제공한다. 원문 문제의 직접 제시값과 별도 연습용 목표 결과를 구분한다. input 안내 문구까지 가려진 호출에는 해당 문구를 따로 제공한다.
- 출력값 자체를 맞히는 객관식·단답에는 정답 출력을 노출하지 않는다. 상세 정답 코드와 보기별/문장별/실행별 해설도 기존 해설 영역에서 확인한다.

## 코드 빈칸 선정

| 기존 추가 연습의 답 단위 | 보완한 작성 단위 | 의미 |
|---|---|---|
| BP12의r / return |3.14 * r ** 2 / return result|원의 넓이 계산식과 반환 문장|
| BP27의get|BP26안의my_stocks.get("ss", 100)|조회할 키와 기본값을 전달하는 호출식|
| BP07의def|BP08안의def addtwo(a, b)|함수명과 매개변수를 포함한 정의 머리|
| BP43의숫자 인덱스|s[1],s[1][2],s[1][2] = 80|행/열 접근과 실제 원소 갱신|
| BP53의sum / len|sum(scores) / len(scores)|합계와 개수로 평균을 계산하는 식|

같은 문장 안의 작은 조각들은 전체 식/호출로 모으고, 동일 호출을 보이는 그대로 베끼는 반복 빈칸은 정리했다. 문법 단위 자체가 한 단어인break·continue·else는 실제 제어 흐름을 완성하는 프로그램 안에 둔다. 교안 원문19문항에 실제로 있는 함수명·숫자 빈칸을 임의로 바꾸지는 않았다.

## 한 예제는 한 문제

BN9는 입력 문자열의 자료형/연결과 정수 변환 후 덧셈을 한 프로그램에서 비교한다. 원래 두 입력 예제의 문장을 순서대로 유지하여 나이20을 두 번 입력하도록 명시했다. 주식 사전은 BP26에 항목 순회와 키 조회를 모았다. 동일 사전 초기화는 한 번만 두고, 기존 두 예제의 순회·조회 문장은 순서를 지켰다. 두 문제 모두 관련 원본/페이지와 통합 작성 표시를 제공한다.

## 해설·채점·기존 답안

프로그램을 실제로 합친 것은 BN9·BP26의 두 관련 예제뿐이며, 다른 완성 코드는 유지했다. 합친 프로그램은 원래 문장의 순서와 입력 횟수·공유 초기화를 대조하고 독립 실행했다. 모든 새 빈칸은 완성 코드의 해당 식/문장, 정답, 상세 이유, 실제 실행 줄과 연결한다. 기존 파일 전사의 강조 설명도 남긴 BO18·BO19·BC25·BFC03 등의 해설로 연결했다.

키/개수/프로그램이 달라진73문항은 예전 단어 답안을 새 정답으로 인정하지 않는다. 해당 문항과 제외21문항의 이전 답안/정오/초안·재풀이 이전 기록을 설정의 ‘수정 전 답안’에 보관하고 새 시도로 구분한다. 원문19개, 다른 유형304개, 정답이 호환되는2개 코드 문항의 기록은 유지한다. 북마크도 보존한다. 새로고침하거나 재풀이를 종료해도 예전 단어 답안이 새 코드 문제에 되살아나지 않도록 했다.

작성/변경 정책은 practice-source/whole-example-review.json이며, 빌드는 정확한 변경 전 문항에서만 이 수정을 적용한다. whole_example_invariants.py는 현재398문항과 원문 보호, 요구사항/결과 예, 새 빈칸/정답/해설을 별도로 검사하고 과거 단계 대조에 한해 명시한 변경 전 기록을 복원한다. 보관본은 previous/before-whole-example-2026-10-25/다.
