## 공지·문제 유형과의 일치

공지의 개념 단답·4/5지선다·코드 빈칸을 유지한다. 서술형이나 들여쓰기 직접 작성은 추가하지 않았다. 한국어 개념을 임의 영문 번역시키지 않고, 새 용어 회상은 기존 BSA027의 강의 영문 표기 Dynamic Typing을 사용한다.

마지막5분은 기존 은행의 BM40·BM51·BM18·BSA027·BOP09를 재사용한다.4/5지선다에는 기존 보기 순서·정답·모든 보기의 판단 근거를 함께 반영한다. BM51의 /가 출력 줄 구분이라는 조건과 BM18의 stops 전체 코드도 풀이 전에 제공한다. 출력 예측·용어 답은 해설을 열기 전에는 숨긴다.

선택 빈칸은 다음과 같이 구분했다.

- BO17: 교안 원문 빈칸 그대로. 단어별 기존 횟수의 키/초기값을 회상한다.
- BC32: 교안 예제 기반 재선정. return 1,2,3과 a,b,c=sub()라는 문장 전체를 작성한다.
- BC24: 교안 예제 기반 재선정. 실제 hours.txt, 이름·시간의 위치, 사람별 누적과 소수점 첫째 자리 요구를 모두 제시한다.

총 회상6문항/18칸 중 처음3문항/9칸이 필수 경로이며 나머지3문항/9칸은 필요할 때만 펼친다. 재선정 문항을 원문 빈칸으로 잘못 표시하지 않는다. 새 시험 문제나 문항 수를 공지처럼 확정하지 않는다.
