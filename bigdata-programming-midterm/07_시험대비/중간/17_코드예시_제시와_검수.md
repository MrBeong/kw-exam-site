## 학생 화면에서 달라진 점

- BM02는 같은 커널의 셀1→2→3 실행 순서를 지문과 코드 상자에 표시한다. 각 셀의 입력 코드를 Python 주석으로 구분하고 실제 문장은 별도 줄에 적는다. 셀의 자동 표시와 저장값의 차이를 판단할 수 있게 한다.
- 함수 문제에는 def·매개변수·반환·실제 호출을, 컬렉션 문제에는 초기값과 변경 문장의 순서를, 파일 문제에는 열기 모드·블록·읽기 위치·닫힘 조건을 코드로 제시한다.
- 지문은 무엇을 답할지 짧게 묻는다. 필요한 조건은 코드와 지문에 남기고, 정답인 출력·예외 이름이나 판단을 코드 주석에 미리 쓰지 않는다. 예외 발생을 묻는 코드는 실제 Python 문법으로 작성하고 의도한 런타임 오류가 나는지 확인했다.
- 커널 재시작 문제는 새 커널에서 해당 셀만 실행한다는 조건을 표시한다. 일반 파일 예제는 필요한 초기 파일을 코드에서 만들거나 빈 파일이라는 조건을 명시한다. 상대경로 문제는 현재 작업 폴더와 스크립트 폴더를 구분해 제시한다.
- 단답형 BS16은 답인 쉼표를 (1,)에 미리 보여 주던 구성을 바꿔, (1)을 한 원소 튜플로 만들기 위한 기호를 묻는다.
- 자료구조·파일 모드·Traceback 위치·편집/실행 역할·키의 적합성처럼 코드 실행 과정 자체를 묻지 않는 객관식5문항은 불필요한 예시를 억지로 붙이지 않았다. 명칭을 회상하는 단답에도 답 이름이 들어간 완성 코드를 붙이지 않는다.
- 코드로 옮긴 내용도 검색할 수 있다. 검색은 지문·문항 ID와 제시 코드(빈칸형은 가린 코드)를 대상으로 한다.

이 예시는 강의 문법과 기존 문항 조건을 바탕으로 구성한 문제용 코드다. 모두 강의 슬라이드의 코드를 문자 그대로 옮긴 예제라고 표시하지 않는다. 실제 실행 서버를 웹페이지에 추가한 것은 아니다.

## 정답·기록·생성본

정답·객관식 보기/순서/정답 위치·각 보기 해설·개념 대응·문항 ID를 유지했다. 이번 표시 보완 때문에 답안을 초기화하지 않는다. 기존 답안38개·다른 코드 문항의 초안·북마크를 독립 검수 프로필에 재현해 그대로 남는지 확인했다. 이전 품질 보완에서 적용하던 변경 전 답안 보관 규칙은 유지한다.

이외154문항은 이전과 문자열/구조가 동일하다. 문제 MD와 정답/해설 MD에도 같은 제시 코드를 생성했다. 강의자료·원본 Notebook·수업 py는 변경하지 않았고 GitHub 푸시는 하지 않았다.
