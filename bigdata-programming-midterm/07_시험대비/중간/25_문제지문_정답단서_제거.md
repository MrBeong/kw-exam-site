# 문제 지문의 정답 단서 제거 · 2026-10-24

BC06의 제목에 빈칸 정답인 continue·break가 그대로 적혀 있었다. 같은 문제가 다른 문항에도 있는지 전체437문항을 확인하고, **코드 빈칸142문항의 공개 전 지문/목표 설명을 다시 작성**했다. 문항 수와370개 빈칸·코드·정답·채점·저장 기록은 그대로다.

[문제 풀기](practice/index.html) · [문안 원본](practice-source/question-display.json) · [정적 대조](final-audit/answer-hint-static.json) · [전체 화면/채점](final-audit/browser-answer-hints.json)

## 풀이 전과 해설의 구분

코드 빈칸의 제목은 **“다음 코드의 빈칸을 완성하시오.”**로 통일했다. 그 아래에는 완성할 동작을 먼저 두고, 필요한 입력 순서·초기 조건·준비 파일과 실제 빈칸 코드를 제시한다. 출제 구분은 원문/추가 연습/Notebook/실습의 범주만 표시한다.

| 발견한 단서 | 수정 |
|---|---|
| BC06의 제목에 continue·break | 중립 지문과 “3은 더하지 않고 6에서 반복을 끝낸다”는 목표 동작으로 변경 |
| 메서드·키워드를 나열한 제목 | remove/pop/del, get, items 등을 제목에 미리 쓰지 않음 |
| 특정 원문 정답 표기 지시 | BC11의 “끝값5”, BN18의 “끝값4”, BFC04의 실수 리터럴 표기 지시 등을 공개 전 설명에서 제거 |
| 풀이를 설명하는 목표 문장 | float·내장 함수명, 제자리 변경/재연결의 결론, 틀린 방식과의 비교 등은 지시할 동작과 구분 |
| 원문 구분의 상세 문구 | BP48의 메서드명 등을 포함한 상세 출처 설명은 해설 뒤에 두고 풀이 전에는 범주명만 표시 |
| 예상 출력·최종 상태·파일 결과 | 코드 문제의 풀이 전 결과 패널을 제거. 실제 실행값·최종 파일·상태는 해설에서 확인 |
| Notebook 자동 표시 설명·원문 표기 차이 | 공개 전 보조 힌트로 제시하지 않고 해설 열람/채점 후 확인 |

미채점 상태에서는 정답·계산된 결과·상세 해설을 문제 본문에 생성하지 않는다. 기존에 채점했거나 사용자가 명시적으로 해설을 연 문항에는 기존 규칙대로 해설이 보인다. 저장한 사용자 답을 임의로 지우지 않는다.

## 문제를 풀 정보는 유지

정답 단서를 없앤다는 이유로 과제 데이터를 삭제하지 않았다. 변경할 가격·점수, 인수가 없을 때 요구하는 값, 조회할 단어, 저장할 문장, 한 번에 처리할 바이트 수·입력 파일·개행 조건은 목표 동작/필수 자료에 남겼다.

예를 들어 BO08의 5000·15000·140000, BO12의 새 기말 점수95, BO14의 재고 수량, BO15의 단어 대응, BE11의 기본 치수, BP27의 조회 대상·기본 안내값, BP31의 두 문장, BP47의 파일 크기·최대 처리량을 유지한다. 이는 목표 프로그램을 결정하는 입력/요구 사항이며, 사용할 메서드·연산자나 계산된 결론을 알려 주는 설명과 구분한다.

강의자료의 코드에 원래 있는 변수명·함수명·반복되는 문장도 유지한다. 원문19문항·52빈칸은 이전 원문 대조 결과와 동일하다. 문안 수정으로 정답을 바꾸거나 다른 코드의 빈칸을 새로 만들지 않았다. 엄격한 원문 표기 채점과 실행상 동등한 다른 표현의 구분은 기존대로 해설에서 설명한다.

## 상세 해설·검색·문서

모든 보기별 근거, 빈칸별 이유·완성 문장, 문장별 설명, 실제 실행 과정·출력·오류·최종 파일/변수 상태는 그대로다. 표시용 설명은 명시적 해설 열람 또는 채점 뒤에 보이며, 닫고 다시 작성할 수 있다.

시험대비 HTML과 문제 MD는 같은 공개용 지문/목표 원본을 사용한다. 정답 MD에는 목표와 풀이 주제를 함께 두고 기존 상세 설명을 유지한다. 검색도 공개 지문·목표 동작·실제로 제시한 코드를 사용하여, 숨긴 풀이 제목의 정답 키워드로 문제를 찾게 하지 않는다. ID 검색은 그대로다.

원본은 practice-source/question-display.json이다. 채점 은행의437개 객체와 실행 해설은 그대로 보존하고 별도의 공개용 문안을 연결했다. 생성 HTML만 수정하지 않았다. 공통 제작/디자인 MD와 기존 미러4곳에도 중립 코드 지문·풀이 전/후 구분·필수 데이터 유지·검색/문제 MD 검수 기준을 반영했다.

단순 정답 문자열 검색은 선별용이다. 목표 문장을 문항별로 검토하고, 주어진 변수/과제 데이터와 풀이 단서를 구분했다. 예를 들어 BP32/33의 x는 제시 코드에서 계속 사용하는 이름이므로 삭제하지 않았다. 단답241·객관식54는 기존 질문/정답을 유지하면서 공개 전 해설 노출과 정상 채점을 확인했다.

```sh
node practice-source/build.mjs
python3 practice-source/verify-answer-hints.py
python3 practice-source/verify.py
python3 practice-source/verify-detailed-solutions.py
```

화면 검수는 실제 사용자 브라우저와 분리된 프로필에서 수행했다. 이전 상태는 previous/before-answer-hint-cleanup-2026-10-24/에 보존했다. 원문 자료·사용자 커널·기존 풀이 저장소는 건드리지 않았으며, 커밋·푸시는 하지 않았다.

창을 새로고침하면 반영된다. 이전에 저장한 답안/해설 열람 상태는 유지하며, 미채점 또는 다시 풀기 상태에서 새 문제 문안을 확인할 수 있다.
