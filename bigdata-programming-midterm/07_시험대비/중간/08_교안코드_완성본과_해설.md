## E01 · 두 수의 합계와 평균

근거: [260914_빅데이터프로그래밍.pdf · PDF p.34, 35, 36](../../01_강의자료/260914_%EB%B9%85%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.pdf#page=34) · [BD-023 개념](01_핵심개념과_문법.md#BD-023)

교안 완성 코드(빈칸 슬라이드는 후속 해설로 완성), 줄바꿈·공백은 읽기 좋게 정돈.

입력 순서: `10` → `15`

```python
a = float(input("첫 수: "))
b = float(input("두 번째 수: "))
total = a + b
average = total / 2
print("합계:", total)
print("평균:", average)
```

| 줄 | 의미 |
|---|---|
| 1–2 | input의 문자열을 float로 변환해 각각 a,b에 저장한다. 입력10과15는10.0,15.0이 된다. |
| 3 | 현재 두 수를 더해 total=25.0을 만든다. |
| 4 | 합계를2로 나누어 average=12.5를 저장한다. |
| 5–6 | 합계와 평균을 각각 출력한다. 쉼표 사이에는 기본 공백이 붙는다. |

출력:

```text
합계: 25.0
평균: 12.5
```

입력 순서: `100`

```python
ftemp = int(input("화씨온도: "))
ctemp = (ftemp - 32.0) * 5.0 / 9.0
print("섭씨온도:", ctemp)
```

| 줄 | 의미 |

| 3 | 계산한 실수를 출력한다. print 형식과 계산값을 구분한다. |

출력:

```text
섭씨온도: 37.77777777777778
```

주의·원문 차이: 수업 노트북 12셀은 (ftemp-32)*5/9다. 같은 정수 입력에서 같은 결과를 내는 교안 표기 차이이며 둘 다 보존한다.

## E03 · 윤년 판별

근거: [260916_빅데이터프로그래밍.pdf · PDF p.14, 15, 16](../../01_강의자료/260916_%EB%B9%85%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.pdf#page=14) · [BD-033 개념](01_핵심개념과_문법.md#BD-033)

수업 노트북 13셀 / PDF 빈칸을 직접 조건식으로 완성

입력 순서: `2000`

```python
year = int(input("연도: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(year, "년은 윤년입니다.")
else:
    print(year, "년은 윤년이 아닙니다.")
```

| 줄 | 의미 |
|---|---|
| 1 | 문자열 연도를 정수로 변환한다. |
| 2 | 4의 배수·100의 배수 제외를 and로 묶고 400의 배수 포함을 or로 연결한다. |
| 3 | 조건이 참인 경우에만 실행한다. |
| 4–5 | 앞 조건이 거짓일 때만 평년 문장을 출력한다. else에는 조건식이 없다. |

출력:

```text
2000 년은 윤년입니다.
```

주의·원문 차이: PDF p.15는 같은 조건을 is_leap 변수에 저장한 변형이다. 직접 if 조건과 따로 구분했다.

## E04 · 유클리드 알고리즘

근거: [260916_빅데이터프로그래밍.pdf · PDF p.22, 23, 24, 25](../../01_강의자료/260916_%EB%B9%85%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.pdf#page=22) · [BD-036 개념](01_핵심개념과_문법.md#BD-036)

교안 완성 코드(빈칸 슬라이드는 후속 해설로 완성), 줄바꿈·공백은 읽기 좋게 정돈.

입력 순서: `48` → `18`

```python
x = int(input("큰 정수: "))
y = int(input("작은 정수: "))
while y != 0:
    r = x % y
    x, y = y, r
print("최대 공약수는 " + str(x) + "입니다")
```

| 줄 | 의미 |
|---|---|
| 1–2 | 양의 두 정수를 입력받아 초기 x,y를 정한다. |
| 3 | y가0인지 본문 실행 전에 검사한다. 0이면 나머지를 구하지 않고 종료한다. |
| 4 | 갱신 전 두 수의 나머지 r을 계산한다. |
| 5 | 갱신 전 y와 r을 순서대로 x,y에 연결한다. |
| 6 | 종료 후 x를 문자열로 바꾸어 출력한다. 이때 y는0이다. |

출력:

```text
최대 공약수는 6입니다
```

| 시작 x | 시작 y | r | 다음 (x,y) |
|---|---|---|---|
| 48 | 18 | 12 | (18,12) |
| 18 | 12 | 6 | (12,6) |
| 12 | 6 | 0 | (6,0) |
| 6 | 0 | 검사만 | 종료 |

## E05 · 팩토리얼

근거: [260916_빅데이터프로그래밍.pdf · PDF p.29, 30, 31, 32](../../01_강의자료/260916_%EB%B9%85%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.pdf#page=29) · [BD-039 개념](01_핵심개념과_문법.md#BD-039)

입력 순서: `4`

```python
n = int(input("정수: "))
fact = 1
for i in range(1, n + 1):
    fact = fact * i
print(n, "!은", fact, "이다.")
```

| 줄 | 의미 |
|---|---|
| 1 | 0 이상의 정수를 입력받는다. |
| 2 | 곱셈 항등값1로 누적값을 초기화한다. |
| 3 | 끝값을 n+1로 지정해 실제 i는1부터 n까지 받는다. |
| 4 | 이전 fact에 현재 i를 곱한 값을 다시 저장한다. |
| 5 | 전체 반복이 끝난 후 한 번 출력한다. |

출력:

```text
4 !은 24 이다.
```

| i | 갱신 전 fact | 갱신 후 fact |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 1 | 2 |
| 3 | 2 | 6 |
| 4 | 6 | 24 |

## E06 · continue와 break가 섞인 누적

근거: [260916_빅데이터프로그래밍.pdf · PDF p.36, 37](../../01_강의자료/260916_%EB%B9%85%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.pdf#page=36) · [BD-041 개념](01_핵심개념과_문법.md#BD-041)

교안 완성 코드(빈칸 슬라이드는 후속 해설로 완성), 줄바꿈·공백은 읽기 좋게 정돈.

```python
total = 0
for i in range(1, 8):
    if i == 3:
        continue
    if i == 6:
        break
    total = total + i
print(total, i)
```

| 줄 | 의미 |
|---|---|
| 1 | 합계 초기값0. |
| 2 | 범위는1부터7까지지만 조건문 때문에 모두 누적하지는 않는다. |
| 3–4 | i=3일 때 남은 본문을 건너뛰어 합계에 넣지 않는다. |
| 5–6 | i=6일 때 반복 전체를 종료하므로6,7은 더하지 않는다. |
| 7 | 이 줄에 도달한1,2,4,5만 누적한다. |
| 8 | 합계12와 종료를 일으킨 제어 변수6을 출력한다. |

출력:

```text
12 6
```
