# 교안 원문 빈칸과 예제 기반 문제의 일치 검수 · 2026-10-24

**기존 코드 빈칸이 모두 원문 그대로였던 것은 아니다.** 교안의 빈칸 실습19개에 연결된 기존 문항 중, 빈칸까지 포함한 템플릿이 공백 정돈 후 같은 것은2개였다. 나머지17개에는 빈칸 수·가리는 범위 또는 고정 코드의 차이가 있었다. 실행 결과가 같거나 같은 개념을 연습한다는 사실을 원문 일치로 잘못 묶지 않았다.

원문을 그대로 연습할 수 있도록 **BO01–BO19,19문항·52빈칸**을 추가했다. 기존418문항과 그 정답·빈칸·보기는 변경하지 않았다. 현재 전체437문항(코드142·단답241·객관식54), 코드370빈칸이다. 기존 문항은 예제 기반 연습으로 남기며 풀이 전 구분을 표시한다.

## 원문19페이지 전수 대조

코드 교안7개340쪽을 밑줄 빈칸 표기로 다시 검색해19쪽·52빈칸을 확인했다. **19쪽 모두 전체 화면으로 직접 대조**했다. 원문에 고정된 변수/함수명·수치·문자열·연산자·문장 순서와 빈칸의 수·위치·범위를 확인하고, 실제 Python의 들여쓰기와 화면 폭 줄바꿈은 정돈했다. 텍스트 공백 병합 검사는 선별/재현용이며 이 검사의 성공만으로 이미지·들여쓰기 검수를 대체하지 않는다.

원문 해설의 표기를 재현하는 연습이다. 예를 들어 정류장 문제의 끝 경계5와 Notebook의4가 같은 결과를 만들 수 있어도, 두 원문을 섞지 않고 각각의 표기와 이유를 해설한다. 실제 교수 정답표나 출제 문제를 확보했다는 뜻은 아니다.

## 다른 예제 기반 문제의 확인

- 기존 코드123문항은 풀이 전에 **교안 예제 기반·빈칸 재선정**, **교안 기반 추가 연습**, **수업 Notebook**, **별도 수업 실습**을 구분해 표시했다. 원문 빈칸19문항과 혼동하게 하는 기존 포괄적 원문 설명은 최신 구분 문구로 대신 표시한다. 추가 연습이라는 표시가 코드가 반드시 원문과 다르다는 뜻은 아니다. 빈칸 위치가 원래 인쇄된 위치라는 보장을 하지 않는다는 구분이다.
- 원문과의 코드 문장 대조에서는 PDF 텍스트만으로 찾을 수 없는 스크린샷이 있음을 구분했다. 예를 들어 BP48의 `Path.cwd().name`, `exists`, `read_text`는 BIG-019 p.9의 실제 코드 화면과 일치함을 확인했다. 텍스트 검색 실패를 새 문법의 근거로 처리하지 않았다. 줄별 텍스트 후보 대조 결과는 [별도 기록](final-audit/lecture-code-text-comparison.json)에 있으며 문자 공백을 접은 후보 검사이지 전체 코드 일치 판정표가 아니다.
- 기존 원본 대응 검사에서 수업 Notebook22코드 셀·py3개·교안111예제군의 대응을 다시 확인했다. Notebook과 PDF가 다른 표기, 실습 py만의 보충 문법은 기존 구분을 유지했다. 원문 Notebook/py/PDF는 수정하지 않았다.
- **전체 코드 빈칸142문항·370정답을 넣어 실제 실행**했다. 목표 출력·생성 파일·반복/난수 조건·오류 없는 실행을 확인했다. 객관식/단답까지 코드가 있는242문항의 상세 실행2,130단계도 다시 생성/검증했다. 기존 타 유형의 보기·정답·채점 기준은 변경하지 않았다.

## 화면·저장과 재현

새로고침한 뒤 **코드 빈칸 → 설정 → 준비 범위 ‘교안 원문 빈칸’**을 선택하면 원문19문항만 나온다. 전체 단원·검색 비움으로 보면19문항이다. 기존 저장 필터는 유지하며 다른 유형으로 이동할 때 코드 전용 범위를 해제해 단답/객관식이 사라지지 않도록 했다. 원문/추가 연습 구분은 정답을 열기 전에도 보인다.

긴 식 전체가 들어가는 답안은 **사용자가 입력한 길이**에 맞춰 입력창을 넓힌다. 아직 입력하지 않은 정답의 길이를 이용해 단서를 주지 않는다. 긴 코드 줄은 코드 창 안에서 가로로 읽으며, 채점 뒤에도 식의 뒤가 잘리지 않는다. 기존 채점 방식인 공백·기호 포함 코드 표기 일치/부분점수 없음은 유지했다.

검수는 격리된 임시 폴더와 독립 브라우저 프로필에서 수행했다. 사용자 실제 풀이 창의 저장소나 커널은 조작하지 않았다. 이전418문항 객체가 모두 동일하므로 이번 작업을 위한 답안 초기화/재채점 버전 변경은 없다.

원본과 재현:

```sh
node practice-source/build.mjs
python3 practice-source/verify-lecture-original-blanks.py
python3 practice-source/verify.py
python3 practice-source/verify-detailed-solutions.py
```

원문 문항/빈칸/해설은 `lecture-blank-questions.json`, 추가 연결은 `lecture-blank-questions.mjs`, 화면 구분은 `lecture-code-kinds.json`에 보존했다. 생성 HTML만 수정하지 않았다. 공통 제작/디자인 MD와 기존 미러에도 원문 빈칸의 수·위치·범위/고정 코드 대조, 변형/Notebook 구분, 전용 필터와 답안 보존 기준을 반영했다.

이번 검수의 신규 시각 확인은 원문19쪽·해설2쪽·스크린샷1쪽,22쪽이다. 전체381쪽을 새로 시각 검수했다고 표시하지 않는다. 미확보 실습 Notebook·최종 출제 페이지·실제 교수 정답표·원영상/타임코드는 여전히 미확인이다. 커밋·푸시는 하지 않았다.
