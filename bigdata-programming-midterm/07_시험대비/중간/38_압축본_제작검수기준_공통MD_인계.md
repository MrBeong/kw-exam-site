## 다음 과목에 적용할 절차

| 단계 | 재사용할 기준 |
|---|---|
| 구성 | 단서→판단/작성→결과→실수/검산의 필수 경로. 전체 코드/응용 회상·낮은 우선순위 사실은 선택 영역. 요청 시간과 실제 강조에 맞춘 배분. |
| 누락 | 큰 개념군뿐 아니라 하위 예제·독립 판단/경계·전사 강조를 실제 본문/코드에 대응. 태그/개수/이름만 맞으면 완료로 보지 않음. 미확인/범위 밖·전사 오인식 구분. |
| 유형 | 공지된 형식을 실제로 수행. 객관식은 보기·선택 지시·모든 보기 근거, 단답은 숨긴 직접 회상, 코드 빈칸은 의미 있는 작성 단위. 제외 유형·과거 과목의 조합을 자동 추가하지 않음. |
| 코드 | 원문 빈칸/재선정 구별, 원문 문법·들여쓰기·위치 보존. 모든 빈칸을 풀 입력·인수·조건·파일을 답보다 먼저 제공. |
| 실행 | 독립 기대값과 실제 런타임/컴파일러의 출력·자료형/상태·오류·파일 비교. 경계·옵션 조합·난수 불변 조건·원본 불변성과 읽기/기록 횟수 확인. |
| 결과 표시 | 실행 통과와 학생 화면 완결성은 별개. 접힌 코드에도 실제 출력/출력 없음/파일 기록·실행 근거를 같은 창에서 확인. 명시적 열람 전 정답 숨김. |
| UI/보존 | 일괄 열기 때 필요한 상위 접힘도 열기. 키보드·모든 영역 세로 휠·내부 가로 읽기·좁은 화면·인쇄/접힘 복원. 별도 검수 프로필과 기존 답안/초안·북마크·타이머·재풀이 기록 보존. |
| 완료 | 편집 원본/빌더·HTML·MD·대응표·진입/검수 기록의 일치, 확인 범위와 현재/과거 결과 구분. 문항/개념/언어/시간·통과 수치를 다음 과목의 할당량으로 복사하지 않음. |

이번에 보완한 [압축본 재검수 사례](37_압축본_강조점과_유형_재검수.md)의 나이 차감·정렬 조건·실제4/5지선다/단답·선택 빈칸·출력 패널·접힘 동작을 일반적인 기준으로 정리했다. 빅데이터프로그래밍의 개념 수·문항 수·Python·엄격 표기 채점을 다른 과목의 고정 조건으로 만들지 않았다.
