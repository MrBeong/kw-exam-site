# 빈칸·출력추적 풀이전략

교수 전사에 윤년·팩토리얼 빈칸형을 시험으로 고려한다는 설명이 있고 사용자가 PDF 밑줄·빈칸 방식의 출제를 알려주었다. [문제](03_예상문제.md)는 **교안 예제를 바탕으로 학습 파트너가 재구성한 연습문제**이며 교수 실제 문제/기출은 아니다.

1. 빈칸 앞뒤의 **입력 자료형→처리 목표→출력 형태**를 표시한다. `input()` 뒤 계산이면 `int/float`, 평균/온도는 `/`, 정수 몫이면 `//`인지 확인한다.
2. 조건식은 경계 테스트를 만든다. 윤년은 2012,1900,2000,2023; 점수 등급은 82609090/95를 바꿔 보며 `if/elif` 순서를 확인한다.
3. 반복은 표를 만든다: `반복 직전 변수→조건→본문 실행→갱신→다음 조건`. `range`의 stop 제외, `break/continue` 뒤 실행되지 않은 문장을 표시한다.
4. 함수는 정의/호출, 매개변수/인수, `print/return`, 지역 이름/공유 객체, return 들여쓰기 위치를 분리한다.
5. 리스트·딕셔너리는 각 줄 후 상태를 복사해 적고 **원본 변경 여부**와 반환값을 따로 기록한다. `sort()`는 원본 변경+None, `sorted()`는 새 리스트; `get()`은 조회만 한다.
6. 출력은 문자열의 따옴표가 실제 화면에 보이는지, print 인수 공백, float 표시, 리스트/딕셔너리 모양, 오류를 확인한다. 집합의 비결정적 출력 순서는 `sorted()`가 있는지 먼저 본다.
7. 노트북은 화면 순서가 실제 실행 순서가 아닐 수 있다. 입력·난수가 포함된 셀의 결과를 단일 고정값으로 외우지 않는다.
