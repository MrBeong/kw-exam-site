## 원문 차이

- PDF 뷰어 쪽수와 인쇄 슬라이드 번호가 다를 수 있어 뷰어 기준으로 통일했다.
- PDF stops[1:5:2]와 수업 Notebook stops[1:4:2]는 같은 B,D 출력이다.
- PDF 화씨 식은 실수 리터럴32.0/5.0/9.0, Notebook은32/5/9이며 원문 둘을 구분했다.
- 윤년 PDF는 is_leap 변형, Notebook은 직접 if 조건이다.
- 점수 평균 PDF는 int·최소1줄, 실습 py는 float·빈 파일 처리가 추가되어 있다. 시험 모범 코드는 PDF를 유지했다.
- bridge.png의 교안 화면 크기는70404바이트다. 제공 fixture의 실제 크기와 다르므로 같은 파일이라고 단정하지 않는다. 바이너리 복사 로직은 임시 복사본으로 실행했다.
- min("Hello world")의 결과는 빈 문자열이 아닌 공백 한 칸이다. 실제 입력/출력 화면과 실행으로 확인했다.
- 전사에서 float/None/함수명이 오인식된 문구는 그대로 사실화하지 않고 실행 가능한 교안·노트북을 우선했다.

## 코드 실행

실행 결과와 환경은 [실행검증.json](concept-source/실행검증.json)에 기록한다. 검증 스크립트는 concept-source/verify.py이며 임시 폴더에서만 출력 파일을 만든다. 실제 사용자의 Notebook 커널/설치 검증과 독립 코드 실행 검증은 다르다.
