# 시험대비 창 안의 상세 해설 · 2026-10-24

PDF를 따로 열지 않아도 문제를 푼 창에서 정답의 근거와 실행 과정을 이해할 수 있도록 전체204문항을 보완했다. 문제·정답·보기 순서·기존 문항 객체·저장 키/버전은 유지했다. GitHub 커밋·푸시는 하지 않았다.

## 학생이 읽는 해설

- **전체204문항**: 코드123·단답27·객관식54에 문항별 풀이를 작성했다. 총496개 풀이 문단이며, 다른 예제의 개념 설명을 그대로 붙이는 대신 해당 문항의 값·실행 조건·혼동 지점을 설명한다.
- **객관식54문항의218개 보기**: 원래 보기별 판정에 상세 설명을 더했다. 오답이 어떤 대입 순서·연산자·자료형·경계값·파일 상태를 혼동했는지 설명한다. 정답의 도출 과정은 별도 「상세 풀이 과정」에서도 읽는다.
- **코드318개 빈칸**: 정답 코드·선택 이유·그 빈칸을 넣은 완성 문장을 함께 보여 준다. 해당 줄에 값 변화나 출력이 있으면 실제 실행 예도 표시한다. 선언·else처럼 별도의 추적 이벤트가 없는 문법, 이번 입력에서 지나지 않은 분기도 기존 문장별 해설에서 역할을 설명한다.
- **코드 문장별 설명**: 완성 코드와 줄별 해설을 기본으로 펼친다. 실제 Python 문법·들여쓰기·기존 빈칸 형식은 유지한다.
- **코드가 있는181문항**: 작성자가 제시한 코드를 독립 Python 환경에서 실행해1,735단계의 상태 변화·분기·반환·추가 출력을 기록했다. 함수 인수 전달, 지역/전역 이름, 원본 변경과 새 객체 연결을 구분한다.
- **출력·오류·파일**: 최종 표준출력과 공백/개행을 보이는 표현을 함께 표시한다. 의도적인 예외12건은 오류명·발생 줄·중단 지점을 표시한다. 해당 문항의 최종 변수 상태와 작성한 텍스트 파일도 창 안에서 확인한다.

해설은 채점하거나 「정답·해설 보기」를 눌렀을 때만 나타난다. 미채점 열람은 기존 답안·정오 기록을 바꾸지 않으며 닫고 계속 작성할 수 있다. PDF는 「원문 출처 · 선택 확인」 안의 선택 링크로 유지한다. 해설을 이해하기 위해 PDF를 먼저 열 필요는 없다.

긴 반복은 처음10단계와 마지막6단계를 먼저 보여 주고 중간 모든 단계는 같은 창에서 펼친다. 중간 기록을 삭제하지 않는다. 긴 변수값의 표시 생략과 집합 원소의 표시 순서도 명시한다. 인쇄할 때는 접은 실행 기록을 펼치고 인쇄 후 원래 접힘 상태로 복원한다.

## 실행을 해석할 때의 조건

- BM01은 화면 배치 순서가 아닌 문제에 지정한 셀 A→C→B로 실행한다. 제시 코드의 줄 번호를 유지한다.
- BM05는 정답 대입문을 앞에 넣은 경우, BM45는 정답 갱신문을 반복 몸체에 넣은 경우를 실행하고 이를 명시한다. 미완성 BM45를 그대로 무한 반복시키지 않는다.
- 난수 문항은 실제로 실행한 한 예시로 표시한다. 특정 난수를 문제의 추가 전제나 유일 정답으로 바꾸지 않는다. 암호는 문자 집합/길이, 주사위는 정수 범위/횟수로 별도 확인한다.
- 표준출력은 `print`가 만든 출력이다. Notebook의 자동 식 표시와는 구별한다. BM02에서 식의 계산값7과 저장된 x=3을 별도로 표시한다.
- 원본 PDF·강의 실습 파일·사용자 커널을 수정하지 않는다. 작성자 코드 실행과 파일 생성은 새 임시 폴더에서만 수행한다. 학생이 입력한 문자열을 Python 코드로 실행하지 않는다.
