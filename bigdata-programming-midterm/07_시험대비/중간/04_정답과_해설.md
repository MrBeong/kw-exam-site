# 빈칸·출력 예상문제 정답과 해설

[문제](03_예상문제.md)는 학습 파트너 제작이며 교수 원문 정답이 아니다. PDF 빈칸의 정확한 배치·문장은 [원본 색인](../../04_실습과_코드/교안_예제_색인.md)에서 확인한다. 입력/난수 결과는 조건을 명시한 경우만 고정값으로 쓴다.

1. x=3 상태의 두 출력은 `3`, `7`; 이후 x=20. 재시작 후 x가 정의되지 않았다면 **NameError**. 마지막 표현식 7의 노트북 자동 표시와 `print` 출력은 별개다.
2. 입력20이면 age는 str `"20"`, 결과 `"201"`. `int(age)+1`은 정수21. 숫자가 아닌 문자열에는 ValueError 가능.
3. 두 빈칸 `float`, `float`, `a+b`, `total/2`. 3.5+4.5=8.0, 평균4.0. `input` 문자열을 바로 `+`하면 연결이므로 변환 필수.
4. `ctemp=(ftemp-32)*5/9`. 100→37.777…°C, 32→0°C. `int('100.5')`는 ValueError; 소수 화씨를 받으려면 float 변환. 같은 온도 단위를 식에 넣고 결과는 섭씨.
5. 순서대로 `11` int, `'74'` str, `1` int, `3` int, `True` bool, `1` int(XOR), `8` int(거듭제곱). `^`와 `**`를 혼동하지 않는다.
6. `unknown`: NameError, `'3'+2`: TypeError, `1/0`: ZeroDivisionError, `int('abc')`: ValueError, `[1][3]`: IndexError, dict 없는 키: KeyError. 오류명을 외우기보다 해당 줄에서 이름·자료형·분모·변환·인덱스·키를 확인한다.
7. `(year%4==0 and year%100!=0) or year%400==0`. 2012 윤년, 1900 평년, 2000 윤년, 2023 평년. 100의 배수는 기본 제외지만 400 배수는 포함.
8. 원래 순서: 95→A,85→B,79→C. `if score>=80`을 먼저 두면 95는 B로 들어가 뒤의 `elif >=90`을 검사하지 않는다. 독립 if 둘과도 다르다.
9. 반복 뒤 `total=1+2+3=6`, i=4. 증가문을 먼저 두면 2+3+4=9. 표를 그리면 종료 조건을 만든 4는 원래 합계에 없음을 알 수 있다.
10. `r=x%y`; `x,y=y,r`. (48,18)→(18,12)→(12,6)→(6,0), 최종 x=6. `(x,y)` 동시 대입은 오른쪽 기존 값을 먼저 평가한다.
11. `fact=1`, `range(1,n+1)`, `fact=fact*i` 또는 `fact*=i`. n=0→1,4→24,10→3628800. `range` stop 제외, 곱의 항등원은 1.
12. 더해진 i=1,2,4,5, total=12. i=3에서 continue, i=6에서 break여서 최종 i=6, 7은 실행되지 않는다. `print(total,i)`는 루프 밖이므로 `12 6`.
13. `random.randrange(len(alphabet))`, `alphabet[index]`. 함수 한 번 길이6 문자열, 세 호출은 세 반환값. 특정 문자열·서로 다름은 보장되지 않는다. `return`은 6회 반복 **뒤**. `random`은 이 실습용이며 인증 목적 아님.
14. `return result`, `calculate_area(r)`, `.2f`. r2→`넓이: 12.56`, r10→`넓이: 314.00`. result는 지역, area는 밖에 저장된 반환값. r이 길이 단위면 area는 그 제곱 단위.
15. 문자열은 불변이라 함수 안 지역 이름을 새 문자열에 연결해도 호출자 원본 문자열은 그대로. 공유 리스트에 `append`하면 객체 내부가 바뀌어 호출자에게 보인다. 리스트 이름을 새 리스트에 **재연결**하면 원본 객체는 바뀌지 않을 수 있다.
16. `[1:4:2]`, `[-2:]`, `[::-1]`. 결과 `['B','D']`, `['E','F']`, `['F','E','D','C','B','A']`. 세 슬라이스는 새 목록, stops는 A–F 그대로.
17. append G, insert A-1, remove C 후 pop은 G. `last='G'`, `letters=['A','A-1','B','D']`, len4. remove는 값 C, pop은 마지막 **위치**.
18. `prices[0]=5000`, `prices.append(15000)`, `prices.extend([10000,20000])`, `prices.remove(140000)`. 최종 `[5000,200000,15000,10000,20000]`, len5, sum250000. `append([10000,20000])`는 리스트 한 원소를 넣어 이 결과가 아니다.
19. `reverse=True`, `[:3]`. scores `[70,95,80,95,60]`, ranked `[95,95,80,70,60]`, top3 `[95,95,80]`, 평균90.0. `scores.sort()`는 원본을 정렬하고 **None 반환**이라 ranked=None. 두 95는 별도 관측.
20. `sentence.split()`, `words[:2]`, `words[::-1]`. words `['red','blue','red','green']`, 처음 둘 `['red','blue']`, 역순 단어 `['green','red','blue','red']`. sentence 원문 `'red blue red green'` 그대로; 문자열 글자 자체 역순과 다르다.
21. `print(sum(row))`, 열 인덱스 모두 `2`. 행 합은 15,40,65; `math_scores=[3,8,13]`, 평균8.0. `s[2]`는 세 번째 **행**이다.
22. `record`, `95`. 기존 두 점수 평균 `(80+90)/2=85.0`. record `('Mina',80,90)`, updated `('Mina',80,95)`; 이미 구한 평균은 자동 변경 안 됨. tuple 직접 대입은 TypeError.
23. `sorted(registered & attended)→['Jun','Sora']`; `sorted(registered-attended)→['Jin','Mina']`; `sorted(attended-registered)→['Ara']`. 집합 자체 출력 순서는 고정하지 않는다.
24. `2`, `5`, `'book'`. 최종 `{'pen':8,'eraser':5}`, len2, False. len은 물품 총량13이 아니라 키 수2.
25. `word`, `0`. counts `{'red':3,'blue':2,'green':1}`, 전체 단어6, 종류3, yellow 기본값0. 없는 키를 get해도 counts에 yellow가 추가되지 않는다.
26. 없는 키에 `english_dict[word]`는 KeyError, `get(word,'등록되지 않은 단어')`는 지정 문구를 반환. 둘 다 새 항목을 넣지 않는다; 길이는 그대로3. `One`과 `one`은 다른 키.
27. 첫 items 원소는 `('ss',10)`(삽입 순서 기준), get 결과 10,100,None, len4. `get('kt',100)`은 kt를 저장하지 않는다.
28. 최종 original `{'name':'Mina','scores':[80,90,100]}`, copied `{'name':'Jun','scores':[60]}`. 바깥 딕셔너리만 복사, append 전까지 안쪽 리스트 공유; 마지막 대입은 copied의 연결만 바꾼다.
29. values `[3,1,3,2]`, ordered `[1,3,3]`, len(unique)=3, get=0, 존재검사 False, count=4. sorted 시점은 append **전**, unique/set과 count 계산은 append **후**.
30. 예: `a.append([1,2])`는 안쪽 리스트 하나 추가, `a.extend([1,2])`는 숫자 둘 추가. `a.sort()`는 a 변경+None 반환, `sorted(a)`는 새 리스트. `print(v)`는 화면 출력+보통 None 반환, `return v`는 호출자에게 v 전달. `x=3`은 대입, `x==3`은 bool 비교. `range(1,n)`은 n 제외, `range(1,n+1)`은 n 포함. 채점 요소: 각 쌍의 실제 동작/결과 차이와 작은 코드.
