# 개념 단답 전수 대조와 상세 해설 공통 기준 · 2026-10-24

기존 **개념 단답27문항은 부족했다.** 개념군24개에만 직접 단답이 있었고, 다른 내용은 객관식·코드 빈칸·해설에 등장하더라도 용어·기호·자료형·반환값·오류·경계를 직접 답하는 연습이 빠져 있었다. 새214문항을 추가해 **단답241문항**, 전체418문항(코드123·단답241·객관식54),318빈칸으로 보완했다. 단답에는 명칭 회상과 짧은 코드 결과 판단이 함께 포함된다. 이 숫자는 학습용 은행의 분량이며 실제 시험 문항 수가 아니다.

## 누락을 확인한 방법과 보완

98개 개념군에 태그가 하나씩 있다는 이유로 완료하지 않았다. 확보한11개 PDF381쪽의 추출문·해시와 기존 페이지별 분류,7개 보존 전사·기존 전사 대조 문서·관련 강조 문단을 다시 대조했다. 정의·분류·표·예제의 질문 가능한 표적을 실제 지문/정답/해설과 연결했다. 기존27단답은 그대로 유지했다.

새 ID는 BSA001–BSA214다. 위 표의 요약만으로 누락을 판정하지 않으며, 대응표에는 전체241문항의 실제 질문 표적·정답·PDF 페이지를 남겼다. 전사 강조점은 물리 행과 직접 단답 ID로 대응시켰다. 세부 동작을 확인하며 추가한 음수 나눗셈·리스트 반복·딕셔너리 키 검사·얕은 복사·빈 줄 세기·정렬 방향·범위 끝값·처음부터 거짓인 while·서식과 저장값·기본 인수·지역 재연결·난수 상한도 포함한다.

한 문제에는 하나의 명확한 판단을 둔다. 실행·상태 판단에는 실제 Python 문법, 줄바꿈·들여쓰기, 필요한 입력·준비 파일·셀 순서를 제시했다. 명칭 회상에는 정답 이름을 노출하는 코드를 억지로 붙이지 않았다. 강의 한글 용어는 한글로, 강의의 영문/함수/기호는 그 표기로 답한다. 공지의 단답 채점 방식인 **띄어쓰기만 무시**를 유지하며, 이름만/괄호 포함/따옴표 제외/숫자 자리 등 답안 형식을 지문에서 구분한다. 실제 교수 정답표를 확보했다는 의미는 아니다.

## 강의 범위 교정과 풀이 기록

- BM33: 제공 교안에서 확인하지 못한 천 단위 구분 서식 대신 강의의 소수 둘째 자리 서식 `.2f`로 교정했다. 코드·보기·정답·보기별 해설·실행값은 모두 일치하며 `123.456`은 `123.46`으로 표시된다.
- BM39: 집합 대칭차집합 대신 교안에 있는 합집합/교집합으로 교정했다. 코드·보기·정답·해설은 합집합 `[1, 2, 3, 4]`, 교집합 `[3]`과 일치한다. 정수의 비트 XOR `^`는 교안의 별도 범위라 유지한다.
- 기존204문항 중202문항 객체와 기존27단답은 그대로다. 위2문항의 이전 답안·정오·문제 전문은 별도 보관하고 해당 문항만 다시 풀도록 했다. 다른 답안·미완성 코드·북마크는 유지한다. 검수 중 강의 표기로 맞춘 신규3문항(지역 이름/전역 이름/연산 순서)에도 이전 답안이 있을 때 보관하는 규칙을 적용했다.
- 저장 키·버전·기존7문항 교정의 적용 여부는 유지한다. 오답 재풀이 중 미채점인 다른 문항은 종료 시 이전 답안을 복원하며, 교정된 문항의 과거 답안은 재풀이 기록에서도 보관한다. 전체 초기화를 강제하지 않는다.

## 확인 범위의 한계

이번 신규 시각 대조는 추출문만으로 판단하기 어려운21쪽이며 기존100쪽의 시각 기록과 구분한다.381쪽 전부를 새로 이미지로 검수했다고 표시하지 않는다. 표지·설치 화면 반복·과목 운영·과제·프로젝트·향후 라이브러리 소개는 새 단답 출제 항목과 분리했다. 슬라이드에 없는 lstrip 구두 보충·다음 차시 try/except/모듈 구현은 범위를 늘리지 않았다.

확보한 자료에서 확인한 단답 표적의 미대응은 보완했다. 다만 실제 시험 최종 페이지·교수 정답표·미확보 ch5_practice.ipynb·원영상/타임코드는 여전히 미확인이다. 가능한 모든 변형이나 실제 출제 내용을 보장하는 표현으로 바꾸지 않는다.

창을 **새로고침 → 개념 단답 → 전체**로 열면 새 문항을 풀 수 있다. 저장한 범위/단원/검색 필터는 유지하므로 전체를 보려면 설정에서 **준비 범위 모두·전체 단원·검색 비움**을 선택한다. GitHub 커밋·푸시는 하지 않았다.
