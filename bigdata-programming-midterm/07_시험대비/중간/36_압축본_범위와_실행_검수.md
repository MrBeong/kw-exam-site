## 실제 시험 준비용 읽기 경로

현재 공지의 개념 단답·4/5지선다·코드 빈칸에 맞췄다. 서술형이나 들여쓰기 직접 작성 훈련을 추가하지 않았다. 코드/기호는 원문 표기를, 개념 용어는 강의에서 사용한 표현을 따른다. 원문에서 영어인 것을 임의로 한국어 또는 다른 영어로 바꾸지 않는다.

| 시간 | 복습에서 해야 할 판단 |
|---|---|
| 0–8분 | 실행된 대입·현재 상태·표현식/print·자료형 변환·연산 방향 |
| 8–23분 | 윤년/팩토리얼 원문 빈칸 회상, range 끝·while 갱신·break/continue 추적 |
| 23–33분 | print/return·지역/전역·공유 객체·기본값/키워드·서식과 실제 값 |
| 33–46분 | 인덱스/슬라이스·메서드 반환·행/열·집합/키 조회·얕은 복사 |
| 46–55분 | 파일 모드·현재 위치·EOF·개행·사람별 초기화·쓰기/복사/평균 |
| 55–60분 | 막히는 단답 판별표만 확인하고 전체 코드5개 출력 점검 |

배분은 복습용 권장 경로이며 실제 시험 비중·총 문항 수나 측정된 학습 시간이 아니다.22개 판단/실수 카드로 구성했고, 이미 아는 추가 전체 코드는 접어두고 필요한 것만 펼친다. 합계·평균/윤년/팩토리얼은 현재 문제은행의 교안 원문 BO01·BO03·BO04 빈칸을 그대로 사용했다. 마지막5개는 기존 문항의 전체 코드를 제시하는 인출 연습이며 새 문제은행 문항을 추가하지 않았다.

## 범위·전사 강조점 대조

기존 개념 노트98개 개념군의 이름만 복사하지 않고, 실제 판단 근거·코드·예외/경계가 압축본의 어느 카드에 있는지 연결했다. 기존7개 전사의 강조34묶음도 대응시켰다. 합계·평균, 윤년, 출력 추적, 팩토리얼의 출제 형태 언급은 제공 전사의 해당 구간을 직접 재확인했다. 전사의 float·n+1·쓰기 모드 등 오인식을 모범 코드로 옮기지 않았다.

- [개념98군·전사34묶음의 위치/본문 근거](final-audit/cram-content-coverage.json)
- [직접 확인하는 근거 문구 원본](cram-source/coverage-witnesses.json)
- [현재 범위·공지](../../03_주차별정리/시험공지_제공본.md)

코드 추적 본문과 별도로, 기존 개념 단답에서 요구하는 Interpreter/Editor/Explorer/Terminal·Interactive Mode/Script Mode·GUI/CLI·Markdown/커널·sys.executable/ipykernel/pip·CPython/Bytecode/Python VM 등의 명칭은 서로 다른 역할을 비교하는 접힌 보충으로 넣었다. 제작자/공개 연도는 소개 슬라이드의 짧은 사실 회수로 표시해 핵심 알고리즘보다 먼저 외우게 하지 않았다. Dynamic Typing·Keywords·Built-in Functions와 각 예외 이름은 현재 강의/단답 표기를 함께 확인했다.

try/except·모듈 설계처럼 확보 교안에 예고만 있는 문법을 새 범위로 넣지 않았다. 파일 평균은 원문 int·정수/최소한줄 전제를 유지하고 실습 py의 float·빈 파일 처리를 구별했다. 이진 복사의2500바이트는 강의의 조각 계산 예시이며 제공 이미지 파일의 실제 크기라고 단정하지 않았다. 최종 페이지 경계·유형별 배점은 기존 미확인 상태를 유지한다.

이번 작업은 현재 검증된 개념·원문 예제·전사 대응과 압축본을 대조한 것이다.381쪽 PDF 전체를 이번에 새로 시각 검수한 결과나 미공개 시험 출제를 보장하는 것으로 제시하지 않는다.

개념 노트의 별도 안내와 예상문제 상단의 ‘1시간 압축’으로 진입할 수 있다. 각 생성 템플릿에도 같은 링크를 반영했다. 커밋·푸시는 하지 않았다.

## 재생성

```sh
python3 cram-source/build.py
python3 cram-source/verify.py
python3 cram-source/verify-coverage.py
```

편집 원본은 cram-source/content.py·style.css·app.js다. build.py는 기존 원문/문제 코드를 참조해 HTML·MD·대응표를 생성하며 기존 문제은행을 다시 작성하지 않는다. 실행 검산의 기대값은 oracles.json, 내용 검수의 독립 근거는 coverage-witnesses.json에 있다.
