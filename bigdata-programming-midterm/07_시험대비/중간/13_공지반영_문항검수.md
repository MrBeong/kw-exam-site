## 형식·채점·원문 경계

- 서술형 및 들여쓰기 직접 작성 문제 없음. 코드 틀의 개행/들여쓰기를 제공하고 번호별 토큰·식·인자만 입력한다.
- 개념 단답은 띄어쓰기만 무시한다. 코드 빈칸은 제공한 완성본과 문자 그대로 일치해야 정답이다. 동등한 코드의 의미 판정/실행 채점으로 표시하지 않는다.
- 공지가 한 글자 차이도 오답·부분점수 없음을 명시하므로 공통 가이드의 일반적인 의미 동등성/부분점수 기본값보다 공지를 우선했다. 실제 교수 정답표를 모르는 상태에서 연습 표기 기준을 실제 채점표라고 단정하지 않는다.
- PDF의 화씨 실수 리터럴·정류장 슬라이스와 Notebook의 표기 차이를 보존했다. 점수 파일은 PDF의 int/최소1줄 전제와 py의 float/빈 파일 처리를 구분했다. Path(__file__).with_name은 실습 보충으로만 분리했다.
- 객관식은 한 개념의 조건·실행 결과·인접 개념 혼동을 중심으로 작성했다. “교수가 그렇게 말했다”·정오 동어반복 보기 없음. 42문항 모든 보기의 근거를 사람이 재검토해 정돈했다. 실제 학생 응답 기반 변별도/난이도를 측정한 것은 아니다.
- 최종 정답 위치: 1번10·2번11·3번11·4번9·5번1. 보기4개40문항, 보기5개2문항. 위치를 맞추기 위한 의미 변경은 하지 않았다.
