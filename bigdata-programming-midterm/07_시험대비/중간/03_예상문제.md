# PDF 빈칸·수업 노트북 기반 예상문제 — 학습 파트너 제작

교수 제공 시험 문제/기출이 아니다. 사용자가 제공한 실제 수업 노트북과 PDF 예제를 기반으로 빈칸·출력 추적형으로 재구성했다. 문제의 페이지는 PDF 파일 기준이고 정답은 [별도 해설](04_정답과_해설.md)에 있다. **1–25는 직접 코드를 쓴 예제/교안 빈칸 위주 우선**, 26–30은 변형·개념 확인이다.

1. **실행 순서** [노트북 셀1–5, 260914 p.19–23] `x=3; x+4`를 실행하고, `print(x);print(x+4)`를 실행하고, 나중에 `x=20`을 실행했다. 두 print 결과와 마지막 x를 써라. 커널 재시작 후 print 셀만 실행하면?
2. **입력 타입** [셀9–10, 260914 p.24–31] `age=input('나이: ');print(age+'1')`에 20을 입력한 결과와 21을 얻도록 바꿀 한 표현식을 써라.
3. **합계·평균 빈칸** [260914 p.34] `a=____(input('첫 수: ')); b=____(input('두 번째 수: ')); total=____; average=____`. 소수도 받아 3.5와4.5에서 합8.0·평균4.0이 되게 완성하라.
4. **화씨 빈칸** [셀12, 260914 p.43] `ftemp=int(input(...)); ctemp=____`. 100°F와 32°F 결과, 100.5 입력 때의 문제를 적어라.
5. **연산 출력** [260914 p.51] `int('7')+4`, `'7'+'4'`, `7//4`, `7%4`, `2+3*4==14`, `2^3`, `2**3`의 값·자료형을 써라.
6. **오류 분류** [260909 p.8–18] `print(unknown)`, `'3'+2`, `1/0`, `int('abc')`, `[1][3]`, `{'a':1}['b']`가 각각 어떤 예외인지 설명하라.
7. **윤년 빈칸** [셀13, 260916 p.14] `if ______:`에 year가 4/100/400 규칙을 만족할 때만 True인 식을 써라. 2012,1900,2000,2023 결과를 표로 적어라.
8. **분기 순서** [260916 p.10–12] `if score>=90: print('A'); elif score>=80: print('B'); else: print('C')`에서 95,85,79 출력은? 첫 조건과 둘째 조건 순서를 바꾸면 95는?
9. **while 상태** [260916 p.21] `i=1;total=0;while i<=3: total+=i;i+=1;print(total,i)`에서 print는 반복 밖이다. 최종 두 수와 증가문을 합계보다 먼저 놓았을 때 total을 구하라.
10. **GCD 빈칸/상태** [셀14, 260916 p.22–25] `while y!=0: r=____; x,y=____`를 완성하고 48,18에서 각 반복 끝의 `(x,y)`와 출력 GCD를 써라.
11. **팩토리얼 빈칸** [셀15, 260916 p.29] `fact=____; for i in range(____,____): fact=____`. n=0,4,10의 결과를 써라.
12. **break/continue** [260916 p.36] `total=0; for i in range(1,8): if i==3: continue; if i==6: break; total+=i; print(total,i)`에서 마지막 print는 반복 밖이다. 더해진 수, total, i를 적어라.
13. **난수 함수 빈칸** [셀16, 260921 p.20] `index=random.randrange(____); password=password+____; return password`를 완성하라. 세 번 호출했을 때 보장되는 것과 보장되지 않는 것은?
14. **반환·서식 빈칸** [셀17, 260921 p.46] `def calculate_area(radius): result=3.14*radius**2; ____ result; area=____(r); print(f'넓이: {area:____}')`. r=2와10 출력을 써라.
15. **문자열/리스트 인수** [260921 p.24–28] 함수에서 문자열 지역 이름을 다시 대입하는 것과 공유 리스트에 `append`하는 것이 호출 뒤 원본에 미치는 차이를 설명하라.
16. **슬라이스 빈칸** [셀18, 260923 p.14] A–F stops에서 B,D 선택 `stops[__:__:__]`, 마지막 두 개 `stops[__:]`, 전체 역순 `stops[::__]`을 완성하고 원본 변화 여부를 써라.
17. **상태 추적** [260923 p.29] `letters=['A','B','C','D'];append('G');insert(1,'A-1');remove('C');last=pop()` 후 last, letters, len을 적어라.
18. **가격 빈칸** [260923 p.31] `[85000,140000,200000]`에서 첫 값을5000, `append(15000)`, `____([10000,20000])`, `remove(____)`로 140000 삭제. 최종 목록·길이·합을 적어라.
19. **정렬 빈칸** [셀19, 260923 p.33] `ranked=sorted(scores,____);top3=ranked[____]`를 완성하고 scores,ranked,top3,평균을 써라. `ranked=scores.sort()`로 바꾸면?
20. **split 빈칸** [260923 p.39] `words=sentence.____();print(words[____]);print(words[____])`로 `red blue red green`의 처음 두 단어와 역순 단어 목록을 출력하라. 원본 문장은?
21. **행·열 빈칸** [셀20, 260923 p.44] 3×5 리스트 `s`의 각 행 합과 세 번째 열 평균을 구하는 `sum(row)`와 `s[0][__],s[1][__],s[2][__]`의 빈칸을 채우고 결과를 써라.
22. **튜플 빈칸** [260928 p.8] `record=('Mina',80,90); name,midterm,final=____; updated=(name,midterm,____)`. 평균(기존 점수), record, updated를 써라.
23. **집합 빈칸** [260928 p.17] 신청 `{'Mina','Jun','Sora','Jin'}`과 참석 `{'Jun','Sora','Ara'}`의 공통, 미참석 신청자, 미신청 참석자를 각각 `&` 또는 `-`로 표현하고 정렬된 결과를 써라.
24. **재고 딕셔너리 빈칸** [셀21, 260928 p.26] `stock['pen']=stock['pen']-__`, `stock['eraser']=__`, `del stock[__]`를 완성하고 최종 stock,len,`'book' in stock`을 적어라.
25. **단어 수 빈칸** [셀22, 260928 p.49] `counts[word]=counts.get(____,____)+1`을 완성하고 `red blue red green blue red`의 counts, 전체 단어 수, 종류 수, `counts.get('yellow',0)`을 써라.
26. **사전 조회** [260928 p.37,45,47] `english_dict[word]`와 `english_dict.get(word,'등록되지 않은 단어')`의 미등록 키 동작 차이, `get` 뒤 사전 길이를 설명하라.
27. **items/get 출력** [260928 p.44–45] `my_stocks={'ss':10,'lg':5,'sk':5,'naver':20}`의 `list(items())` 첫 원소, `get('ss',100)`, `get('kt',100)`, `get('skt')`, len을 써라.
28. **얕은 복사** [260928 p.35] `original={'name':'Mina','scores':[80,90]};copied=original.copy();copied['name']='Jun';copied['scores'].append(100);copied['scores']=[60]` 후 양쪽 dict를 써라.
29. **종합 출력** [260928 p.53] `values=[3,1,3];ordered=sorted(values);values.append(2);unique=set(values);d={'count':len(values)}` 후 values,ordered,len(unique),`d.get('missing',0)`,`'missing' in d`,d['count']를 써라.
30. **설명형:** 빈칸 시험에서 `append`/`extend`, `sort`/`sorted`, `print`/`return`, `=`/`==`, `range(1,n)`/`range(1,n+1)`가 결과를 어떻게 바꾸는지 각 한 문장과 작은 코드로 설명하라.
