# 빈칸별 출력/동작 목표 보완 · 2026-10-25

BP20의 4·5행에서 무엇을 선택해 출력해야 하는지 지문에 없었다. ‘주어진 위치와 구간을 읽는다’는 문장은 구간을 정해 주지 않으며 마지막의 첫 글자 교체만 명확했다. 정답 코드의 누출을 줄인다는 기준을 적용하면서 과제 수행에 필요한 목표까지 덜어 낸 부분이다.

코드131문항의 공개 목표와 가린 연산/함수·선택 대상을 다시 대조했다. BP20의 필수 선택 대상을 추가하고,BP34도 마지막 행의 ‘정수를 문자열로 바꿔 이어 붙이기’를 목표에 명시했다. 다른 문항은 입력/고정 코드/기존 목표가 평가 동작을 지정하는지 확인했다. 모든 고정 print의 내용을 무조건 반복하는 대신 각 빈칸이 풀 수 있는 목표를 갖는지 대조했다.

정답인0:2·2:5·1:이나변환 함수 이름은 공개 설명에 넣지 않았다. 구간의 의미·변환 방향은 학생에게 주어야 하는 과제 조건이다. Py·tho·Jython처럼 계산된 출력 패널을 풀이 전에 새로 추가하지 않고,자연어 요구사항으로 명시했다.

작성 원본 question-display.json의 두 목표와 공개 표시 revision만 바꾸고 문제·해설 MD와 HTML을 재생성했다. goal-target-review.json에는 변경 전후 문구와 각 빈칸·행·요구사항의 대응을 남겼다. goal_invariants.py는 이 명시적 문안 변경만 이전 검사에 허용한다. **437개 문제 레코드·완성 코드·빈칸 위치·정답·실행·상세 해설·저장 버전은 그대로**다. 기존 답안·정오·초안·북마크를 초기화하거나 새로 이전하지 않는다.

verify-goal-targets.py의 176검사로 공개 목표 131개와 표적 이유를 대조하고, 변경한 두 문항의 숨긴 작업 7개가 문안 및 실제 실행과 맞는지 확인했다. 첫 두 선택만 다르게 하고 마지막 Jython은 그대로 만드는 반례를 통해 이전 문안의 누락과 새 요구사항이 제외하는 결과를 기록했다. 문자열 검사만으로 의미 검수를 대신하지 않는다.
