01

실행 환경과 코드의 실행 순서

눈에 보이는 코드가 아니라 실제로 실행된 코드와 현재 상태를 읽는다.

001Python · 편집기 · 터미널의 역할
  • Python 인터프리터는 코드를 실행하고 VS Code는 코드를 작성·관리하는 편집기다. Explorer는 파일 관리, Editor는 코드 작성, Terminal은 명령과 결과 확인 영역이다.
  • python hello.py는 셸 명령이다. .py 파일이나 Python의 >>> 뒤에 적는 문장이 아니다. >>>와 셸 프롬프트는 코드에 포함하지 않는다.
  • 대화형 모드는 짧은 실험에, .py 스크립트는 저장한 여러 줄을 다시 실행할 때 쓴다. 스크립트에서는 식만 적지 말고 결과가 필요하면 print()한다.

002Notebook · 셀 · 커널참고
  • .ipynb는 코드 셀·Markdown 셀·출력을 함께 보관한다. 코드 셀 안은 위에서 아래로 실행하지만 셀을 실행하는 순서는 사용자가 정한다.
  • 커널은 Python 코드를 실행하고 변수 상태를 유지한다. 여러 셀은 같은 커널 상태를 공유한다. 편집기 확장 설치와 Python/커널 설치는 별개다.
  • Ctrl+Enter는 현재 셀 실행, Shift+Enter는 실행 후 다음 셀 이동이다. 인터프리터·커널·패키지 설치 환경이 일치하는지 확인한다.

003자동 표시 · print · 대입 · 저장
  • 코드 셀의 마지막 표현식은 값을 자동 표시할 수 있다. 대입문은 값을 바꾸지만 자동 출력하지 않는다. 여러 결과를 보려면 print()를 쓴다.
  • x + 4를 평가해 7을 보아도 x가 7로 바뀐 것은 아니다. 대입문이 없으면 x는 3이다.
  • 편집·저장만으로 커널의 값이나 기존 출력이 새로 계산되지 않는다. score = 80을 90으로 편집만 하면 다음 출력은 여전히 85일 수 있고, 대입 셀을 재실행하면 95가 된다.

004실행 번호와 재시작
  • A 셀 x = 10, B 셀 print(x), C 셀 x = 20일 때 A→B는 10, A→C→B는 20이다. 화면 배치가 실행 순서가 아니다.
  • 커널을 재시작하면 변수·함수 상태가 초기화된다. 코드가 화면에 남아 있어도 B만 실행하면 NameError가 날 수 있다.
  • 재시작 후 위에서부터 모두 실행해도 같은 결과가 나오는지 확인한다. 이전 실행의 변수가 코드 누락을 가리지 않게 한다.

005print와 문자열의 해석
  • print(10 + 20)은 계산 결과 30, print("10 + 20")은 식 모양의 문자열을 출력한다.
  • 여러 인수는 기본적으로 공백으로 나누고 마지막에는 줄바꿈을 붙인다. print()는 빈 줄, 문자열의 \n은 줄바꿈이다.
  • sep은 인수 사이, end는 출력 끝에 붙는 문자열이다. 표시 방식을 바꾸어도 원래 값의 자료형은 그대로다.

019복합 조건과 단축 평가
  • 비교는 ==, !=, >, <, >=, <=를 사용한다. 이상/초과, 이하/미만의 경계를 구분한다.
  • and는 두 조건 모두, or는 적어도 하나, not은 참·거짓 반전이다. or는 “정확히 하나만 참”이 아니다.
  • and는 앞이 거짓이면, or는 앞이 참이면 뒤를 평가하지 않는다. count != 0 and 10 / count > 2는 count가 0일 때 나눗셈을 하지 않는다.
  • 일반적인 and/or는 피연산자 자체를 반환할 수 있다. 0 or 5는 5, "Python" and 3은 3이다. age >= 18 and 25는 나이 상한 비교가 아니다.
