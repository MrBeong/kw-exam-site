# 실제 수업 노트북 22개 코드 셀 — 우선 복습

원본 [Untitled.ipynb](../01_강의자료/week01/Untitled.ipynb)을 **읽기만** 했다. 사용자 설명에 따르면 수업 중 직접 작성한 예제여서 시험 가능성이 높다. [첫수업.py](../01_강의자료/week01/첫수업.py)는 `print("Hello, World!");` 한 줄이다. 이 노트북의 코드 셀은 22개+빈 셀1개이며 실행 번호가 화면 순서와 다르고 셀12는 미실행 상태다. 따라서 저장 출력이 지금 코드를 차례대로 실행한 결과라고 단정하지 않는다. 원본 노트북은 수정·전체 실행하지 않았고, 아래의 고정 입력 결과는 코드 논리로 검산했다. 각 셀의 입력·처리·출력을 **노트북을 보지 않고 재구성**하는 것이 핵심이다.

## 특히 빈칸·변형으로 다시 써 볼 코드

1. **입력 타입:** `text=input(...)`을 숫자 계산에 쓰기 위해 어느 줄에 `int` 또는 `float`를 넣어야 하는가? 입력 `20`에서 `"201"`과 `21`을 만드는 두 경로를 모두 적어라.
2. **상태 추적:** 셀1→5를 화면 순서대로 실행한 경우와 셀5→셀2를 실행한 경우의 두 `print` 결과를 각각 적어라. 커널 재시작 후 셀2만 실행하면 오류가 나는 이유는?
3. **조건·반복:** 윤년의 100/400년 예외, GCD의 `(x,y)` 갱신, 팩토리얼 초기값/범위를 빈칸 없이 다시 작성하라.
4. **함수:** random index가 범위를 벗어나지 않는 이유, `return`을 루프 안으로 들여쓰면 왜 1글자만 나오는지, 면적 함수의 print/return 차이를 말하라.
5. **컬렉션:** 원본을 변경하는 `append`, 딕셔너리 대입/삭제와 새 객체를 만드는 `sorted`, 슬라이스를 구분하고 각 출력값을 계산하라.

입력이 들어가는 셀/난수 셀은 고정 출력 한 줄로 암기하지 않는다. 노트북 자체는 커널·패키지·입력 상태가 필요하며 다운로드/읽기/실행 검증을 구분한다. 현재까지는 **원본 확보·코드 읽기 완료**, 노트북 전체 실행 검증은 미수행이다.
