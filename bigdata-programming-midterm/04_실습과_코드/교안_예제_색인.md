# 강의 PDF 예제 색인과 복습 우선순위

PDF 파일에서 1부터 센 쪽수다. 실제 수업 [노트북](../01_강의자료/week01/Untitled.ipynb)에 직접 작성한 예제는 **최우선**, 교안의 코드 빈칸/밑줄 실습은 **높음**, 그 외 출력 추적·개념 사례는 **보통**, 설치 화면·진로/도구 역사 사례는 **낮음**으로 둔다. 이는 사용자의 우선순위 요청, [조건·반복 전사](../02_녹화와_전사/조건과_반복_제공전사.txt)의 빈칸형 출제 고려 발언, 수업 노트북과 교안 중복에 근거한다. 시험 범위 확정이나 점수 배점 추정은 아니다. 전사·PDF의 정확한 출제 문장과 원문은 원파일을 보존한다.

[260907 개발환경 교안](../01_강의자료/260907_Python%26DevelopmentEnvironment_01.pdf) p.7–21의 설치/인터프리터 선택과 [9/2 소개](../01_강의자료/260902_Intro.pdf) p.1–12의 평가·라이브러리 예시는 읽어두되, 사용자가 말한 코드/빈칸 출제 근거에서는 우선순위를 낮춘다. 260928 전사 앞부분의 AI 회사·프로젝트 경험담도 개념 적용 맥락이지 정답을 암기할 알고리즘은 아니다. **날짜 표기는 원본 파일명 식별용이며 실제 강의일 확인으로 승격하지 않았다.**

각 PDF의 모든 텍스트 페이지는 추출물 폴더 (로컬 관리 문서)에 보존했다. 추출문에서 밑줄·그림·코드 줄맞춤은 빠질 수 있어 빈칸 위치는 원본 PDF에서 대조했다. [빈칸 복습문제](../07_시험대비/중간/03_예상문제.md)와 [별도 해설](../07_시험대비/중간/04_정답과_해설.md)에서 풀 수 있다.
