## 중간고사 (PDF p.2)

- 필기·Closed-book, 40점 만점, 최종 성적40%.
- 개념 단답형, 4지/5지선다, 코드 빈칸. 서술형·들여쓰기 직접 작성은 출제하지 않는다.
- 모든 문제는 강의 슬라이드 범위 안에서 출제한다.
- 개념 단답: 띄어쓰기 차이만 허용하고 다른 표현은 오답.
- 코드 빈칸: 한 글자 차이도 오답, 부분점수 없음.
- 휴대전화/부정행위 적발 시 F.
- 공지에는 시험 날짜·시간·장소·문항 수·유형별 배점·최종 페이지 경계가 없다. 10/26 15:00은 별도의 기존 사용자 정보다.

## 행사 가산점 (PDF p.3)

10/13–14 코엑스 Physical AI Tech Week 프로그램1개 이상 참여. 행사 명찰 또는 본인이 나온 내부 사진의 출력 증빙 제출 시 중간4점 추가, 중간40점 만점인 경우 추가 없음. 이미 지난 행사이며 사용자의 참석/증빙/제출 여부는 미확인이다. 이 내용을 개념 시험문제로 만들지 않았다.

## 기말 프로젝트 (PDF p.4–5)

2026년12월2일까지 공지에 나열된 방송사/종합일간지에 지면·영상(풀/숏츠)으로 보도되면 참신성 만점이라는 추가 기준이다. 기존 과제·기말 안내와 별도로 보존하며 중간 문제에 혼합하지 않았다. 새 제출·외부 연락을 수행하지 않았다.
