## 핵심 질문과 학습 흐름

**강의자료 요약:** 파이썬 기본 문법을 이해한 뒤 패키지로 데이터를 수집·처리·시각화하는 과정이다(p.2–7). Matplotlib은 시각화, Selenium은 웹 데이터 수집 자동화, NumPy/Pandas는 배열 형태 데이터와 분석 예시로 소개된다. 아직 코드 파일이나 실행 예제는 제공되지 않았다.

## 평가와 강조

- 출석·태도 10%, 중간 필기 40%, 개인 과제보고서 15%, 팀 기말 프로젝트 35%. p.9–10.
- 중간: 대면·필기·Closed-book, 파이썬 기초 문법과 알고리즘 위주. 세부 범위·날짜·문항 유형은 미확인. p.9.
- 개인 보고서는 분석이 만드는 사회적/비즈니스 가치를 중심으로 평가하며 4주차 추가 안내 예정. 기말 팀은 7주차 무작위 구성, 발표 1회·보고서 1회. p.10.
- 교수님은 AI 도구 의존을 지양하고 본인 이해와 작성 과정을 강조한다(p.8, 10). 학습에는 직접 출력 예측·설명·수정하는 연습을 반영한다. ‘호랑이’ 비유를 프로그래밍의 정의로 다루지 않는다.
- 9/9 CBTL 설문 마감, 성적 미반영. p.11. 실제 응답 여부는 미확인이다.

## 자주 혼동할 부분 — 학습 파트너 보완

패키지 이름을 아는 것과 코드를 이해하는 것은 별개다. 이후 실습마다 입력·출력·매개변수·처리 순서·결과 해석을 적고, 조건이나 데이터가 달라지면 결과가 어떻게 바뀌는지 직접 설명한다. 현재 다운로드·환경설정·컴파일·실행 검증을 수행한 상태는 아니다.

## 복습 질문 — 학습 파트너 작성

1. 데이터를 수집→처리→시각화할 때 단계별 목적을 설명할 수 있는가?
2. 코드를 실행하기 전에 결과를 예측하고 그 이유를 설명할 수 있는가?
3. 보고서의 분석 결과가 누구에게 어떤 결정을 돕는지 말할 수 있는가?

이 OT에는 구체적인 문법 문제·수식·정답이 없다. 본 강의 코드가 들어오면 빈칸·변형·출력 추적 문제로 연결한다.
